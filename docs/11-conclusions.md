## 3. 决议明细

### 3.1 色彩

| 项 | 决议 |
| --- | --- |
| `text.tertiary` | `#4C616D`（最严口径 4.61）；**加深与色晕降浓两件都做，不可互替** |
| `gradient.mid` 起点 | `#3898B4` |
| 深色 `text.on-fill` | `#FFFFFF` |
| `status-text.*` | 成功 `#226A4C` / 信息 `#125F8F` / 警示 `#8A5A18` / 危险 `#9E4038` |
| 群青 `#4C8DAE` | 降级为描边 / 图形专用色 |
| 色卡数量 | **9 个**（不补齐到 12） |
| 浅色色晕浓度 | 66% → **42%** |
| 深色版色温 | **压向青灰**（方向已定，目标色值待定，与深色色晕同批评审） |

### 3.2 组件与形态

| 项 | 决议 |
| --- | --- |
| `tonal` | 走 **tint 叠加**（不改描边）；亮度阶梯 0.56 / 0.80 / 0.93 |
| 三级色层级 | 由"颜色"改为"字号 + 颜色"共同承担；三段映射：主 17+ / 次 15–17 / 三级 12–13 |
| Tab 栏高度 | **58**（底部留白 82 的算式建立在其上） |
| 玻璃取值 | 以 `material.*` 令牌为准；导航栏 / Tab 栏 / 浮层 `regular` 70%，模态 / Toast `thick` 86% |
| `material.sheen` | 仅保留给 Hero 卡与空状态 |
| Tab 标签字号 | `caption2` 11 · 500（10pt 下限取消） |
| 触控热区 | 规格写「iOS ≥44 / Android ≥48」 |

### 3.3 令牌与真源

| 项 | 决议 |
| --- | --- |
| 字体行高 | 令牌改存**行高比** `lineHeightRatio`，不存绝对值 |
| 新增令牌 | `status-text.*` / `component.*` / `size.navbar-large` / `scrim` / `wash` / `gradient.wash.*` / `semantic.*.gradient.tint` |
| 派生布局常量 | 82 / 92 / 62 由**生成器算**（存组件参数，不存绝对值） |
| 画廊 `--g-*` | 改为**生成产物**并纳入 `--check` |
| 画廊定位 | 阶段性评审产物，每批组件定稿时重生成，不承诺实时同步 |
| 账目治理 | 数值只存在于令牌一处；对比度表格由生成器产出（见 §4.3） |

### 3.4 地基决策（M0 一次冻结）

四件**必须在 M0 一次令牌变更中完成**（分次做等于 37 规格 × 3 画廊各改多遍）：

1. 语义色（含 `text.tertiary`）
2. 色晕令牌与浓度（浅色 42% + 深色版本）
3. `WDTextStyle` 形态 + 行高比
4. RTL 命名方向（leading / trailing、图标镜像列）

### 3.5 按候选推进项

| 项 | 采用的候选 |
| --- | --- |
| 深色色晕 | 由深色渐变族 `#123449` 派生（36%），三级 13.84 / 8.05 / 5.66 全达标 |
| 玻璃规则 | `06 §5.2` 改"结果式"（不写死百分比），档位与深色色晕绑定；浅色 70% 安全 |
| tint 配方 | 令牌只存"配方 + 基准底（需注明 card 还是 canvas）"，hex 由生成器算 |
| 三级色映射 | 见 §3.2；三级色仅用于非必需信息 |
| 文案注入 | `WDLocalization`（key + 参数 + 默认值），M1 定形态 |
| M0 冻结口径 | M0 只"定形态"，"确认冻结 `WDTextStyle`"挪到 M1 出口 |
| 最不利底色取法 | 落成断言算法：对色晕每个色标 × 每个 alpha 档采样，自动取与文字明度差最小者 |
| 净 alpha 口径 | 令牌写明**生效 alpha**（含是否计入预览 `.55` 元素透明度） |

## 4. 执行计划

### 4.1 M0 出口条件

M0 收尾必须同时满足：

1. `node tools/token-build/build.js --check` 通过；
2. 对比度断言通过，且**支持 alpha 合成**、**自动取最不利背景**（canvas / 色晕 / status-soft / 卡片实底 / 玻璃）；
3. 两端能编译；
4. `WDTextStyle` **形态冻结** + 生成器产出**行高比**；
5. RTL 命名已冻结（leading / trailing、图标镜像列）；
6. 画廊 `--g-*` 由生成器输出并纳入 `--check`；
7. 色晕令牌写清净 alpha 并出深色版本，经第 2 条断言验证；
8. 玻璃档位与 `06 §5.2` 调和；
9. 色卡数量与文档描述一致（B9 第 1 条）。

### 4.2 里程碑

| 阶段 | 工期 | 出口条件 |
| --- | --- | --- |
| **M0 规范冻结** | **1.5 周** | 见 §4.1 |
| **M1 Foundation** | 1 周 | 两端 Showcase 页；**浅/深 × 常规/AX3 × LTR/RTL 六态**截图入库；`WDTextStyle` 确认冻结 |
| **M2 基础组件 1 批** | 2 周 | 验收清单全勾；AX3 / fontScale 1.3 不截断 |
| **M3 基础组件 2 批** | 2 周 | 基础层封板，公开 API 冻结 |
| **M4 反馈与弹层** | 2 周 | 焦点进出归还逐条验收；遮罩与层级无跳变 |
| **M5 导航与表单** | 2 周 | 滚动收缩跟随进度；Tab 栏底部留白 ≥82 |
| **M6 场景层与发布** | 1.5 周 | 无障碍回归 + 截图基线 + 双端同 tag `v1.0.0` |

**合计 12–13 周**（1 iOS + 1 Android + 0.5 设计评审）；串行人力约 16–18 周。

### 4.3 质量门禁与账目治理

| 门禁 | 说明 |
| --- | --- |
| 令牌生成一致 | `node build.js --check`，每次 PR |
| 对比度断言 | 支持 alpha 合成 + 最不利背景；每次 PR |
| 编译 | iOS `swift build` / `xcodebuild`；Android `:wisdom-ui:assembleDebug` |
| 公开 API 冻结 | Android `binary-compatibility-validator`；iOS `swift-api-digester`（属 M3） |
| 快照回归 | 浅/深 × 常规/大字号（+RTL）；每次 PR |
| 画廊与令牌一致 | `--g-*` 由生成器输出 |
| 账目生成化 | `tokens/contrast.json` 声明前景 × 背景 × 场景 × 阈值 → 生成 `docs/contrast-report.md`，文档只引用不手写 |
| 字面量 lint | 两端各一条规则（SwiftLint / ktlint+detekt），命中裸 hex / 裸数值即构建失败 |

### 4.4 执行顺序

`改令牌 → apiDump → 改规格 → 改文档 → 重生成 → 两端编译 + 断言`，每步跑一次验证；M0 收尾冻结命名（含 RTL），再开 M1。

## 5. 开放问题（保留）

### 真开放（无候选解，需验证或再决定）

1. **A1 落地细节** — 嵌入"哪一套"中文字体、是否子集化、字体授权（MiSans / HarmonyOS Sans SC 商用授权），以及 9MB+ 体积由组件库还是产品层承担。
2. **A2 落地细节** — 深色 canvas 压向青灰的**目标色值**，与深色色晕同批评审后定。
3. **Android：Material You 动态取色会顶掉品牌蓝** — 宿主套 `dynamicLightColorScheme()` 会覆盖 Wisdom 语义色，跨端一致性失效。需 M1 明确"不接入"或提供 opt-in 开关。
4. **iOS 26：系统 chrome 与自绘悬浮 Tab 栏的关系** — 需真机验证；若复用系统 chrome 可行，`02 §34` 的 Tab 尺寸验收应只约束自绘档（iOS 17–25 与 Android）。影响 P0。

### 待验证确认（有候选，落地时才关）

5. 深色色晕候选、玻璃结果式规则 → M0 断言通过后定稿
6. tint 配方 / 基准底、三级色映射表 → 设计侧补齐后进 M0
7. 净 alpha 口径（预览 `.55` 是否计入生效 alpha）→ 令牌中写明
8. iOS 行高比落地方式（`.lineSpacing` 换算 vs `NSParagraphStyle`）→ M1 实测出结论

### 文档治理（待办）

9. 讨论稿 [`10-discussion.md`](10-discussion.md) 的 §4.5「待裁定开放项」与 §5「行动项」已过期（B10 / T1 已裁定却仍写"待裁定"）；**本文取代之**，后续以本文为准，讨论稿按需回填指针。
