# 06 · 组件详细规格

> 本文是**开发的依据**与**验收的标准**。组件实现完成、且本文的验收清单全部勾选，才视为交付。
> 清单见 [`02-components.md`](02-components.md)，可视化见 [`design/gallery/wisdom-components.html`](../design/gallery/wisdom-components.html)。

## 规格模板

每个组件按下面 12 节写，缺一节不算完成。写规格时遵守两条：

- **写令牌名，不写色值**。色值只在 `tokens/wisdom.tokens.json` 里出现一次。
- **验收项可勾选**。写不成"是/否"的句子不是验收项。

| # | 章节 | 要回答的问题 |
| --- | --- | --- |
| 1 | 用途 | 什么时候用它，什么时候**不要**用它，替代方案是什么 |
| 2 | 解剖 | 由哪几段组成，每一段用什么令牌 |
| 3 | 尺寸 | 各档的高度 / 内距 / 字号 / 图标 / 圆角，精确到 pt |
| 4 | 变体 | 每个变体的背景 / 文字 / 描边 / 阴影，逐项对应令牌 |
| 5 | 状态 | 默认 / 按下 / 聚焦 / 禁用 / 加载 / 选中 / 错误，各自的视觉、动效、触觉 |
| 6 | 布局 | 与相邻元素的关系、是否全宽、最大宽度、换行规则 |
| 7 | 内容 | 字数上限、截断方式、空值、数字与单位格式 |
| 8 | 交互 | 点击 / 长按 / 滑动 / 拖拽 / 键盘分别发生什么 |
| 9 | 动效 | 时长与曲线，引用 `motion.*` 令牌 |
| 10 | 无障碍 | 朗读文本、角色、触控热区、动态字体、对比度 |
| 11 | 平台差异 | iOS 与 Android 各自怎么做 |
| 12 | 验收清单 | 可勾选的检查项 |

# 01 · Button

**视觉参考**：画廊 01 · Button ｜ **优先级** P0 ｜ **两端同名** `WDButton` / `WdButton`

### 1. 用途

触发一个动作。是界面上唯一"会让事情发生"的基础组件。

- **用**：提交表单、确认操作、触发一个明确的动作
- **不要用**：导航到别的页面（用 `WDListRow` 或链接）；筛选（用 `WDChip`）；只有图标没有文字的场合（用 `WDIconButton`）
- **一屏一个主操作**。`filled` 变体每屏最多一个，其余操作降级为 `tonal` / `glass` / `plain`

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 容器 | 必有 | 胶囊底 + 内边距，高度由尺寸档决定 |
| 前置图标 | 可选 | `size.icon.sm`（16），与文字间距 `space.3`（8） |
| 标签 | 必有 | `type.headline`（17/22 · 600） |
| 后置图标 | 可选 | 同前置，只用于"有方向"的动作（下一步、展开） |
| 加载指示 | 条件 | 加载态替换标签，**容器宽度不变** |

前置与后置图标不同时出现——同一个按钮只表达一个方向。

### 3. 尺寸

| 档 | 高度 | 水平内距 | 字号 | 图标 | 圆角 | 最小宽度 |
| --- | --- | --- | --- | --- | --- | --- |
| `sm` | `size.control.sm` 32 | 12 | 13 | 14 | `radius.full` | — |
| `md`（默认） | `size.control.md` 44 | 16 | 15 | 16 | `radius.full` | — |
| `lg` | `size.control.lg` 52 | 20 | 16 | 20 | `radius.full` | — |

表单内的按钮可改用 `radius.md`，与输入框的圆角对齐。
只有图标的场合必须保持 `size.touch-target-min`（44×44）的热区，视觉可以更小。

### 4. 变体

| 变体 | 背景 | 文字 | 描边 | 阴影 | 用在哪 |
| --- | --- | --- | --- | --- | --- |
| `filled` | `gradient.fill-light`（深色外观 `gradient.fill-dark`） | `text.on-fill` | 无 | `elevation.brand` | 唯一主操作 |
| `tonal` | `gradient.surface` | `text.on-soft` | 无 | 无 | 次级操作 |
| `glass` | `surface.glass-strong` | `text.primary` | `border.hairline` | `elevation.1` | 浮在图片或内容之上 |
| `outline` | 透明 | `text.primary` | `border.hairline-strong` | 无 | 中性操作 |
| `plain` | 透明 | `text.brand` | 无 | 无 | 行内操作、列表右侧 |
| `destructive` | `gradient.deep` | 白 | 无 | `elevation.brand` | 删除、退出等不可逆操作 |

`filled` 的浅色端与深色端分别是 `derived.fill-light-1` / `derived.fill-light-2`，
配 `derived.text-on-fill` 对比度 5.4–6.9:1。**不允许把亮色渐变配白字**。

### 5. 状态

| 状态 | 视觉 | 动效 | 触觉 |
| --- | --- | --- | --- |
| 默认 | 见变体表 | — | — |
| 按下 | 缩放至 `motion.component.press-scale`（0.97），亮度降到 96% | `motion.duration.instant` 100ms | 轻 |
| 聚焦 | 外扩 3pt 光环，`text.brand` 32% 透明 | `motion.duration.fast` | — |
| 禁用 | 整体 40% 不透明度，去掉阴影 | 无 | 不响应 |
| 加载 | 标签原位换成指示器，容器宽度**不变**；保留原标签供读屏 | 指示器持续旋转 | 触发时轻 |
| 悬停 | 仅指针设备，亮度 98% | `motion.duration.instant` | — |

### 6. 布局

- 同一组按钮水平排列，间距 `space.3`（8）
- 竖排时**主操作在上**，间距 `space.4`（12）
- 纵向堆叠的按钮组可以全宽；水平并排的按钮内容宽度即可，不要等宽拉伸
- 宽度不足以放下全部文字时，标签**不换行**，容器向外扩；容器宽度受父级限制时标签截断

### 7. 内容

- 标签 2–6 个汉字，最多 12 个字符
- 动词开头，不用"确定/好的"这类无信息量的词；删除场景直接写"删除"
- 不用句号结尾
- 加载态文案由加载指示器承担，标签不改成"加载中"

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击 | 按下态 → 触发 `onClick`。若 `onClick` 内部会发起异步操作，调用方负责切到加载态 |
| 长按 | 默认不响应。上下文菜单场景由外层容器处理 |
| 拖拽 | 不响应 |
| 键盘 | 空格 / 回车触发；`Tab` 聚焦时显示聚焦光环 |
| 重复点击 | 加载态期间忽略后续点击，不排队 |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 按下 / 抬起 | `motion.duration.instant` 100ms，`cubic-bezier(.2, 1.5, .5, 1)` |
| 加载态切换 | `motion.duration.fast` 160ms 交叉淡化 |
| 聚焦光环 | `motion.duration.fast` 160ms |

按下用弹性曲线（回弹感来自曲线，不是弹簧动画）；状态切换用线性时长。

### 10. 无障碍

- **标签即朗读文本**，不需要额外的 `aria-label`
- 加载态朗读"提交，处理中"，不是"加载中"
- 禁用态用 `aria-disabled` 语义而非移除元素，保证读屏能发现它
- 触控热区不小于 44×44，`sm` 档视觉 32 但热区补到 44
- 文字随动态字体放大，容器高度同步增高，**不裁切**
- 文字与背景对比度 ≥ 4.5:1；图形边界 ≥ 3:1

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | 内部用系统 `Button` + `WDButtonStyle`，同时把 style 暴露出去 | `Surface(onClick)` 包 `Row`，用 `WDButtonVariant` 参数 |
| 系统行为 | 保留 `.disabled`、键盘导航、VoiceOver 角色 | 保留 Ripple；`Modifier` 是必选参数后的第一个可选参数 |
| 按压反馈 | `.scaleEffect` + `WdPressStyle` | `indication = null` + `animateFloatAsState` |

### 12. 验收清单

- [ ] 三个尺寸的高度分别为 32 / 44 / 52，误差 ≤ 1pt
- [ ] 六个变体的背景 / 文字 / 描边与变体表逐项一致，色值全部来自令牌
- [ ] `filled` 浅色外观配深色文字，对比度实测 ≥ 5.4:1
- [ ] 加载态切换时容器宽度不变，无跳动
- [ ] 禁用态仍可被读屏发现，且标注为不可用
- [ ] 动态字体放大到 AX3 不截断、不重叠
- [ ] 触控热区任意档位均 ≥ 44×44
- [ ] 深浅两种外观都验证过，浅色优先

# 02 · IconButton

**视觉参考**：画廊 02 ｜ **优先级** P0

### 1. 用途

纯图标的单一动作。空间紧张或动作含义无歧义时使用。

- **用**：导航栏的搜索/新增、工具条的撤销/重做、列表右侧的更多
- **不要用**：含义有歧义的图标；带文字的场合（用 `WDButton`）；破坏性操作（如删除，必须带文字说明）

### 2. 解剖

容器 + 图标两段。没有标签，**语义完全由无障碍标签提供**。

### 3. 尺寸

| 档 | 视觉尺寸 | 热区 | 图标 | 圆角 |
| --- | --- | --- | --- | --- |
| `sm` | 32×32 | 44×44 | `size.icon.sm/md` 16–20 | `radius.full` 或 `radius.sm` |
| `md`（默认） | 44×44 | 44×44 | `size.icon.lg` 24 | `radius.full` 或 `radius.sm` |

`sm` 档视觉 32，热区必须补到 44——通过加大点击区域而不是放大图标，用负内边距或 `contentShape` 实现。

### 4. 变体

| 变体 | 背景 | 图标色 | 描边 | 用在哪 |
| --- | --- | --- | --- | --- |
| `filled` | `gradient.mid` | 白 | 无 | 强调动作 |
| `tonal` | `gradient.surface` | `text.on-soft` | 无 | 次级动作 |
| `glass` | `surface.glass-strong` | `text.primary` | `border.hairline` | 浮在内容之上（导航栏） |
| `outline` | 透明 | `text.primary` | `border.hairline-strong` | 中性动作 |
| `plain` | 透明 | `text.brand` | 无 | 行内动作 |

### 5. 状态

与 Button 一致：默认 / 按下（缩放 0.97）/ 聚焦（3pt 光环）/ 禁用（40%）。
图标按钮**没有加载态**——加载状态下应当换成 `WDButton` 或骨架。

### 6. 布局

- 一行内最多 3 个，间距 `space.3`（8）
- 导航栏内的图标按钮与屏幕边缘间距 `space.5`（16）

### 7. 内容

- 必须提供无障碍标签，写**动作**而不是图标名：写"搜索"不写"放大镜"
- 图标不配文字时不做视觉截断，图标本身保持完整

### 8. 交互

点击 → 立即执行，**不做二次确认**。
破坏性动作不放在 IconButton 里——没有文字说明的删除按钮是事故源头。
长按：默认不响应；工具栏场景可显示工具提示。

### 9. 动效

同 Button：按下 `motion.duration.instant`，聚焦光环 `motion.duration.fast`。

### 10. 无障碍

- 必须有 `aria-label` / `accessibilityLabel`，否则读屏只能读出"按钮"
- 角色为 `button`，图标本身标记为装饰
- 热区 ≥ 44×44
- 图标与背景对比度 ≥ 3:1

### 11. 平台差异

iOS 用 `Image(systemName:)` + `.frame(minWidth: 44, minHeight: 44)`；
Android 用 `IconButton` 或 `Box(Modifier.size(44.dp).clickable(...))`。

### 12. 验收清单

- [ ] 每个实例都有无障碍标签，且写的是动作不是图标名
- [ ] `sm` 档视觉 32，实测热区 ≥ 44×44
- [ ] 没有出现无文字的破坏性操作
- [ ] 深浅两外观下图标对比度 ≥ 3:1

# 03 · TextField

**视觉参考**：画廊 03 ｜ **优先级** P0

### 1. 用途

单行文本输入。

- **用**：任务名称、成员名、金额、时间
- **不要用**：多行内容（用 TextArea）；选项选择（用 Picker / Radio）；布尔值（用 Switch）

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 字段标签 | 必有 | 常驻在输入框上方，`type.footnote`，用 `text.secondary` |
| 容器 | 必有 | 固定高度 46 |
| 前缀 | 可选 | 图标 17，或文字（货币符号），色 `text.tertiary` |
| 输入区 | 必有 | `type.body`（17），占位符 `text.tertiary` |
| 后缀 | 可选 | **最多一个**：单位 / 清除 / 显隐 / 计数 / 下拉 |
| 辅助文案 | 条件 | 错误时必有；常态可选。`type.footnote` |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 高度 | **46**（固定，所有变体一致） |
| 圆角 | `radius.md` 14 |
| 水平内距 | 12 |
| 前缀与输入区间距 | `space.3` 8 |
| 后缀与输入区间距 | `space.3` 8 |
| 标签与容器间距 | `space.2` 4 |
| 辅助文案与容器间距 | `space.2` 4 |
| 最小宽度 | 190 |

### 4. 变体

| 变体 | 背景 | 描边 | 用在哪 |
| --- | --- | --- | --- |
| `inset`（默认） | `fill.field` | 无 | 表单内 |
| `outline` | 透明 | `border.hairline-strong` | 白底卡片上，视觉更轻 |
| `glass` | `surface.glass-strong` | `border.hairline` | 浮在图片或内容之上 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 默认 | 见变体表，标签 `text.secondary` | — |
| 聚焦 | 描边换 `text.brand` 1.5pt + `text.brand` 18% 光环；标签可高亮 | `motion.duration.fast` 160ms |
| 错误 | 描边换 `status.danger`，下方辅助文案用 `status.danger` | 同聚焦 |
| 禁用 | 整体 40%，不允许聚焦 | 无 |
| 只读 | 背景用 `surface.card-sunken`，文字用 `text.secondary`，可选中不可编辑 | 无 |

### 6. 布局

- 表单里字段纵向排列，间距 `space.5`（16）
- 同一行最多两个字段，此时间距 `space.4`（12）
- 字段容器**默认全宽**，只有同一行两个字段时才各占一半

### 7. 内容

- 标签 2–8 个汉字，**必填，不允许只用占位符当标签**
- 占位符写示例而不是重复标签：标签"任务名称"，占位符"例如：整理储物间"
- 错误文案一句话说清"哪里错了 + 怎么改"："名称已被占用，换一个试试"
- 字数计数显示 `当前/上限`，接近上限时（≥90%）换 `status.warning`

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击容器任意位置 | 聚焦输入区 |
| 聚焦 | 键盘弹出，页面滚动避让，字段保持可见 |
| 输入 | 实时校验只做格式级（数字、邮箱）；内容级校验失焦后再做 |
| 清除按钮 | 清空并保持聚焦 |
| 显隐切换 | 明文/密文切换，图标同步换，**保持光标位置** |
| 回车 | 提交并收起键盘；多字段表单里跳到下一字段 |
| 失焦 | 触发完整校验 |

### 9. 动效

聚焦描边与光环 `motion.duration.fast` 160ms 线性；错误文案出现 160ms 淡入 + 4pt 下移。

### 10. 无障碍

- 字段标签与输入区必须关联，读屏先读标签再读内容
- 错误态读"任务名称，错误，名称已被占用"
- 后缀按钮各自有标签："清除内容"、"显示密码"、"选择单位"
- 输入字号不小于 16（避免 iOS 自动缩放），随动态字体放大时容器高度**同步增高，不裁切**
- 聚焦光环对比度 ≥ 3:1

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 键盘 | 系统键盘 + 安全区避让 | `WindowInsets.ime` 避让 |
| 回车键 | `.submitLabel(.next/.done)` | `ImeAction.Next/Done` |
| 焦点 | `@FocusState` | `FocusRequester` |

**实现注意**：高度固定 46，**不要给输入框容器设 `flex: 1` / `Modifier.weight()`**。
在纵向堆叠里 `flex-basis` 会归零，高度跟着内容变，同一组表单会出现三种高度。

### 12. 验收清单

- [ ] 所有变体、所有状态的容器高度都是 46，误差 ≤ 1pt
- [ ] 标签常驻，没有任何一个样例用占位符代替标签
- [ ] 后缀最多一个，不存在"清除 + 计数"同时出现
- [ ] 错误态有描边变化**且**有文字说明，两个都有
- [ ] 聚焦时光环可见，且字段不被键盘遮挡
- [ ] 输入字号 ≥ 16，动态字体放大后不裁切
- [ ] 读屏先读标签、再读内容、错误时读错误

# 04 · SearchField

**视觉参考**：画廊 04 ｜ **优先级** P0

### 1. 用途

在一个已知集合里查找。**搜索的对象是已知的，筛选的对象是未知的**——这是它和 Chip 的分界。

- **用**：在任务、成员、历史记录里按关键词查找
- **不要用**：几个固定选项之间切换（用 `WDSegmentedControl` 或 `WDChip`）；跳转到别的页面

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 容器 | 必有 | 胶囊底，与输入框同高 |
| 前导图标 | 必有 | 搜索图标 `size.icon.md`，色 `text.tertiary`，位置固定不随状态变动 |
| 输入区 | 必有 | `type.body` 17 |
| 清除按钮 | 条件 | 有值时出现，清空内容但保持聚焦 |
| 取消按钮 | 条件 | 聚焦时出现在**容器外**右侧，不挤占容器内空间 |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 高度 | **46**（与 `WDTextField` 一致，同一页面里两者高度必须相同） |
| 圆角 | `radius.full` |
| 水平内距 | 12 |
| 前导图标与输入区间距 | `space.3` 8 |
| 容器与取消按钮间距 | `space.4` 12 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 标准 | 空态 → 有值 → 聚焦三态 |
| 带取消 | 聚焦时展开取消按钮；不聚焦时不占位 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 空态（未聚焦） | 容器底 `surface.card`，占位符 `text.tertiary` | — |
| 聚焦 | 描边换 `text.brand` 1.5pt + 18% 光环；取消按钮展开 | 160ms |
| 有值 | 右侧出现清除按钮 | 160ms 淡入 |
| 无结果 | 容器保持正常；下方换成 `WDEmptyState` | — |
| 禁用 | 整体 40% | 无 |

### 6. 布局

- 位于页头或列表上方，左右边距 `space.5`（16）
- 与下方内容的间距 `space.4`（12）
- 聚焦展开取消按钮时，**容器宽度收窄，不是整体右移**——列表内容位置保持不动

### 7. 内容

- 占位符写清搜索范围：「搜索任务或成员」，不要只写「搜索」
- 输入 1 个字符即可开始搜，不需要最少字符数
- 无结果文案要给出下一步：「没找到"储物间"，换个词试试」

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 聚焦 | 键盘弹出，取消按钮展开 |
| 输入 | 300ms 防抖后过滤，输入过程中不阻塞 |
| 点击清除 | 清空内容，保持聚焦与取消按钮展开 |
| 点击取消 | 清空内容、收起键盘、取消按钮收回 |
| 回车 | 收起键盘，保留结果 |
| 结果更新 | 通过 `aria-live` 播报「找到 3 项」 |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 取消按钮展开 | `motion.duration.fast` 160ms，宽度与透明度同步 |
| 清除按钮出现 | `motion.duration.fast` 160ms 淡入 |
| 结果刷新 | 不做整列表动画，避免输入时闪烁 |

### 10. 无障碍

- 角色为 `searchbox`，朗读文本包含搜索范围
- 清除按钮标签「清除搜索内容」，取消按钮标签「取消搜索」
- 结果数量变化用 `aria-live="polite"` 播报，**不要播报每次按键**
- 前导图标标记为装饰
- 触控热区 ≥ 44×44；输入字号 ≥ 16

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | 自定义，或 `.searchable` 放在导航栏 | 自定义，或 `SearchBar` |
| 取消按钮 | 默认不显示，聚焦后出现 | 默认显示取消图标 |
| 键盘 | `.submitLabel(.search)` | `ImeAction.Search` |

### 12. 验收清单

- [ ] 前导图标位置在任何状态下都不动
- [ ] 聚焦时容器宽度收窄，下方列表内容不发生位移

- [ ] 无结果时有空状态且给出下一步建议
- [ ] 结果数量用 `aria-live` 播报，不是每次按键都播

# 05 · Switch

**视觉参考**：画廊 05 ｜ **优先级** P0

### 1. 用途

**即时生效**的布尔开关。拨动即写入，没有确认按钮。

- **用**：共享给家人、每日提醒、免打扰
- **不要用**：需要点"保存"才生效的设置（用 `WDCheckbox`）；二选一（用 `WDSegmentedControl` 或 Radio）；会触发不可逆操作的开关

判断标准：如果打开后用户必须再点一次确认，就不该用 Switch。

### 2. 解剖

轨道 + 滑块两段。轨道承担状态色，滑块承担位置。整行可点时，标签在左、开关在右。

### 3. 尺寸

| 档 | 轨道 | 圆角 | 滑块直径 | 行程 |
| --- | --- | --- | --- | --- |
| 标准 | 51×31 | `radius.full` | 27（轨道高 − 4） | 20 |
| 紧凑 | 40×24 | `radius.full` | 20 | 16 |

滑块上下左右各留 2 的内边距。

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 标准 | 只有标签 |
| 带描述 | 标签下方一行 `type.footnote` 用 `text.secondary`，说明开关的后果（"关闭后不再收到推送"） |

描述只在"用户不看清后果就会误操作"时使用，不是默认。

### 5. 状态

| 状态 | 视觉 | 动效 | 触觉 |
| --- | --- | --- | --- |
| 关 | 轨道 `border.hairline-strong`，滑块白 | — | — |
| 开 | 轨道 `gradient.mid`，滑块白 | 轨道 260ms，滑块 300ms | 轻 |
| 按下 | 滑块临时放大到 1.06 | 100ms | — |
| 禁用 | 整体 40%，不响应 | 无 | 无 |

### 6. 布局

- 开关固定在行右侧，与右边缘间距 `space.5`（16）
- 整行可点：点击标签区域同样切换，热区不小于 `size.touch-target-min`
- 与上一行的间距 `space.4`（12）

### 7. 内容

- 标签 4–10 个汉字，动词或名词短语，不用疑问句
- 描述一行，最多 18 个汉字，超过换成两行说明文字而不是截断

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击轨道 | 切换，立即写入 |
| 拖动滑块 | 实时跟随手指，松手按位置吸附到最近的一端 |
| 点击标签区域 | 同点击轨道 |
| 写入失败 | 轨道回弹到原位置 + `WDBanner` 说明原因，**不做静默失败** |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 滑块位移 | `motion.component.switch-knob` 300ms，`cubic-bezier(.2, 1.5, .45, 1)` |
| 轨道变色 | `motion.component.switch-track` 260ms 线性 |
| 按下放大 | `motion.duration.instant` 100ms |

滑块用弹性曲线，轨道用线性——两者时长不同步是刻意的，视觉上滑块"甩"到位、底色随后跟上。

### 10. 无障碍

- 角色为 `switch`，状态为"开"/"关"，读屏读"共享给家人，开，开关"
- 带描述时，描述并入朗读内容
- 触控热区 ≥ 44×44
- 开关状态**不能只靠颜色**表达，滑块位置是主要信号，颜色是辅助
- 禁用态标注为不可用，不可从无障碍树中移除

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | 自定义 `ToggleStyle` | `Switch` + 自定义 `colors` / `thumbContent` |
| 尺寸 | 标准 51×31 | Material 默认较小，需要显式放大到 51×31 |
| 触觉 | `UIImpactFeedbackGenerator(.light)` | `HapticFeedbackType.TextHandleMove` |

### 12. 验收清单

- [ ] 轨道 51×31、滑块 27，行程 20，误差 ≤ 1pt
- [ ] 拖动过程中滑块跟随手指，松手正确吸附
- [ ] 点击标签区域也能切换
- [ ] 切换时有轻触觉
- [ ] 写入失败会回弹并给出说明，不是静默失败
- [ ] 读屏正确朗读"标签 + 开/关"
- [ ] 禁用态仍能被读屏发现
- [ ] 开关状态不依赖颜色单独表达

# 06 · Checkbox

**视觉参考**：画廊 06 ｜ **优先级** P0

### 1. 用途

多选，以及任务清单里的"完成"。

- **用**：多项可同时选中的列表、任务行的完成勾选
- **不要用**：单选项（用 Radio）；即时生效的开关（用 Switch）；筛选标签（用 Chip）

### 2. 解剖

方框 + 勾 + 光晕三段。勾是**描边画出来的**而不是图标，这样才能做描边动画。

| --- | --- |
| 方框 | 26×26，圆角 `radius.checkbox` 9（约 35%，接近 squircle，不用正圆） |
| 勾 | 白色描边 2.2pt，`rotate(42deg)` |

### 3. 尺寸

| 档 | 方框 | 圆角 | 标签 |
| --- | --- | --- | --- |
| 标准 | `size.checkbox` 26 | 9 | `type.subheadline` 15 |
| 紧凑 | 22 | 7 | `type.footnote` 13 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 标准 | 方框 + 标签 |
| 无标签 | 只用于表头全选，必须有独立的无障碍标签 |

### 5. 状态

| 状态 | 视觉 | 动效 | 触觉 |
| --- | --- | --- | --- |
| 未选 | 描边 `border.hairline-strong` 1.5pt，底 `fill.field` | — | — |
| 已选 | 底 `gradient.mid`，无描边，顶部 1pt 内高光，`elevation.brand` 投影 | 勾 260ms 弹出，填充与投影同步 220ms | 轻 |
| 半选 | 同已选底，勾换成 12×2.4 的白色横杠 | 同已选 | 轻 |
| 按下 | 缩放至 `motion.component.checkbox-press`（0.90） | `motion.duration.instant` | 轻 |
| 禁用 | 整体 40%，**保留当前勾选状态** | 无 | 无 |
| 光晕 | 选中瞬间外扩，`brand` 42% → 透明 | `motion.component.checkbox-glow` 400ms | — |

### 6. 布局

- 纵向列表，行间距 `space.4`（12）
- 多列最多两列，列间距 `space.5`（16）
- 任务行内，方框在左，与标题间距 `space.3`（8）

### 7. 内容

- 标签 2–12 个汉字，名词短语或短句

- 任务行标题过长时截断，不换行

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击方框 | 切换，光晕播放一次 |
| 点击标签 | 同方框 |
| 任务行内点击整行 | 切换完成状态 |
| 半选点击 | 变为全选（不做三态循环） |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 勾的描边 | `motion.component.checkbox-draw` 260ms，`cubic-bezier(.2, 1.6, .5, 1)` |
| 填充与投影 | 220ms，同曲线 |
| 光晕扩散 | `motion.component.checkbox-glow` 400ms，只播一次 |
| 按下缩放 | `motion.duration.instant` 100ms |

### 10. 无障碍

- 角色为 `checkbox`，状态为"已选中 / 未选中 / 部分选中"
- 任务行读"整理储物间，未完成，复选框"
- 勾选完成时给出触觉反馈，同时用 `aria-live` 播报"已完成"
- 热区 ≥ 44×44，方框视觉 26
- 选中态不依赖颜色：勾的**形状**是主要信号
- 动态字体放大时方框尺寸不变，只放大标签，行高同步增高

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |

### 12. 验收清单

- [ ] 方框 26×26、圆角 9，误差 ≤ 1pt
- [ ] 勾是描边动画，不是直接出现的图标
- [ ] 选中时有光晕，且只播一次
- [ ] 半选显示横杠而不是勾
- [ ] 禁用态保留原勾选状态，不是清空

# 07 · Radio

**视觉参考**：画廊 07 ｜ **优先级** P1

### 1. 用途

在一组互斥选项里选一个，且**选中即生效**。

- **用**：2–5 个并列选项，且用户需要看到全部选项才能决定（仅自己 / 共享给全家）
- **不要用**：超过 5 个选项（改用 `WDPicker`）；需要点"保存"才生效（改用 `WDCheckbox`）；两个选项且语义相反（改用 `WDSwitch` 或 `WDSegmentedControl`）

### 2. 解剖

圆形底 + 内圆点 + 标签。内圆点是**实心圆**而不是勾，用于和 Checkbox 在形状上区分。

### 3. 尺寸

| 档 | 外圆 | 内圆点 | 标签 |
| --- | --- | --- | --- |
| 标准 | 26 | 12 | `type.subheadline` 15 |
| 紧凑 | 22 | 10 | `type.footnote` 13 |

外圆与标签间距 `space.3`（8）；同组内两项间距 `space.4`（12）；热区 ≥ 44×44。

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 标准 | 兜底 |
| 带描述 | 选项下方一行 `type.footnote` 说明差异，仅在选项含义不易区分时使用 |

### 5. 状态

| 状态 | 视觉 | 动效 | 触觉 |
| --- | --- | --- | --- |
| 未选 | 描边 `border.hairline-strong` 1.5pt，底 `fill.field` | — | — |
| 已选 | 底 `gradient.mid`，内圆点白色 `scale(1)` | 内点 200ms 弹出，底 220ms | 轻 |
| 按下 | 缩放至 0.92 | 100ms | 轻 |
| 禁用 | 整体 40%，**保留选中状态** | 无 | 无 |

### 6. 布局

- 纵向排列，组内间距 `space.4`（12）
- 一组最多 5 项，超过改用 `WDPicker`
- 一组内**不换行**：换行会让用户误以为分成两组

### 7. 内容

- 标签 2–10 个汉字，名词短语
- 同组内所有选项的句式保持一致（都是名词，或都是"动词 + 宾语"）
- 不要加"请选择"之类的引导语，选项本身就是引导

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击选项 | 选中该项，同组其余项自动取消 |
| 点击已选项 | **保持选中**，不提供取消（单选组的语义是"必须有一个"） |
| 键盘 | 方向键在组内移动并即时选中，`Tab` 整组进出一个焦点 |

### 9. 动效

内圆点 200ms `cubic-bezier(.2, 1.5, .5, 1)`；外圈底色 220ms 线性；按下缩放 100ms。

### 10. 无障碍

- 每个选项角色为 `radio`，**整组用 `radiogroup` 包裹并给出组标签**（如"可见范围"）
- 读屏朗读"仅自己可见，已选中，单选按钮，第 1 项，共 2 项"
- 方向键切换时即时播报新选项
- 触控热区 ≥ 44×44
- 选中态不依赖颜色：内圆点的**有无**是主要信号

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | 自定义样式 + 分组容器 | `RadioButton` + `selectableGroup()` |
| 键盘 | 系统焦点引擎 | `Modifier.selectableGroup()` 提供方向键 |

### 12. 验收清单

- [ ] 外圆 26、内圆点 12，误差 ≤ 1pt
- [ ] 每个样例都有可见的选中态，浅深两外观都验证过
- [ ] 同组内互斥：选中一项后其余自动取消
- [ ] 点击已选项不会取消选中
- [ ] 一组不超过 5 项、不换行
- [ ] 整组有组标签，读屏能读出"第 n 项，共 m 项"
- [ ] 触控热区 ≥ 44×44

# 08 · Slider

**视觉参考**：画廊 08 ｜ **优先级** P0

### 1. 用途

在连续或较大范围里取值，且**具体数值不如大致位置重要**。

- **用**：完成度、提醒提前量、音量、字号
- **不要用**：需要精确输入数值（用 `WDTextField`）；小范围整数增减（用 `WDStepper`）；二值（用 `WDSwitch`）

### 2. 解剖

轨道 + 已填充段 + 手柄 + 数值标签四段。轨道与填充用同一条 6pt 高的线，靠颜色区分。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 轨道高 | 6 |
| 手柄 | 26（白色 + `elevation.1` + 1pt `border.hairline` 描边） |
| 圆角 | `radius.full` |
| 最小宽度 | 120 |
| 手柄与轨道端点的内缩 | 手柄半径 13，轨道两端各留 13 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 单值 | 默认 |
| 带刻度 | 离散取值，步长按刻度（如提前 1 天 / 2 天 / 1 周），松手吸附 |
| 范围 | 两个手柄，用于区间（如预算下限到上限）。两端手柄不允许交叉，最小间隔 = 1 步长 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 默认 | 轨道 `border.hairline-strong`，填充 `gradient.mid` | — |
| 拖拽 | 手柄放大到 1.15，数值标签跟随手柄移动 | 100ms |
| 聚焦 | 手柄外扩 3pt 光环 | 160ms |
| 禁用 | 整体 45%，手柄变灰，不响应 | 无 |

### 6. 布局

- 轨道上方放标签（如"完成度"），右侧放当前值（"62%"），两者在同一行
- 数值标签用等宽数字，避免拖动时宽度跳动
- 与上下元素间距 `space.4`（12）

### 7. 内容

- 数值格式固定：百分比带 `%`，时间带单位（"1 天前"），金额带货币符号
- 拖动过程中实时更新数值，**松手才算一次有效变更**
- 离散档位时显示档位名称而不是原始数字

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 拖动手柄 | 实时跟随，数值同步更新 |
| 点击轨道 | 跳到该位置并触发一次变更 |
| 拖到端点 | 到边界后不再移动，手柄给出阻力感 |
| 键盘 | 方向键 ±1 步长，`Home` / `End` 跳到两端 |
| 松手 | 触发一次 `onChange`，带轻触觉 |

### 9. 动效

手柄放大与数值更新 100ms（跟随手指，不能有延迟）；聚焦光环 160ms；
点击轨道跳到位置时 200ms 过渡（不是瞬移）。

### 10. 无障碍

- 角色为 `slider`，必须提供 `value` / `min` / `max`，可选 `step`
- 读屏朗读"完成度，62%，可调整"
- 支持读屏的增减手势（iOS 上滑下滑调整）
- 触控热区高度 ≥ 44（轨道视觉 6，热区向上向下各扩 19）
- 数值变化不做 `aria-live` 实时播报，只在松手后播报一次

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | 自定义，或 `Slider` + 自定义轨道 | `Slider` + `SliderDefaults.colors` |
| 触觉 | 到端点时 `UIImpactFeedbackGenerator(.rigid)` | `HapticFeedbackType.LongPress` |

### 12. 验收清单

- [ ] 轨道高 6、手柄 26，误差 ≤ 1pt
- [ ] 拖动实时跟随，无可感知延迟
- [ ] 数值标签用等宽数字，更新时不抖动
- [ ] 点击轨道能跳到该位置，且有 200ms 过渡
- [ ] 到端点后手柄不再移动
- [ ] 松手才触发一次变更，拖动过程中不触发
- [ ] 读屏能读出当前值与可调整状态
- [ ] 热区高度 ≥ 44

# 09 · Stepper

**视觉参考**：画廊 09 ｜ **优先级** P1

### 1. 用途

小范围整数增减，取值精度比 Slider 高、输入成本比 TextField 低。

- **用**：数量（买几个）、人数、重复次数
- **不要用**：范围超过 20（用 `WDTextField`）；连续值（用 `WDSlider`）

### 2. 解剖

减号按钮 + 数值 + 加号按钮，包在一个胶囊容器里。数值区不可编辑，避免键盘与步进冲突。

### 3. 尺寸

| 档 | 容器高 | 按钮宽 | 字号 |
| --- | --- | --- | --- |
| 标准 | 36 | 40 | 14 |
| 紧凑 | 30 | 32 | 13 |

容器圆角 `radius.full`；数值区最小宽 26，居中。

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 标准 | 用于表单 |
| 紧凑 | 用于列表行内 |
| 带单位 | 数值后加单位（如"3 个"），单位用 `text.secondary` |

### 5. 状态

| 状态 | 视觉 |
| --- | --- |
| 默认 | 容器 `surface.glass-strong` + `border.hairline`；按钮符号 `text.brand` |
| 按下 | 按钮区域 `fill.pressed`，`motion.duration.instant` |
| 到下限 | 减号按钮禁用（40%），加号正常 |
| 到上限 | 加号按钮禁用，减号正常 |
| 整体禁用 | 全部 45% |

### 6. 布局

- 表单里右对齐，与字段标签在同一行
- 与相邻元素间距 `space.4`（12）
- 容器宽度随内容变化，不拉伸

### 7. 内容

- 数值用等宽数字，位数变化时容器宽度**可以**变化，但要给出 100ms 宽度过渡避免抖动
- 到边界时不做提示文字，按钮置灰即可

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击 + / − | 步进 1，带轻触觉 |
| 长按 + / − | 连续步进，先慢后快 |
| 到达边界 | 按钮禁用，继续点击无效果、无触觉 |
| 键盘 | 方向键上下调整 |

### 9. 动效

数值切换 100ms 淡入（不是滑动，滑动会让连续步进时的数字糊成一片）；按钮按下 100ms；容器宽度变化 100ms。

### 10. 无障碍

- 容器角色为 `adjustable`（iOS）/ `progressBar`-like 可调整控件（Android）
- 读屏朗读"数量，3，可调整"，并支持直接的增减手势
- **不要**把两个按钮分别独立暴露成焦点——会让读屏用户按多次才能改一个值
- 每个按钮仍需独立的无障碍标签"减少数量" / "增加数量"，供直接点击
- 触控热区 ≥ 44×44（标准档按钮宽 40，热区向外扩 2）

### 11. 平台差异

iOS 无系统 Stepper，需自定义；
Android 无对应控件，用 `Surface` + 两个 `IconButton` 实现。
两端都必须自行保证连续步进的节奏一致。

### 12. 验收清单

- [ ] 标准档容器高 36、按钮宽 40，误差 ≤ 1pt
- [ ] 到上限时加号禁用、到下限时减号禁用，另一个仍可用
- [ ] 长按能连续步进，先慢后快
- [ ] 数值用等宽数字，位数变化时不抖动
- [ ] 读屏是"一个可调整控件"，不是两个独立按钮
- [ ] 触控热区 ≥ 44×44

# 10 · Chip

**视觉参考**：画廊 10 ｜ **优先级** P0

### 1. 用途

轻量标记与筛选。三种用法语义不同，**不要混在同一行**。

| 用法 | 语义 | 可点 |
| --- | --- | --- |
| 展示 | 只说明属性（"全家共享"） | 否 |
| 可选 | 过滤条件（"已完成"） | 是，切换选中 |
| 可删除 | 已应用的筛选值（"妈妈 ×"） | 是，点击删除 |

### 2. 解剖

容器 + 可选前导图标 + 文字 + 可选删除键。删除键的热区 28×28，不与容器重叠。

### 3. 尺寸

| 档 | 高度 | 水平内距 | 字号 | 圆角 |
| --- | --- | --- | --- | --- |
| 标准 | 32 | 12（带图标时左 10 右 14） | 13 | `radius.full` |
| 紧凑 | 28 | 10 | 12 | `radius.full` |

### 4. 变体

| 变体 | 背景 | 文字 | 描边 |
| --- | --- | --- | --- |
| 展示 | `surface.card` | `text.secondary` | `border.hairline` |
| 可选 · 未选 | `surface.card` | `text.secondary` | `border.hairline` |
| 可选 · 已选 | `gradient.surface` | `text.on-soft` | `text.brand` 42% |
| 可删除 | `surface.card` | `text.secondary` | `border.hairline` |
| 带图标 | 同上，图标 15 | — | — |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 默认 | 见变体表 | — |
| 按下 | 缩放至 0.96 | 100ms |
| 选中 | 换 surface 底 + 深色文字 | 200ms 底色与文字同步 |
| 禁用 | 40% | 无 |

### 6. 布局

- 横向排列，间距 `space.3`（8）
- **允许横向滚动**（横向溢出不换行）——换行会让筛选区高度跳动
- 与下方内容间距 `space.4`（12）
- 同一行内所有 Chip 高度一致

### 7. 内容

- 文字 2–6 个汉字
- 可删除芯片的内容必须是**具体值**（"妈妈"），不是类别（"成员"）
- 展示型芯片不要超过 3 个，超出的信息用文字表达

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击可选芯片 | 切换选中，立即过滤 |
| 点击删除键 | 只删除该芯片，不触发整行点击 |
| 长按可删除芯片 | 不做额外菜单，避免和拖拽排序冲突 |
| 横向拖动 | 滚动，不触发放大或删除 |

### 9. 动效

选中切换 200ms；删除时 240ms 淡出 + 宽度收缩（同排后续芯片左移）；
新芯片插入时 240ms 淡入 + 右移，错峰 20ms。

### 10. 无障碍

- 可选芯片角色为 `checkbox`（多选）或 `radio`（单选），朗读"已完成，已选中"
- 删除键标签"移除筛选：妈妈"
- 展示型芯片不作为焦点元素
- 触控热区：可选 32 高需补到 44；删除键 28×28 需补到 44
- 选中态不依赖颜色：已选芯片同时有底色变化和文字加粗

### 11. 平台差异

iOS 用 `Chip` 自定义（系统无对应控件）；
Android 用 `FilterChip` / `InputChip` / `AssistChip` 三选一，不要都用同一个。

### 12. 验收清单

- [ ] 标准高度 32、紧凑高度 28，误差 ≤ 1pt
- [ ] 三种用法没有混在同一行
- [ ] 删除键有独立的触控热区，点击不会触发整行
- [ ] 已选态同时有底色与字重变化，不只靠颜色
- [ ] 横向溢出时滚动而不是换行
- [ ] 删除动画后同排芯片左移，无跳变
- [ ] 触控热区 ≥ 44×44

# 11 · Badge

**视觉参考**：画廊 11 ｜ **优先级** P0

### 1. 用途

状态与计数的紧凑表达。**徽标不单独承载信息**，必须依附在主体上。

- **用**：任务状态（已完成 / 已逾期）、未读数、在线点
- **不要用**：作为主要信息的载体（状态应当同时有文字）；装饰性点缀

### 2. 解剖

胶囊底 + 图标（可选）+ 文字。计数型是纯数字，叠在宿主的右上角。

### 3. 尺寸

| 形态 | 尺寸 | 字号 | 圆角 |
| --- | --- | --- | --- |
| 状态胶囊 | 高 24，水平内距 10 | 11 · 600 | `radius.full` |
| 圆点 | 7×7 | — | `radius.full` |
| 计数 | 高 20，最小宽 20 | 11 · 600 · 等宽 | `radius.full` |

计数徽标相对宿主右上角偏移 -4 / -4，白色描边 2 与宿主分隔。

### 4. 变体

| 变体 | 背景 | 文字 | 用于 |
| --- | --- | --- | --- |
| `shared` | `gradient.surface` | `text.on-soft` | 共享状态 |
| `schedule` | `gradient.mid` | 白 | 时间点 |
| `pending` | `surface.glass-strong` | `text.brand` | 进行中 |
| `success` | `status-soft.success` | `status.success` | 已完成 |
| `warning` | `status-soft.warning` | `status.warning` | 即将到期 |
| `danger` | `status-soft.danger` | `status.danger` | 已逾期 |

### 5. 状态

徽标本身是展示元素，没有按下态。计数为 0 时**整体隐藏**，不留空位。
计数超过 99 显示 `99+`。

### 6. 布局

- 徽标与主体文字间距 `space.2`（4）；一行内最多 2 个徽标
- 计数徽标随宿主一起移动，不参与宿主内部布局
- 状态胶囊在列表行内右对齐

### 7. 内容

- 状态胶囊文字 ≤ 4 个汉字，用名词短语（"已逾期"而不是"这个任务已经超过截止时间了"）
- 徽标文字不换行、不截断；放不下就说明这一处置放的信息过多

### 8. 交互

徽标不可点。宿主可点时，点击宿主触发宿主的动作，不单独触发徽标。

### 9. 动效

计数变化 160ms 淡入缩放（1 → 1.08 → 1）；状态切换 200ms 底色与文字同步过渡。
计数从 0 变 1 时才播放一次，从 1 变 2 只更新数字。

### 10. 无障碍

- 徽标不进入无障碍焦点序列，作为宿主朗读内容的一部分
- 宿主朗读为"提醒，3 条未读"而不是分成两个元素
- 状态胶囊的颜色不是唯一信号：**图标形状必须不同**（对勾 / 三角 / 实心禁止）
- 文字与底色对比度 ≥ 4.5:1

### 11. 平台差异

iOS 用 `Text` + `padding` + `background` 组合；
Android 用 `Badge` / `BadgedBox`，但状态胶囊需要自定义。

### 12. 验收清单

- [ ] 状态胶囊高 24、圆点 7、计数高 20，误差 ≤ 1pt
- [ ] 计数为 0 时完全隐藏，不留占位
- [ ] 计数超 99 显示 99+，宽度能容纳三个字符
- [ ] 计数徽标有白色描边，与宿主图标能分开
- [ ] 六种状态中，除颜色外**图标形状**也各不相同
- [ ] 读屏作为宿主的一部分朗读，不是独立元素

# 12 · Avatar

**视觉参考**：画廊 12 ｜ **优先级** P0

### 1. 用途

代表一个人。在家庭协作场景里，头像是"这是谁的"最省空间的答案。

- **用**：成员标识、任务归属、评论作者
- **不要用**：代表团队或组织（用 Icon + 文字）；纯装饰

### 2. 解剖

圆形底 + 内容（首字 / 图标 / 照片）+ 可选在线点。

### 3. 尺寸

| 档 | 直径 | 首字号 | 用在哪 |
| --- | --- | --- | --- |
| `xs` | `size.avatar.xs` 20 | 9 | 堆叠溢出、紧凑行 |
| `sm` | 28 | 11 | 列表行 |
| `md` | 32 | 12 | 列表行（默认） |
| `lg` | 40 | 14 | 详情页 |
| `xl` | 56 | 18 | 成员资料、空状态 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 文字 | 取名字首字，底色按成员固定分配（四档之一） |
| 图标 | 无姓名时用 `person` 占位 |
| 照片 | 有头像时用照片，圆形裁切，2pt 描边与背景分隔 |
| 在线 | 右下角 10×10 状态点，白描边 2 |

### 5. 状态

| 状态 | 视觉 |
| --- | --- |
| 在线 | 状态点 `status.success` |
| 离线 | 无状态点（**不用灰色点**，避免和在线点混淆） |
| 已停用成员 | 头像整体 50% 并去饱和 |

### 6. 布局

- 与右侧文字间距 `space.4`（12）
- 列表行内头像与行边缘间距 `space.5`（16）
- 头像永远垂直居中于所在行

### 7. 内容

- 首字取名字第一个字符；英文名取首字母大写
- **同一个人的配色在任何页面都必须一致**——按成员 ID 固定，不按出现顺序分配
- 照片缺失时不显示破图，退回文字头像

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击（成员资料入口） | 打开该成员的资料页 |
| 点击（仅标识） | 不响应，无按下反馈 |
| 长按 | 显示成员名提示（仅紧凑列表里姓名被隐藏时） |

### 9. 动效

头像不做动画。照片加载完成用 160ms 淡入（不用缩放，避免列表滚动时抖动）。

### 10. 无障碍

- 朗读成员名，如"妈妈"；不朗读"头像"或首字
- 首字 / 图标标记为装饰
- 在线状态并入朗读："妈妈，在线"
- 触控热区 ≥ 44×44（`sm` 及以下需向外扩热区）

### 11. 平台差异

iOS 用 `Image` + `.clipShape(Circle())`；Android 用 `Image` + `Modifier.clip(CircleShape)`。
两者对照片的裁切重心默认居中，人脸偏移时需要用焦点参数修正。

### 12. 验收清单

- [ ] 五档直径 20 / 28 / 32 / 40 / 56，误差 ≤ 1pt
- [ ] 同一成员在不同页面的头像配色一致
- [ ] 无照片时退回文字头像，不出现破图
- [ ] 在线点 10×10 且有 2pt 白描边
- [ ] 离线状态不显示灰点
- [ ] 读屏朗读成员名而不是首字
- [ ] 浅深两外观下头像与背景都能分辨

# 13 · AvatarStack

**视觉参考**：画廊 13 ｜ **优先级** P0

### 1. 用途

一眼看出"有多少人参与"。用于卡片头部、任务归属、共享状态。

- **用**：成员数 2 人及以上
- **不要用**：1 个人（直接用 `WDAvatar`）；需要精确知道每个人是谁（用完整列表）

### 2. 解剖

最多 4 个头像 + 溢出计数。溢出项显示 `+n`，底色用 `surface.glass-strong`。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 头像档位 | `sm` 28 或 `md` 32 |
| 重叠量 | 直径的 30%（28 → 8，32 → 9） |
| 描边 | 2pt，颜色取所在容器底色（卡片或画布） |
| 最大显示数 | 4 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 标准 | 最多 4 个 + 溢出计数 |
| 无溢出 | 总数 ≤ 4 时不显示 `+n` |

### 5. 状态

堆叠本身无状态。成员变动时（新增/离开）用 240ms 淡入淡出，不重排已有位置。

### 6. 布局

- 与右侧文字间距 `space.3`（8）
- 与其他元素竞争空间时，**优先压缩堆叠**（减少显示数量），而不是压缩文字
- 堆叠总宽 = 直径 + (显示数 − 1) × (直径 − 重叠量)

### 7. 内容

- `+n` 中的 n = 总人数 − 已显示数
- 少于 2 人不使用堆叠
- 溢出项用 `text.secondary` 而不是某个成员的配色

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击堆叠 | 展开完整成员列表（用 `WDBottomSheet`） |
| 点击单个头像 | 打开该成员资料 |
| 点击 `+n` | 同点击堆叠 |

### 9. 动效

展开时成员逐个进入，错峰 `motion.component.list-stagger`（20ms），240ms `motion.spring.gentle`。

### 10. 无障碍

- 作为**一个**元素朗读："家庭成员 6 人：我、妈妈、爸爸、妹妹，另有 2 人"
- 不逐个朗读每个头像，否则读屏用户要听 6 遍才能往下走
- 触控热区 ≥ 44×44（堆叠整体）

### 11. 平台差异

两端都需自定义。注意 iOS 的 `HStack` 负间距与 Android 的 `Row` + `offset` 在重叠处描边的绘制顺序，
必须让**右侧头像压在左侧之上**，否则描边会被盖住。

### 12. 验收清单

- [ ] 重叠量为直径的 30%，误差 ≤ 1pt
- [ ] 最多显示 4 个，超出显示 `+n`，n 计算正确
- [ ] 右侧头像压在左侧之上，描边不被遮挡
- [ ] 少于 2 人不显示堆叠
- [ ] 空间不足时优先减少显示数量，不压缩文字
- [ ] 读屏作为单个元素朗读，包含人数与姓名
- [ ] 触控热区 ≥ 44×44

# 14 · Divider

**视觉参考**：画廊 14 ｜ **优先级** P1

### 1. 用途

分隔。**这是最后手段**——能用间距表达的，不要画线。

- **用**：列表行之间、两个语义不同的区块之间
- **不要用**：卡片与卡片之间（用 `space.4` 间距）；分组标题与内容之间（用间距）；装饰性分隔

### 2. 解剖

一条 1pt 的线，无圆角。

### 3. 尺寸

| 变体 | 起点 | 终点 |
| --- | --- | --- |
| 全宽 | 容器左边缘 | 容器右边缘 |
| 内缩 | 文本区起始（16 + 34 + 12 = 62） | 容器右边缘 |

### 4. 变体

全宽 / 内缩两种。列表行之间用内缩，卡片内部整体分区用全宽。

### 5. 状态

无状态。颜色固定 `border.hairline`，不随选中或按下变化。

### 6. 布局

- 列表内：行与行之间自动绘制，**末行不画**
- 卡片内：与上下内容各留 `space.4`（12）间距
- 不要连续画两条线（中间没有内容时说明分组设计有问题）

### 7. 内容

分割线不带文字。需要标签的分隔请用分组标题（`WDListSection`）。

### 8. 交互

不可交互，不进入无障碍树。

### 9. 动效

无。

### 10. 无障碍

不进入无障碍树；分组语义由 `WDListSection` 的标题承担，不由分割线承担。

### 11. 平台差异

iOS 的 `List` 自带分隔线并处理内缩，用自定义容器时需手动画；
Android 用 `HorizontalDivider`，注意末行不画的逻辑要自己处理。

### 12. 验收清单

- [ ] 线宽 1pt，颜色 `border.hairline`
- [ ] 内缩起点的 62 与列表行文本区对齐
- [ ] 列表末行不画分隔线
- [ ] 没有任何一处用分割线代替了本可以用间距表达的分组
- [ ] 不进入无障碍树

# 15 · ProgressBar

**视觉参考**：画廊 15 ｜ **优先级** P0

### 1. 用途

线性进度。任务完成度、上传下载、多步骤流程。

- **用**：有一个明确的总量，进度可以量化
- **不要用**：等待时间未知且没有总量（用不确定态或 Skeleton）；强调单一指标（用 `WDProgressRing`）

### 2. 解剖

轨道 + 填充两段。轨道用浅色，填充用中蓝，两者颜色差是唯一的进度信号。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 高度 | 6 |
| 圆角 | `radius.full` |
| 最小宽度 | 100 |
| 分段模式的段间距 | 2 |

### 4. 变体

| 变体 | 说明 | 用在哪 |
| --- | --- | --- |
| 确定 | 按百分比填充 | 上传、下载 |
| 分段 | 用 n 段表示"n 项里完成几项" | 家务完成度（比百分比直观） |
| 不确定 | 一段来回移动，不表达进度 | 等待时间未知 |
| 完成 | 填满 + `status.success` 底色 | 流程结束 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 进行中 | 填充 `gradient.mid` | 数值变化 240ms 线性 |
| 完成 | 填充换 `status.success` | 到达 100% 时 300ms 过渡 + 一次成功触觉 |
| 不确定 | 一段 35% 宽来回移动 | 1.4s 循环 |
| 禁用 | 整体 45% | 无 |

### 6. 布局

- 轨道上方放说明文字，右侧放数值（"45%"），两者同一行
- 与上下元素间距 `space.4`（12）
- 默认全宽；卡片内跟随卡片内边距
- 多段进度纵向排列，间距 `space.3`（8）

### 7. 内容

- 百分比用等宽数字
- 分段模式显示"3 / 5"而不是"60%"
- 数值不超过 100%，超过时截断并记录错误

### 8. 交互

不可交互。需要用户操作才能推进时，用 `WDButton` 而不是可点进度条。

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 数值变化 | 240ms 线性（不用缓出，缓出会让接近完成时看起来卡住） |
| 首次出现 | `motion.component.progress-easeout` 3200ms 缓出 |
| 不确定态 | 1.4s 循环，`ease-in-out` |

不确定态**超过 1 秒**才显示，避免一闪而过。

### 10. 无障碍

- 角色为 `progressbar`，必须提供 `valuenow` / `valuemin` / `valuemax`
- 朗读"上传进度，45%"
- 不确定态不提供 `valuenow`，朗读"加载中"
- 进度变化不做实时 `aria-live` 播报，只在跨越 25% / 50% / 75% / 100% 时播报
- 填充与轨道的对比度 ≥ 3:1

### 11. 平台差异

iOS 用 `ProgressView(value:)` + 自定义 `tint`；
Android 用 `LinearProgressIndicator(value)` + `trackColor`，不确定态用 `indeterminate = true`。

### 12. 验收清单

- [ ] 高度 6、圆角 `radius.full`
- [ ] 填充与轨道对比度 ≥ 3:1，浅深两外观都验证
- [ ] 数值不超 100%，超出时不出视觉异常
- [ ] 分段模式显示"3 / 5"，段数等于总量
- [ ] 不确定态在 1 秒后才出现
- [ ] 到达 100% 时有成功触觉且只触发一次
- [ ] 读屏能读出当前值与总量

# 16 · ProgressRing

**视觉参考**：画廊 16 ｜ **优先级** P0

### 1. 用途

环形进度。用于**需要强调的单一指标**，因为环比线占用更多视觉重量。

- **用**：一张卡片里的核心指标（本周家务完成度）、连续打卡
- **不要用**：一行里出现 3 个以上（视觉过载）；纯等待（用不确定态）

### 2. 解剖

轨道环 + 进度弧 + 环内内容（数值或图标）。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 直径 | 60（标准）/ 44（紧凑） |
| 线宽 | 6（标准）/ 5（紧凑） |
| 起点 | 12 点方向，顺时针 |
| 环内留白 | 直径 − 2 × 线宽 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 百分比 | 环内显示"60%" |
| 计数 | 环内显示"3/5"，用于离散总量 |
| 完成 | 环色换 `status.success`，环内显示对勾 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 增长 | 弧从 0 长到目标值 | 3200ms 缓出，数字同步递增 |
| 完成 | 环色转 `status.success` | 弹一下 + 成功触觉，只播一次 |
| 停滞 | 环色降饱和到 70% | 无 |

### 6. 布局

- 环内数字用 `type.title2` 等宽
- 与右侧文字间距 `space.5`（16）
- 一张卡最多一个环
- 环与文字垂直居中对齐

### 7. 内容

- 环内数字不超过 4 个字符（"60%"、"3/5"、"完成"）
- 环外必须有说明文字，环本身不解释自己代表什么
- 计数模式的分子不超过分母

### 8. 交互

默认不可交互。需要点击时整块（环 + 文字）作为热区，不要只让环可点。

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 首次增长 | `motion.component.progress-easeout` 3200ms 缓出 |
| 完成反馈 | `motion.spring.bouncy` 一次，配合成功触觉 |
| 数值更新 | 数字 240ms 过渡，与弧同步 |

**不用线性**：线性增长在接近结束时看起来像卡住。

### 10. 无障碍

- 作为整体朗读"本周家务，已完成 3 项，共 5 项，60%"
- 环本身标记为装饰，信息由文字承担
- 旋转的进度弧不触发持续播报，只在完成时播报一次
- 环与轨道对比度 ≥ 3:1；环内数字与环内底色对比度 ≥ 4.5:1

### 11. 平台差异

iOS 用 `Circle().trim(from:to:)` + `.stroke(style:)`；
Android 用 `Canvas` + `drawArc`，或用 `CircularProgressIndicator` 的 `progress` 参数自定义线宽。
两端都要保证线帽是**圆头**（`strokeCap: .round` / `StrokeCap.Round`）。

### 12. 验收清单

- [ ] 直径 60、线宽 6，起点在 12 点方向且顺时针
- [ ] 线帽为圆头
- [ ] 增长用缓出，数字与弧同步，结束不卡顿
- [ ] 完成后环色转成功色并只弹一次
- [ ] 环内数字 ≤ 4 个字符，用等宽数字
- [ ] 环与轨道对比度 ≥ 3:1，环内数字 ≥ 4.5:1
- [ ] 读屏朗读"总量 + 已完成 + 百分比"，不是只读百分比

# 17 · Card

**视觉参考**：画廊 17 ｜ **优先级** P0

### 1. 用途

把一组相关内容圈在一起。**卡片是分组手段，不是装饰**。

- **用**：一组相关的信息、一张图上加一段文字、需要整体可点的内容块
- **不要用**：单个列表项（用 `WDListRow`）；只是为了"看起来有层次"而加卡片；卡片里再套卡片

判断标准：如果去掉卡片边界、改用间距也能读明白，就不要用卡片。

### 2. 解剖

容器 + 内边距 + 内容三段。内容可以是任意组合，但容器本身不带任何内置结构。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 内边距 | `space.5` **16（固定，所有变体一致）** |
| 圆角 | `radius.xl` 24 |
| 卡间距 | `space.4` 12 |
| 分组间距 | `space.7` 24 |
| 最小宽度 | 不设，由父级决定 |

嵌套时内层圆角 = 外层圆角 − 内边距（24 − 16 = 8，即 `radius.xs`）。

### 4. 变体

| 变体 | 背景 | 描边 | 阴影 | 用在哪 |
| --- | --- | --- | --- | --- |
| `elevated`（默认） | `surface.card` | `border.hairline` | `elevation.1` | 主要内容卡片 |
| `glass` | `surface.glass-strong` | `border.hairline` | `elevation.1` + 背景模糊 | **浮在内容或图片之上时** |
| `outline` | 透明 | `border.hairline` | 无 | 密集列表、设置项 |
| `sunken` | `surface.card-sunken` | 无 | 无 | 卡内嵌块、次级信息 |
| `media` | `surface.card` | `border.hairline` | `elevation.1` | 顶部图片 + 文字区 |

**只有 `glass` 带背景模糊**。其余变体一律实底——在同一个圆角上叠"半透明 + 描边 + 内高光 + 背景模糊"，
浏览器在圆角处采样背景会产生一圈重影，这是肉眼可见的瑕疵。

### 5. 状态

| 状态 | 视觉 |
| --- | --- |
| 静态 | 见变体表 |
| 可点 · 按下 | 整卡亮度降到 96%，`motion.duration.instant` |
| 可点 · 禁用 | 整体 40% |

卡片默认**不可点**。只有整卡确实是一个动作时才加按下反馈，且这种情况下不应再在卡内放箭头。

### 6. 布局

- 卡片之间 `space.4`（12），分组之间 `space.7`（24）
- **用间距表达分组，不要用分割线**
- 卡片宽度由父级决定，默认撑满可用宽度
- 卡内元素纵向排列，间距 `space.3`（8）；主标题与副标题间距 `space.1`（2）

### 7. 内容

- 一张卡表达一件事。卡内出现两个不相关的主题就应该拆成两张
- 标题一行，最多 20 个汉字，超出截断
- 正文最多三行，超出截断并在末尾加省略号

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击（可点卡） | 整卡响应，按下时整卡降亮度 |
| 点击（静态卡） | 不响应，也不显示任何按下反馈 |
| 卡内子元素可点 | 子元素优先响应，事件不冒泡到整卡 |

### 9. 动效

卡片本身不做进出动画（避免列表滚动时抖动）。
按下反馈 `motion.duration.instant` 100ms；`media` 变体的图片加载完成用 160ms 淡入，不用缩放。

### 10. 无障碍

- 静态卡不进入无障碍焦点序列，内容逐项朗读
- 可点卡作为整体朗读，角色为 `button`，朗读文本由卡内标题提供
- 卡内不要出现嵌套的可点区域（整卡可点时）
- 文字与卡片底色的对比度 ≥ 4.5:1；`outline` 变体描边与背景对比度 ≥ 3:1

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 圆角 | `RoundedRectangle(cornerRadius:style: .continuous)` 连续曲率 | `RoundedCornerShape`，数值 **+2** 补偿曲率差异 |
| 模糊 | iOS 26 用 `glassEffect`，17–25 用 `.ultraThinMaterial` | Haze 库；降级为 88% 纯色 + 描边 |
| 可点 | `Button { } label: { }` + `.buttonStyle(.plain)` | `Surface(onClick = ...)` |

### 12. 验收清单

- [ ] 所有变体内边距都是 16，误差 ≤ 1pt
- [ ] 只有 `glass` 用了背景模糊，其余变体是实底
- [ ] 卡片圆角处没有可见重影或双层描边
- [ ] 嵌套时内层圆角 = 外层圆角 − 内边距
- [ ] 分组之间用 24pt 间距，没有用分割线代替间距
- [ ] 静态卡没有按下反馈
- [ ] 可点卡内的子元素可点区域不会误触发整卡
- [ ] 深浅两外观下卡片与背景都能分辨（对比度 ≥ 3:1）

# 18 · ListRow

**视觉参考**：画廊 18 ｜ **优先级** P0

### 1. 用途

列表里的一行。承载"一条记录 + 一个动作"。

- **用**：设置项、任务项、成员项、任意可枚举的内容
- **不要用**：一行的内容超过三行文字（改用 `WDListSection` 里的卡片）；需要横向比较多个字段的场合（用 Table）

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 前导 | 可选 | 图标底座 34×34（`radius.sm`）或头像，或勾选框 |
| 文本区 | 必有 | 标题 `type.subheadline`；副标题 `type.caption1` 用 `text.secondary` |
| 尾部 | 可选 | 值文本 / 徽标 / 头像 / 箭头，**最多一个** |
| 分隔线 | 条件 | 从文本区起始内缩，末行不显示 |

### 3. 尺寸

| 行数 | 行高 |
| --- | --- |
| 单行 | 44 |
| 双行 | 60 |
| 三行 | 76 |

水平内距 16（首尾一致）；各段间距 `space.4`（12）；分隔线左内缩 = 16 + 34 + 12 = 62。

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 单行 / 双行 / 三行 | 按内容量选择，不为了"好看"加副标题 |
| 带选择 | 选中时左侧 3pt 品牌色条 + `brand` 8% 透明底 |
| 带勾选 | 前导换成 `WDCheckbox`，任务行形态 |
| 禁用 | 整体 40%，不响应 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 默认 | 透明底 | — |
| 按下 | 整行 `fill.pressed` | `motion.duration.instant` 100ms |
| 选中 | 左侧 3pt 品牌条 + 浅底 | `motion.duration.fast` 160ms |
| 禁用 | 整体 40% | 无 |

### 6. 删除

| 阶段 | 规格 |
| --- | --- |
| 左滑 | 整行左移，右侧露出「删除」，宽 86，底 `gradient.deep`，白色图标 + 文字 |
| 松手 | 位移 < 阈值时吸附回 0，**不删除**；≥ 阈值时直接删除，不再要求二次确认 |
| 删除后 | 底部弹撤销条，停留 5 秒，可一键恢复；超时后真正删除 |
| 无障碍 | 提供"删除"的自定义操作，不要求用户必须会左滑 |
| 撤销 | 恢复整行位置 + 淡入，`motion.duration.fast` |

**不做二次确认弹窗**——撤销条比弹窗少一步，且不会打断连续操作。

### 7. 多选

长按进入多选：顶部显示"已选 n 项"，底部换成「取消 / 删除」工具条，行前导换成勾选框。
批量删除同样给撤销，一次撤销恢复整批。退出多选时清空选择。

### 8. 内容

- 标题一行，最多 20 个汉字，超出截断
- 副标题一行，最多 24 个汉字，超出截断
- 尾部值文本右对齐，数字用等宽
- 末行不画分隔线

### 9. 交互

| 操作 | 结果 |
| --- | --- |
| 点击 | 整行响应；尾部有箭头表示进入下一级 |
| 长按 | 进入多选 |
| 左滑 | 露出删除 |
| 右滑 | 默认不响应；可配置为"标记完成"，但不要和左滑同时存在竞争动作 |

### 10. 无障碍

- 整行作为一个元素朗读："整理储物间，18:00 前，未完成，按钮"
- 前导图标标记为装饰；头像朗读成员名
- 分隔线不进入无障碍树
- 触控热区 = 整行高度，任意档位均 ≥ 44
- 提供"删除"自定义操作，左滑只是快捷方式

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 左滑 | `.swipeActions`，系统提供手势与吸附 | `SwipeToDismissBox`，需要自己实现吸附与阈值 |
| 多选 | `.environment(\.editMode)` 或自定义 | 自定义 `SelectionContainer` |
| 分隔线 | 系统 `List` 自带 | 手动 `Divider`，注意末行不画 |

### 12. 验收清单

- [ ] 三种行数的高度分别为 44 / 60 / 76，误差 ≤ 1pt
- [ ] 分隔线从文本区起始内缩，末行不显示
- [ ] 尾部最多一个元素，不存在"箭头 + 徽标"并存
- [ ] 左滑未达阈值松手会回弹，不删除
- [ ] 删除后出现撤销条，停留 5 秒，能恢复
- [ ] 读屏提供"删除"操作，不强制用户左滑
- [ ] 按住进多选后，退出时选择被清空
- [ ] 动态字体放大后行高同步增高，文字不裁切

# 19 · ListSection

**视觉参考**：画廊 19 ｜ **优先级** P0

### 1. 用途

把列表项分组。**分组的边界靠间距和标题，不靠分割线**。

- **用**：同一页面有多组语义不同的内容（今天 / 本周）
- **不要用**：只有一组内容（直接用 `WDListRow` 列表）；分组内只有一项且不需要标题

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 分组标题 | 必有 | `type.overline` 12 · 500 · 字距 +0.6，色 `text.secondary` |
| 标题右侧动作 | 可选 | 分组级操作（"编辑"/"全部"），`text.brand`，**最多一个** |
| 内容容器 | 必有 | 一个卡片，内部是 `WDListRow` 序列 |
| 页脚 | 可选 | 汇总信息，`type.footnote`，色 `text.secondary` |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 标题与内容间距 | `space.3`（8） |
| 内容与页脚间距 | `space.2`（4） |
| 分组与分组之间 | `space.7`（24） |
| 页面左右边距 | `space.5`（16） |

标题左侧与卡片内文本对齐时额外缩进 `space.1`（2）。

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 标准 | 标题 + 卡片 |
| 带动作 | 标题右侧加一个文字动作 |
| 带页脚 | 卡片下方加一行汇总 |

### 5. 状态

分组本身无状态。空分组**整个隐藏**（连标题一起），不要显示空标题。

### 6. 布局

- 分组纵向排列，间距 24
- 分组内行与行之间由 `WDListRow` 自己处理分隔线
- 同一页面最多 4 个分组，超过时考虑用 Tab 拆分
- 分组标题**左对齐**，与卡片左边缘对齐，不要居中

### 7. 内容

- 标题 ≤ 6 个汉字，用时间或类别名词（"今天"、"本周"、"家庭共享"）
- 标题与页脚不用来放操作说明
- 页脚一行，≤ 20 个汉字，写汇总而不写引导语（"共 2 项，已完成 1 项"而不是"点击查看更多"）

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击标题右侧动作 | 执行分组级操作 |
| 点击标题文字 | 不响应（标题不是按钮） |
| 点击页脚 | 不响应 |

### 9. 动效

无。分组不做进出动画，避免列表滚动时抖动。

### 10. 无障碍

- 分组标题作为 `header` 语义，读屏用户可快速跳转到分组
- 读屏顺序：标题 → 标题右侧动作 → 组内各行 → 页脚
- 页脚作为分组的补充说明朗读
- 分组标题与背景对比度 ≥ 4.5:1

### 11. 平台差异

iOS 用 `Section(header:)` 放进 `List`，或自定义 `LazyVStack` + `pinnedViews`；
Android 用 `stickyHeader` 或直接自定义 `Column`，注意分组之间不要用 `Divider` 代替间距。

### 12. 验收清单

- [ ] 分组之间间距 24，且**没有用分割线**代替间距
- [ ] 标题字号 12、字重 500、字距 +0.6
- [ ] 标题与卡片左边缘对齐
- [ ] 空分组整体隐藏，不出现空标题
- [ ] 标题右侧最多一个动作
- [ ] 页脚只写汇总信息，不写引导语
- [ ] 读屏能把标题识别为分组标题

# 20 · Icon

**视觉参考**：画廊 20 ｜ **优先级** P0

### 1. 用途

表达概念或状态的最小图形单位。**图标不单独承载操作**。

- **用**：配合文字做视觉锚点；需要快速识别的位置（Tab 栏、列表前导）
- **不要用**：单独表达一个动作（必须包在 `WDIconButton` 里）；需要用颜色区分的状态（图标形状本身要能区分）

### 2. 解剖

图标 + 可选底座两段。

| 底座 | 尺寸 | 圆角 | 背景 | 图标色 |
| --- | --- | --- | --- | --- |
| 无 | — | — | — | `currentColor` |
| 浅底座（默认） | 34×34 | `radius.sm` | `gradient.surface` | `text.on-soft` |
| 深底座 | 34×34 | `radius.sm` | `gradient.mid` | 白 |
| 大底座 | 40×40 | `radius.lg` | `gradient.surface` | `text.on-soft` |

### 3. 尺寸

| 档 | 尺寸 | 用在哪 |
| --- | --- | --- |
| `sm` | 16 | 行内文字旁、尾部 |
| `md` | 20 | 表单前缀、列表 |
| `lg` | 24 | 导航栏、Tab 栏、工具栏 |
| `xl` | 28 | 强调、空状态 |

同一层级内不混用档位。描边粗细按尺寸匹配：24pt 图标线宽约 1.8–2。

### 4. 变体

同一语义在两端各有一套：iOS 用 SF Symbols（优先 `.rounded` 变体），Android 用 Material Symbols Rounded。
两端靠**语义名称**对照，不逐像素对齐。

### 5. 状态

图标本身没有状态，状态由容器承担（按钮的按下/禁用、Tab 的选中）。
唯一例外：Tab 栏选中态换 `text.brand` 并把标签加粗，**不换图标形状**。

### 6. 布局

- 图标与文字的间距 `space.3`（8）
- 图标与容器边缘的间距不小于 `space.3`（8）
- 图标在容器内居中，不做基线对齐

### 7. 内容 · 语义对照表

| 语义 | SF Symbols | Material Symbols |
| --- | --- | --- |
| 首页 | `house.fill` | `home` |
| 成员 | `person.2.fill` | `group` |
| 日历 | `calendar` | `calendar_month` |
| 提醒 | `bell.fill` | `notifications` |
| 搜索 | `magnifyingglass` | `search` |
| 设置 | `gearshape.fill` | `settings` |
| 新增 | `plus` | `add` |
| 更多 | `ellipsis` | `more_horiz` |
| 进入 | `chevron.right` | `chevron_right` |
| 完成 | `checkmark.circle.fill` | `check_circle` |
| 删除 | `trash` | `delete` |

新增图标必须同时补齐两端的名称，缺一个视为未完成。

### 8. 交互

图标本身不可点。可点时包在 `WDIconButton` 里，热区 ≥ 44×44。

### 9. 动效

图标不单独做动画。选中态变化用 `motion.duration.fast` 160ms 变色，
不用旋转或缩放——旋转图标会让界面显得廉价。

### 10. 无障碍

- 装饰性图标标记为隐藏，不进入无障碍树
- 作为唯一视觉信息的图标（如状态点）必须有文字或无障标签
- 图标与背景对比度 ≥ 3:1
- 不依赖颜色区分图标含义，形状必须不同

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 图标集 | SF Symbols，优先 `.rounded` | Material Symbols Rounded |
| 尺寸控制 | `.font(.system(size:))` + `.imageScale` | `Icon(painter, Modifier.size())` |
| 多色 | `.symbolRenderingMode(.hierarchical)` | `Icon` 单色，多色需自绘 |

### 12. 验收清单

- [ ] 四个尺寸档位分别为 16 / 20 / 24 / 28，同一层级不混用
- [ ] 两端语义名称对照表已补齐，没有只做一端的图标
- [ ] 图标底座尺寸 34×34、圆角 `radius.sm`
- [ ] 没有任何一个可点图标游离在按钮之外
- [ ] 装饰图标不进入无障碍树
- [ ] Tab 选中态只换色和字重，不换图标形状
- [ ] 图标与背景对比度 ≥ 3:1

# 21 · SegmentedControl

**视觉参考**：待补 ｜ **优先级** P0

### 1. 用途

2–5 个互斥选项之间切换，**切换即时生效，内容在同一页面内替换**。

- **用**：同一份数据的不同视图（今天 / 本周 / 全部）
- **不要用**：超过 5 项（用 `WDPicker`）；需要点保存才生效（用 `WDRadio`）；跳转到不同页面（用 `WDTabBar`）

分界线：切完之后**页面标题不变**，只是内容换了，就是 SegmentedControl。

### 2. 解剖

| 段 | 说明 |
| --- | --- |
| 容器 | 胶囊，内边距 3，底 `surface.card` 或玻璃 |
| 选中指示块 | 圆角胶囊，随选中项滑动；底色 `surface.card-solid` + `elevation.1` |
| 各段 | 等宽，文字居中，竖向居中 |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 容器高 | 38（内容 32 + 上下内边距 3） |
| 单段最小宽 | 56 |
| 段水平内距 | 14 |
| 字号 | 13 · 500（选中 600） |
| 圆角 | `radius.full` |

### 4. 变体

| 变体 | 容器底 | 用在哪 |
| --- | --- | --- |
| 玻璃 | `surface.glass` + `border.hairline` | 浮在内容或图片之上 |
| 实底 | `fill.field` | 页面内常规位置 |

2–5 段均可；段宽等分，不按文字长度分配。

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 未选 | 文字 `text.secondary` | — |
| 选中 | 指示块滑到该段；文字 `text.primary` 600 | 指示块 280ms `motion.spring.snappy`；文字 160ms |
| 按下 | 该段文字临时降到 70% 不透明度 | 100ms |
| 禁用 | 整体 40%，不响应 | 无 |

### 6. 布局

- 默认**内容宽度**（按段数与最小宽撑开）；需要撑满时用全宽并在两端留 `space.5`
- 与下方内容间距 `space.5`（16）
- 不与返回按钮、标题放在同一行

### 7. 内容

- 每段 2–4 个汉字，等长最佳
- 段文字不用标点、不用换行
- 同一组内句式一致（都是名词，或都是时间范围）

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击未选项 | 切换，指示块滑动，内容替换 |
| 点击已选项 | **不重复触发**，不重置内容滚动位置 |
| 横向拖动指示块 | 支持时实时跟随，松手吸附；不支持时只响应点击 |
| 键盘 | 方向键在段之间移动并即时切换 |

内容切换时**保留各视图自己的滚动位置**，不共用。

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 指示块滑动 | 280ms，`motion.spring.snappy` |
| 文字颜色与字重 | `motion.duration.fast` 160ms |
| 内容替换 | 不做交叉淡化——同页面切换用直接替换，避免重影 |

### 10. 无障碍

- 容器角色为 `tablist`，每段角色为 `tab`，并标注"第 n 项，共 m 项"
- 选中项标注 `aria-selected="true"`
- 内容区角色为 `tabpanel`，与对应 tab 关联
- 触控热区：单段高度 38 需补到 44（纵向向外扩 3）
- 选中态不依赖颜色：指示块的位置与文字字重同时变化

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | 自定义（系统 `Picker(.segmented)` 外观不可控） | `SingleChoiceSegmentedButtonRow` |
| 指示块 | `matchedGeometryEffect` | `Modifier.offset` + `animateDpAsState` |

### 12. 验收清单

- [ ] 容器高 38、单段最小宽 56，误差 ≤ 1pt
- [ ] 段宽等分，不按文字长度分配
- [ ] 指示块滑动用弹簧曲线，280ms 内到位
- [ ] 点击已选项不重复触发，滚动位置不重置
- [ ] 切换视图时各视图保持各自滚动位置
- [ ] 触控热区 ≥ 44
- [ ] 读屏能读出"第 n 项，共 m 项"与选中状态

# 22 · Picker

**视觉参考**：待补 ｜ **优先级** P1

### 1. 用途

从 **5 个以上**的选项里选一个。

- **用**：分类、成员、频率、单位等选项较多的单选
- **不要用**：≤ 5 项（用 `WDSegmentedControl` 或 `WDRadio`）；多选（用 `WDCheckbox` 列表）；日期（用 `WDDatePicker`）

### 2. 解剖

| 段 | 说明 |
| --- | --- |
| 触发入口 | 一行，左侧标签，右侧当前值 + `chevron-down` |
| 弹出层 | 选项列表，可滚动，当前项打勾 |
| 遮罩 | 点击关闭（不提交） |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 触发入口高 | 44 |
| 选项行高 | 44 |
| 弹出层最小宽 | 180，最大宽 = 屏幕宽 − 32 |
| 圆角 | `radius.md` 14 |
| 选项水平内距 | 14 |

### 4. 变体

| 形态 | 说明 | 用在哪 |
| --- | --- | --- |
| 菜单 | 从触发入口下方展开 | 选项 ≤ 10 |
| 滚轮 | 底部弹出滚轮 | 选项多且需要快速滚动 |
| 内联 | 直接平铺在页面里 | 选项 ≤ 8 且表单需要一眼看全 |

同一表单里只用一种形态。

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 默认 | 值为 `text.primary`，箭头 `text.tertiary` | — |
| 未选 | 显示"请选择"，色 `text.tertiary` | — |
| 展开 | 弹出层淡入 + 从触发入口方向缩放 0.96 → 1 | 240ms `motion.spring.gentle` |
| 已选 | 当前项左侧打勾，其余等高占位 | — |
| 禁用 | 整体 40% | 无 |

### 6. 布局

- 触发入口在表单里右对齐，与标签同一行
- 弹出层从触发入口对齐展开，空间不足时自动翻转方向
- 弹出层与触发入口间距 `space.2`（4）

### 7. 内容

- 选项文字 2–8 个汉字，左对齐
- 支持分组标题（`type.overline`），分组内选项缩进 `space.5`
- 当前值超长时截断，不换行

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击触发入口 | 展开 |
| 点击选项 | 选中、关闭、触发一次 `onChange` |
| 点击遮罩 / `Esc` | 关闭，不改变当前值 |
| 展开后滚动 | 选项列表内部滚动，遮罩不滚动 |

展开时**把当前选项滚到可视区中间**，不要让用户自己找。

### 9. 动效

弹出层 240ms `motion.spring.gentle`，从触发入口方向缩放入场；关闭 160ms 淡出。
勾选标记出现 160ms，不做位移。

### 10. 无障碍

- 触发入口角色为 `button`，朗读"分类，当前值：家务，展开选择"
- 弹出层角色为 `listbox`，选项角色为 `option`，当前项标注 `aria-selected`
- 展开后焦点进入弹出层，`Esc` 关闭后焦点回到触发入口
- 触控热区 ≥ 44

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 菜单形态 | `Menu` | `DropdownMenu` |
| 滚轮形态 | `Picker` + `.wheel` | `NumberPicker` 或自定义 |

两端都保留系统控件的键盘与读屏行为，只统一触发入口的样式。

### 12. 验收清单

- [ ] 触发入口高 44、选项行高 44，误差 ≤ 1pt
- [ ] 展开时当前选项自动滚到可视区中间
- [ ] 点击遮罩关闭且不改变当前值
- [ ] 空间不足时弹出方向自动翻转，不被裁切
- [ ] 未选状态显示"请选择"而不是空白
- [ ] 同一表单里只出现一种 Picker 形态
- [ ] 读屏能读出当前值，选中项标注 `aria-selected`

### 7. 内容

- 标签 2–8 个汉字，名词短语，**不加冒号**
- 标签与控件的值语义要区分：标签"截止日期"，值"明天"，不要两边都写日期
- 说明文字一行，≤ 20 个汉字；错误文字一行，越短越好
- 错误文字必须说清"哪里错 + 怎么改"

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击标签 | 聚焦对应控件（左右排布时） |
| 点击整行 | 仅当行内只有一个控件且控件本身可聚焦时，聚焦该控件 |
| 校验失败 | 就地显示错误文字，**不弹窗、不滚动到顶部** |
| 提交时校验 | 滚动到第一个错误的行并聚焦 |

### 9. 动效

错误文字出现 160ms 淡入 + 4pt 下移；行高随之增加，用 `motion.duration.fast` 过渡，避免整表跳动。

### 10. 无障碍

- 标签与控件必须关联，读屏先读标签再读控件
- 出错时读"截止日期，错误，日期不能早于今天"
- 左右排布时，点击标签也能聚焦控件（标签的可点区域与行等高）
- 分组时每个分组有组标签（如"提醒设置"）

### 11. 平台差异

iOS 用 `LabeledContent` 或自定义 `HStack`；
Android 用 `Row` + `Modifier.semantics { }` 建立标签与控件的关联。
两端的"标签关联控件"都要显式声明，不能只靠视觉相邻。

### 12. 验收清单

- [ ] 行最小高 44，行间距 16
- [ ] 同一表单内排布方式统一，没有混用左右与上下
- [ ] 标签不加冒号
- [ ] 错误文字替换说明文字，不叠加显示
- [ ] 校验失败就地显示，不弹窗
- [ ] 提交时能滚动到第一个错误行并聚焦
- [ ] 读屏先读标签再读控件，错误时读出错误

# 25 · Alert

**视觉参考**：待补 ｜ **优先级** P0

### 1. 用途

需要用户**立刻做决定**，且决定之前不能继续往下走。

- **用**：删除确认、放弃未保存的修改、权限被拒后引导去设置
- **不要用**：只是告知结果（用 `WDToast`）；可以撤销的操作（用撤销条）；收集输入（用 `WDBottomSheet`）；错误提示（用 `WDBanner`）

准入标准：**如果这个决定可以撤销，就不要用 Alert。**

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 遮罩 | 必有 | 阻止与下层交互，底色为页面底色的 40% 黑 |
| 卡片 | 必有 | `surface.card-solid` + `elevation.3` + `radius.xl` |
| 标题 | 必有 | `type.headline` 17 · 600，居中 |
| 正文 | 可选 | `type.footnote` 13，色 `text.secondary`，居中，最多 3 行 |
| 按钮组 | 必有 | 横向等分；两按钮时中间用 1pt 分割线 |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 卡片宽 | 270（固定，不随内容变化） |
| 卡片圆角 | `radius.xl` 24 |
| 标题区上下内距 | 16 / 6 |
| 正文区左右内距 | 16，下内距 14 |
| 按钮高 | 44 |
| 按钮字号 | 16（破坏性按钮用 `status.danger`） |

### 4. 变体

| 变体 | 按钮组 | 用在哪 |
| --- | --- | --- |
| 双按钮 | 取消 + 确认，取消在左 | 默认 |
| 单按钮 | 只有一个"知道了" | 纯告知但仍需阻断 |
| 危险 | 确认按钮用 danger 色 | 删除、清空等不可逆操作 |
| 带输入 | 卡片内嵌一个 `WDTextField` | 需要输入名称才能继续（如重命名） |

### 5. 状态

| 状态 | 视觉 |
| --- | --- |
| 出现 | 遮罩 160ms 淡入；卡片 240ms 从 0.92 缩放到 1 + 淡入 |
| 按钮按下 | 按钮底色 `fill.pressed` |
| 长文案 | 正文超过 3 行时卡片内部滚动，卡片高度不超过屏幕的 60% |

### 6. 布局

- 卡片在遮罩内**水平居中、垂直居中偏上**（垂直居中会显得重心过低）
- 卡片与屏幕左右最小间距 `space.8`（32）
- 按钮等宽；两按钮之间分割线与卡片等宽

### 7. 内容

- 标题 ≤ 12 个汉字，一句话说清要决定什么（"删除这条任务？"）
- 正文 ≤ 60 个汉字，补充后果（"删除后无法恢复，其他成员也看不到了"）
- 按钮文案用**动词**："删除"、"放弃修改"，不用"确定 / 取消"这种没有信息量的词
- 取消按钮保留"取消"即可，它本身就是标准语义

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击确认 | 执行动作并关闭 |
| 点击取消 | 关闭，不执行 |
| 点击遮罩 | **不关闭**——Alert 的前提是必须做出选择 |
| `Esc` / 返回键 | 等价于取消 |
| 重复点击确认 | 第一次点击后禁用按钮，防止重复提交 |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 遮罩淡入 | `motion.duration.fast` 160ms 线性 |
| 卡片入场 | `motion.duration.base` 240ms，缩放 0.92 → 1 |
| 关闭 | 160ms 淡出，不做缩放 |

### 10. 无障碍

- 角色为 `alertdialog`，标题与正文自动朗读
- 出现时**焦点移入卡片**，并限制在卡片内（焦点陷阱）
- 关闭后焦点**归还到触发元素**
- 破坏性按钮的朗读包含后果："删除，删除后无法恢复"
- 按钮触控热区 ≥ 44

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | `.alert`，或自定义以支持带输入 | `AlertDialog` |
| 按钮顺序 | 取消在左、确认在右 | Material 默认确认在右 |
| 遮罩点击 | 系统默认不关闭 | 系统默认可关闭，需显式禁用 |

### 12. 验收清单

- [ ] 卡片宽 270，圆角 `radius.xl`
- [ ] 卡片位置为垂直居中偏上，不是正中
- [ ] 点击遮罩不关闭
- [ ] `Esc` / 返回键等价于取消
- [ ] 确认按钮点击后立即禁用，不会重复提交
- [ ] 正文超过 3 行时卡片内滚动，总高不超屏幕 60%
- [ ] 出现时焦点进入并被限制在卡片内，关闭后归还
- [ ] 按钮文案是动词，不是"确定"
- [ ] 危险操作的按钮使用 danger 色，且朗读包含后果

# 26 · BottomSheet

**视觉参考**：待补 ｜ **优先级** P0

### 1. 用途

承接次级内容或表单，**不离开当前上下文**。

- **用**：新建任务、成员选择、筛选面板、详情预览
- **不要用**：必须完整专注的任务（用整页）；简单确认（用 `WDAlert`）；一组操作（用 `WDActionSheet`）

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 遮罩 | 必有 | 半透明，点击关闭；可配置为不可关闭 |
| 面板 | 必有 | 顶部两角 `radius.xxl` 32，底边贴合屏幕 |
| 把手 | 必有 | 36×5，`radius.full`，色 `border.hairline-strong`，距顶 8 |
| 头部 | 可选 | 标题 `type.title3` + 右侧关闭按钮 |
| 内容 | 必有 | 可滚动区域 |
| 底部操作 | 可选 | 固定不滚动，上方 1pt 分割线 + `space.5` 内距 |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 圆角 | 顶部两角 `radius.xxl` 32 |
| 把手 | 36×5，距顶 8 |
| 头部高 | 56 |
| 内容左右内距 | `space.5`（16） |
| 底部操作区高 | 72（含安全区） |
| detents | 半屏 0.5 / 大 0.92 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 半屏 | 默认，detent 0.5 |
| 大 | detent 0.92，用于长表单 |
| 可拉伸 | 在半屏与大之间可拖拽切换 |
| 不可关闭 | 遮罩不可点、禁用下拉（如强制更新） |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 出现 | 遮罩淡入 160ms；面板从底部滑入 340ms | `motion.spring.gentle` |
| 拖拽中 | 面板跟随手指，遮罩透明度同步变化 | 实时 |
| 松手 | 速度 ≥ 500pt/s 或位移超过 40% 时关闭，否则回弹 | `motion.spring.snappy` |
| 关闭 | 面板下滑 240ms，遮罩淡出 160ms | — |

### 6. 布局

- 面板宽度 = 屏幕宽；宽屏（≥ 600）时最大宽 480 并水平居中
- 底部操作区固定在面板底部，内容在其上方滚动
- 内容顶部与头部的间距 `space.4`（12）
- 键盘弹出时面板整体上移，不遮挡当前字段

### 7. 内容

- 标题 ≤ 10 个汉字，说明这个面板在做什么（"新建任务"）
- 内容过长时内部滚动，不把面板撑到全屏——需要全屏说明应该用整页
- 底部操作区最多两个按钮，主操作在右

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 下拉面板 | 关闭（不可关闭变体除外） |
| 下拉内容区 | 先滚动内容，到顶后继续下拉才拖动面板 |
| 点击遮罩 | 关闭；有未保存修改时先弹 `WDAlert` 确认 |
| 点击把手 | 在半屏与大之间切换 |
| 返回键 / `Esc` | 同点击遮罩 |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 面板入场 | `motion.duration.slow` 340ms，`motion.spring.gentle` |
| 面板关闭 | `motion.duration.base` 240ms |
| detent 切换 | `motion.spring.snappy` |
| 遮罩 | 160ms，与面板位移同步 |

### 10. 无障碍

- 出现时焦点进入面板并被限制在内（焦点陷阱）
- 关闭后焦点归还触发元素
- 提供"下滑关闭"的自定义辅助操作，不能只依赖手势
- 关闭按钮标签"关闭"，并按面板标题补充上下文："关闭新建任务"
- 把手标记为装饰，不进入无障碍树

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | `.sheet` + `.presentationDetents` | `ModalBottomSheet` |
| 把手 | 系统提供 | `dragHandle` |
| 拖拽 | 系统处理速度阈值 | 需要自己实现嵌套滚动与阈值 |

### 12. 验收清单

- [ ] 顶部圆角 32、把手 36×5，误差 ≤ 1pt
- [ ] 内容可滚动时，先滚内容再拖面板，不冲突
- [ ] 速度 ≥ 500pt/s 或位移超 40% 时关闭，否则回弹
- [ ] 有未保存修改时关闭前弹确认
- [ ] 键盘弹出不遮挡当前字段
- [ ] 焦点进入面板并归还，提供"下滑关闭"辅助操作
- [ ] 宽屏下最大宽 480 且水平居中

# 27 · ActionSheet

**视觉参考**：待补 ｜ **优先级** P1

### 1. 用途

从一组操作里选一个，且这组操作**与当前位置强相关**。

- **用**：长按一条任务后的操作、分享方式选择、含删除的操作组
- **不要用**：只有 1–2 个操作（直接放按钮）；需要解释每个选项（用 `WDBottomSheet`）；选项需要输入

### 2. 解剖

| 段 | 说明 |
| --- | --- |
| 遮罩 | 半透明，点击关闭 |
| 操作列表 | 纵向，每项 44 高，图标可选 |
| 取消 | **独立的胶囊**，与操作列表分离，固定在最下 |

取消按钮之所以独立，是为了让"取消"永远不会被误认为另一个操作。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 操作行高 | 44 |
| 行水平内距 | 16 |
| 列表圆角 | `radius.lg` 18 |
| 取消胶囊高 | 48 |
| 与安全区间距 | `space.3`（8） |
| 操作列表与取消的间距 | `space.3`（8） |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 标准 | 全部为普通操作 |
| 含破坏性 | 破坏性操作单独成组，用 `status.danger` |
| 带图标 | 每项前置 20pt 图标 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 出现 | 从底部滑入 | 340ms `motion.spring.gentle` |
| 按下 | 该行 `fill.pressed` | 100ms |
| 破坏性 | 文字 `status.danger` | — |
| 关闭 | 下滑淡出 | 240ms |

### 6. 布局

- 面板宽度 = 屏幕宽 − 2 × `space.5`（16）
- 操作列表底部与取消胶囊之间固定 `space.3`（8）
- 破坏性操作放在**列表最下方**（或独立成组），不能夹在中间

### 7. 内容

- 每项 ≤ 8 个汉字，动词开头（"复制链接"、"设为已完成"）
- 危险操作写清后果（"删除任务"而不是"删除"）
- 面板顶部可加一行标题说明操作对象（"整理储物间"），`type.footnote`，色 `text.secondary`

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击某项 | 执行、关闭 |
| 点击取消 | 关闭，不执行 |
| 点击遮罩 | 同取消 |
| 返回键 / `Esc` | 同取消 |

### 9. 动效

滑入 340ms `motion.spring.gentle`；关闭 240ms；行按下 100ms。

### 10. 无障碍

- 角色为 `menu`（iOS 上为 action sheet），每项角色 `menuitem`
- 破坏性项朗读包含后果
- 出现时焦点进入列表，取消按钮可被独立到达
- 行高 44 已满足触控热区

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | `.confirmationDialog` | `ModalBottomSheet` + 列表（Material 无 ActionSheet） |
| 取消位置 | 独立胶囊在底部 | 列表内最后一项 |

Android 端务必把取消做成列表外的独立项，不要混进操作列表。

### 12. 验收清单

- [ ] 操作行高 44、取消胶囊高 48，误差 ≤ 1pt
- [ ] 取消是独立胶囊，不与操作列表混在一起
- [ ] 破坏性操作在最下方或独立成组，不夹在中间
- [ ] 点击遮罩与返回键都等价于取消
- [ ] 每项文案是动词且有明确对象
- [ ] 出现时焦点进入，取消可被独立到达

# 28 · Toast

**视觉参考**：待补 ｜ **优先级** P0

### 1. 用途

**非阻塞**的轻提示，告知"刚刚发生了一件事"。

- **用**：保存成功、已复制、已同步、任务已删除（带撤销）
- **不要用**：需要用户决策（用 `WDAlert`）；需要用户处理且不能错过的错误（用 `WDBanner`）；加载中（用进度组件）

分界线：**Toast 会自己消失，所以它承载的信息必须是"不看也没关系"的。**

### 2. 解剖

玻璃胶囊 + 状态图标 + 文字 + 可选操作按钮。底部距安全区 `space.5`（16）。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 高度 | 46（单行）；多行时自适应，最多 2 行 |
| 最小宽度 | 120 |
| 最大宽度 | 屏幕宽 − 2 × `space.6`（40） |
| 水平内距 | 18 |
| 圆角 | `radius.full` |
| 图标 | 16 |

### 4. 变体

| 变体 | 图标 | 用在哪 |
| --- | --- | --- |
| 成功 | `check` + `text.brand` | 保存、同步完成 |
| 信息 | `info` | 中性提示 |
| 失败 | `x-circle` + `status.danger` | 操作未成功，但可重试 |
| 带操作 | 右侧加一个文字按钮（"撤销"） | 删除后撤销 |

### 5. 状态

| 状态 | 时长 |
| --- | --- |
| 出现 | 320ms 上移淡入 |
| 停留（纯提示） | 3 秒 |
| 停留（带操作） | 5 秒 |
| 消失 | 160ms 淡出 |
| 手指悬停 | 暂停计时 |

### 6. 布局

- 底部居中，距安全区 `space.5`（16）
- 同时只显示**一条**；新 Toast 顶掉旧 Toast，不排队堆叠
- 与底部 Tab 栏共存时出现在 Tab 栏上方 `space.4`（12）

### 7. 内容

- 一句话 ≤ 20 个汉字，说结果不说过程（"任务已保存"而不是"正在保存任务"）
- 不用"成功！"这类只有情绪没有信息的文案
- 带操作时按钮文案具体："撤销"而不是"好"

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击 Toast | 无操作时为无响应（不关闭）；带操作时触发该操作并关闭 |
| 点击页面其他区域 | **不关闭**，Toast 自己会消失 |
| 向上滑 | 立即关闭 |
| 连续触发 | 复用同一个 Toast，重置计时并替换内容 |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 出现 | `motion.component.toast-in` 320ms，上移 12pt + 淡入，`motion.spring.gentle` |
| 消失 | `motion.duration.fast` 160ms 淡出（不做位移，避免和出现方向相反显得突兀） |

### 10. 无障碍

- 成功 / 信息用 `aria-live="polite"`
- 失败用 `role="alert"`，会被立即播报
- 带操作时朗读"任务已删除，撤销，按钮"
- Toast 出现**不抢焦点**——它是非阻塞提示
- 文字与底色对比度 ≥ 4.5:1（玻璃底上必要时加底色托底）

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | 自定义浮层，挂在 window 上避免被容器裁切 | `Snackbar` + `SnackbarHost` |
| 位置 | 底部居中 | Material 默认底部左对齐，需要改为居中 |
| 时长 | 自定义 | `SnackbarDuration.Short / Long` |

### 12. 验收清单

- [ ] 单行高 46、圆角 `radius.full`，误差 ≤ 1pt
- [ ] 同时只显示一条，连续触发时复用而不是堆叠
- [ ] 纯提示停留 3 秒，带操作停留 5 秒
- [ ] 手指悬停时暂停计时
- [ ] 失败态用 `role="alert"`，成功态用 `polite`
- [ ] Toast 出现不抢焦点
- [ ] 与底部 Tab 栏共存时不被遮挡
- [ ] 出现在 window 层，不被局部容器裁切

# 29 · Banner

**视觉参考**：待补 ｜ **优先级** P0

### 1. 用途

**常驻**的页面级提示。需要用户看到、可能需要处理，但不阻断当前操作。

- **用**：权限被限制、网络不可用、试用期剩余天数、批量操作的部分失败
- **不要用**：一次性结果（用 `WDToast`）；需要立刻决策（用 `WDAlert`）；装饰性强调

分界线：**Banner 不自动消失**，所以它承载的信息必须值得占一块常驻空间。

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 状态图标 | 必有 | 18pt，形状区分状态（对勾 / 信息 / 三角 / 实心禁止） |
| 文案 | 必有 | `type.footnote` 13，最多 2 行 |
| 操作按钮 | 可选 | 文字按钮，最多一个 |
| 关闭键 | 可选 | 可关闭的提示才有 |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 最小高 | 44（单行） |
| 内边距 | 12 |
| 圆角 | `radius.lg` 18 |
| 图标与文案间距 | `space.3`（8） |
| 文案与操作间距 | `space.3`（8） |

### 4. 变体

| 变体 | 底色 | 文字与图标 | 用在哪 |
| --- | --- | --- | --- |
| 成功 | `status-soft.success` 渐变 | `status.success` | 同步完成 |
| 信息 | `status-soft.info` 渐变 | `status.info` | 中性说明 |
| 警示 | `status-soft.warning` 渐变 | `status.warning` | 快到期、接近上限 |
| 错误 | `status-soft.danger` 渐变 + 文字加粗 | `status.danger` | 操作失败、需处理 |

底色一律用**同色 20% 左右的渐变**，不用纯色块。

### 5. 状态

| 状态 | 说明 |
| --- | --- |
| 常驻 | 直到条件解除才消失（如网络恢复） |
| 可关闭 | 右上角有关闭键，关闭后本次会话不再出现 |
| 出现 | 240ms 淡入 + 8pt 下移，不循环 |

### 6. 布局

- 页面顶部，或所在分组内顶部，左右边距 `space.5`（16）
- 与下方内容间距 `space.4`（12）
- 同一页面最多 2 条，多条时按严重度排序：错误 → 警示 → 信息

### 7. 内容

- 一句话说清"发生了什么 + 需要做什么"："网络不可用，改动已暂存本地"
- ≤ 40 个汉字，超过 2 行说明这条信息不该用 Banner 承载
- 操作按钮文案具体："去设置"、"重试"，不用"知道了"

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击操作按钮 | 执行对应动作，Banner 可保留或关闭 |
| 点击关闭键 | 关闭，本次会话不再出现（持久化到会话级，不写磁盘） |
| 点击 Banner 本体 | 无操作时无响应 |

### 9. 动效

出现 240ms 淡入 + 8pt 下移；关闭 160ms 淡出 + 高度收起。
**不做循环动画**，也不做呼吸效果——常驻元素持续动会持续抢注意力。

### 10. 无障碍

- 信息 / 成功用 `role="status"`，警示 / 错误用 `role="alert"`
- 错误态的图标与文字同时变化，不依赖颜色
- 关闭键标签"关闭提示"，并按内容补充："关闭网络提示"
- 不抢焦点；若在页面加载时就存在，随内容一起被朗读

### 11. 平台差异

两端都需自定义。iOS 可参考 `SafeAreaInset` 固定在导航栏下方；
Android 可参考 `Snackbar` 的常驻变体，但不要用 `Snackbar` 做常驻提示（它默认会消失）。

### 12. 验收清单

- [ ] 圆角 `radius.lg`、内边距 12，误差 ≤ 1pt
- [ ] 四种状态的底色都是同色渐变，不是纯色块
- [ ] 错误态文案加粗，且图标形状与其他状态不同
- [ ] 不自动消失、无循环动画
- [ ] 同一页面不超过 2 条，按严重度排序
- [ ] 可关闭的提示关闭后本次会话不再出现
- [ ] 读屏角色正确（信息用 status，错误用 alert）

# 30 · EmptyState

**视觉参考**：待补 ｜ **优先级** P1

### 1. 用途

没有内容时，说明**为什么没有**以及**接下来能做什么**。

- **用**：首次进入列表、搜索无结果、权限受限、加载失败
- **不要用**：内容还在加载（用 `WDSkeleton`）；内容确实为空但用户不关心（直接留白）

### 2. 解剖

圆形图标底座 + 标题 + 说明 + 一个主操作。四段都可选，但至少要有标题。

| 段 | 规格 |
| --- | --- |
| 图标底座 | 56×56 圆形，`gradient.surface` 底 + `text.on-soft` 图标 26 |
| 标题 | `type.headline` 17 · 600 |
| 说明 | `type.subheadline` 15，`text.secondary`，最多 2 行，居中 |
| 主操作 | `WDButton` filled 或 tonal，最多一个 |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 底座 | 56×56 |
| 底座与标题间距 | `space.4`（12） |
| 标题与说明间距 | `space.2`（4） |
| 说明与操作间距 | `space.5`（16） |
| 文本最大宽 | 32 个汉字宽（约 240） |

### 4. 变体

| 变体 | 标题示例 | 操作 |
| --- | --- | --- |
| 首次空 | "还没有任务" | "新建第一个任务" |
| 搜索无结果 | "没找到"储物间"" | "清除筛选" |
| 权限受限 | "需要通知权限" | "去设置" |
| 加载失败 | "加载失败" | "重试" |

四种的差别不在视觉，而在**文案与操作**，配色保持一致。

### 5. 状态

空状态本身无状态。加载失败的变体可以重复触发"重试"，重试期间按钮进入加载态。

### 6. 布局

- 在**内容区域**内垂直居中，不是屏幕正中（要扣掉导航栏与 Tab 栏）
- 左右边距 `space.8`（32），避免文字贴边
- 与页面顶部至少留 `space.9`（40）

### 7. 内容

- 标题 ≤ 12 个汉字，陈述事实（"还没有任务"）
- 说明 ≤ 40 个汉字，给出原因或下一步，**不写"这里什么都没有"这类废话**
- 操作文案是动词短语，且与标题呼应
- 搜索无结果时，标题里带上用户输入的关键词，让用户确认搜的是什么

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击主操作 | 执行对应动作 |
| 无操作时 | 整块不可交互，不做按下反馈 |

### 9. 动效

不做入场动画。加载失败重试时按钮进入加载态即可。
**空状态做动画会显得轻浮**，且用户已经处于受挫状态。

### 10. 无障碍

- 作为一组朗读：标题 → 说明 → 操作
- 图标底座标记为装饰
- 读屏用户进入空页面时，标题应能被首个朗读到
- 文字对比度 ≥ 4.5:1，说明文字用 `text.secondary` 已满足

### 11. 平台差异

两端都需自定义。注意 iOS 的 `ContentUnavailableView` 可以直接用，
但它的默认排版与我们的间距规格不同，需要对齐后再用。

### 12. 验收清单

- [ ] 图标底座 56×56，误差 ≤ 1pt
- [ ] 在内容区内垂直居中，不被导航栏或 Tab 栏挤压
- [ ] 文本最大宽约 240，不贴边
- [ ] 四种变体的视觉一致，只有文案与操作不同
- [ ] 说明文字给出原因或下一步，不是废话
- [ ] 搜索无结果时标题包含关键词
- [ ] 没有入场动画
- [ ] 加载失败可重试，重试时按钮进入加载态

# 31 · Skeleton

**视觉参考**：待补 ｜ **优先级** P1

### 1. 用途

内容加载中的占位，**保持布局稳定**，避免内容出现时页面跳动。

- **用**：首次加载列表、卡片、详情页
- **不要用**：加载时间可预期且很短（< 300ms）；加载失败（用 `WDEmptyState`）

### 2. 解剖

灰色块 + 微光扫过。骨架的**形状必须和真实内容一致**——形状不一致的骨架比没有骨架更糟，
因为它会误导用户对内容的预期。

### 3. 尺寸

| 形态 | 规格 |
| --- | --- |
| 文本行 | 高 11，圆角 6，宽度按真实文本比例（70% / 45%） |
| 列表行 | 与 `WDListRow` 等高（44 / 60 / 76） |
| 卡片 | 与真实卡片同尺寸、同圆角、同内边距 |
| 头像 | 圆形，直径同真实头像 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 文本 | 3–4 行文本块 |
| 列表 | 5–6 行列表项，前导圆形 + 两行文本 |
| 卡片 | 卡片轮廓 + 卡内两行 + 一个按钮宽度的块 |

### 5. 状态

只有一种状态（加载中）。加载完成后骨架**整块替换**为真实内容，不做逐块替换。

### 6. 布局

- 骨架的外边距、间距与真实内容**完全一致**
- 骨架数量取真实内容的典型数量（列表取 5–6 行，不要渲染 50 行）
- 骨架不滚动

### 7. 内容

骨架内**不写任何文字**。写"加载中…"会让页面在加载完成时发生文本跳动。
需要说明进度时用 `WDProgressBar` 的不确定态。

### 8. 交互

不可交互。骨架出现时，页面滚动应被禁用（内容高度还没确定）。

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 微光扫过 | `motion.component.skeleton-shimmer` 2200ms 线性，循环 |
| 替换为内容 | 160ms 交叉淡化 |

开启"减弱动态效果"时**停止微光**，显示静态灰块。

### 10. 无障碍

- 骨架容器标注 `aria-busy="true"`
- 整个骨架区朗读**一次**"加载中"，不要每个灰块都朗读
- 加载完成后朗读"内容已加载"，并把焦点保持在原位置
- 灰块与背景对比度约 1.5:1 即可，不需要文字级对比度（它不是文字）

### 11. 平台差异

两端都需自定义。注意 Android 的 `Modifier.placeholder` 需要额外依赖；
两端实现同一套微光节奏（2200ms）以保证观感一致。

### 12. 验收清单

- [ ] 骨架形状与真实内容一致，替换时**无布局跳动**
- [ ] 外边距、间距、圆角与真实内容完全相同
- [ ] 骨架内没有任何文字
- [ ] 列表骨架 5–6 行，不渲染全量数据
- [ ] 微光 2200ms 循环；减弱动态效果时静止
- [ ] 容器标注 `aria-busy`，只朗读一次"加载中"
- [ ] 加载完成后整块替换，不逐块闪烁

# 32 · PullToRefresh

**视觉参考**：待补 ｜ **优先级** P1

### 1. 用途

用户主动请求刷新。**只用于内容会变化且用户有刷新动机的列表**。

- **用**：消息列表、家庭动态、协作任务
- **不要用**：静态内容（设置页）；实时推送已经覆盖的场景

### 2. 解剖

下拉指示器 + 文字状态 + 刷新中的进度环。

| 阶段 | 显示 |
| --- | --- |
| 下拉未达阈值 | 环从左到右画出进度，文字"下拉刷新" |
| 达到阈值 | 环变成完整圆，文字"松开刷新" |
| 刷新中 | 环旋转，文字"正在刷新" |
| 完成 | 环收起，列表内容回到原位 |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 触发阈值 | 64（下拉超过此距离松手才刷新） |
| 指示器直径 | 24 |
| 环线宽 | 2 |
| 指示器与首行间距 | `space.4`（12） |
| 最大下拉距离 | 120（超过后阻力显著增加） |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 品牌进度 | 环用 `text.brand`，默认 |
| 极简 | 只有环，没有文字（空间极紧时） |

### 5. 状态

| 状态 | 视觉 |
| --- | --- |
| 空闲 | 指示器隐藏在列表上方 |
| 下拉中 | 指示器跟随下拉距离显出，透明度 0 → 1 |
| 刷新中 | 指示器固定显示，环旋转 |
| 完成 | 160ms 后收起 |

### 6. 布局

- 指示器水平居中
- 指示器出现时**不下推列表内容**，而是覆盖在列表上方（避免内容位移）
- 刷新完成后列表回到顶部位置，不保留偏移

### 7. 内容

- 文字三态固定为"下拉刷新 / 松开刷新 / 正在刷新"
- 不显示上一次刷新时间（那是 Banner 或页脚的职责）
- 刷新失败时收起指示器并弹 `WDToast`，不把错误文字挤在下拉区

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 下拉 | 阻力递增；超过 64 后松手触发刷新 |
| 阈值处 | 触发一次轻触觉（**只触发一次**，不随手指抖动重复触发） |
| 刷新中再下拉 | 不响应 |
| 刷新超时 | 10 秒后收起诉失败 |
| 键盘操作 | 提供"刷新"辅助操作，不强制手势 |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 指示器跟随 | 实时，无动画 |
| 回弹 | `motion.spring.snappy` |
| 环旋转 | 刷新期间持续，`prefers-reduced-motion` 时改为静态环 |

### 10. 无障碍

- 提供"刷新"的自定义辅助操作，读屏用户不需要会下拉
- 刷新开始与结束各播报一次："正在刷新" / "刷新完成"
- 触觉在阈值处触发一次
- 减弱动态效果时，环不做旋转，改为静态进度

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | `.refreshable` | `PullToRefreshBox` |
| 指示器 | 系统提供，样式不可控 | 可自定义 `indicator` |

两端都要保证"不下推内容"这一条，系统默认行为可能不同，需要显式调整。

### 12. 验收清单

- [ ] 触发阈值 64，最大下拉 120，误差 ≤ 2pt
- [ ] 指示器覆盖在列表上方，**不下推内容**
- [ ] 阈值处触觉只触发一次
- [ ] 三态文案正确切换
- [ ] 刷新中再次下拉不重复触发
- [ ] 10 秒超时收起诉失败，失败用 Toast 提示
- [ ] 提供"刷新"辅助操作，不强制手势
- [ ] 减弱动态效果时环不旋转

# 33 · NavigationBar

**视觉参考**：待补 ｜ **优先级** P0

### 1. 用途

页面级导航容器：告诉用户"这是哪"，并提供返回与页面级操作。

- **用**：每个二级及以上页面
- **不要用**：Tab 内的一级页面加返回按钮（一级页面没有返回）；把页面内容塞进导航栏

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 返回 / 关闭 | 条件 | 二级页必有；一级页没有 |
| 标题 | 必有 | 内联模式 `type.headline` 17 · 600，居中或左对齐（跟平台） |
| 右侧操作 | 可选 | **最多 2 个**图标按钮，间距 `space.3`（8） |
| 大标题 | 条件 | 大标题模式才有，`type.largeTitle` 34 · 700，左对齐 |

### 3. 尺寸

| 模式 | 高度 | 组成 |
| --- | --- | --- |
| 内联（紧凑） | 44 | 状态栏下的单行 |
| 标准 | 56 | 单行 + 上下留白 |
| 大标题 | 96 | 内联行 44 + 大标题区 52 |

图标按钮 32×32 视觉，热区 44×44。左右边距 `space.5`（16）。

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 透明 | 页面顶部，内容未滚动时无底色 |
| 玻璃 | 内容滚动到栏下方时切换为 `surface.glass` + `border.glass-top` |
| 大标题 | 标题独立成行，滚动时收缩为内联 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 未滚动 | 透明底，无分割线 | — |
| 已滚动 | `surface.glass` + 底部 1pt `border.hairline` | 240ms 交叉淡化 |
| 大标题收缩 | 大标题缩到内联标题的位置并降字号 | `motion.spring.gentle` |
| 返回按下 | 按钮缩放 0.97 + `fill.pressed` | 100ms |

### 6. 布局

- 导航栏固定在顶部，内容在其下方滚动
- 大标题模式下，大标题与内容左边缘对齐（`space.5`）
- 右侧操作最多 2 个，超过时合并进"更多"
- 页面内容顶部需预留 `space.7`（24）起始留白

### 7. 内容

- 标题 ≤ 8 个汉字，用页面名而不是动作名（"家庭"而不是"查看家庭"）
- 标题不用缩写、不用省略号；放不下时优先缩短文案
- 返回按钮**只显示箭头不显示文字**（除非空间充裕且需要指明来源页）

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击返回 | 返回上一页 |
| 点击大标题 | 列表滚动到顶部 |
| 向下滚动 | 大标题收缩为内联，导航栏转玻璃底 |
| 向上滚动到顶 | 大标题恢复，导航栏转透明 |
| 边缘右滑（iOS） | 返回上一页 |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 大标题收缩 / 展开 | `motion.spring.gentle`，跟随滚动进度而非固定时长 |
| 玻璃底切换 | `motion.duration.base` 240ms 交叉淡化 |
| 返回按下 | `motion.duration.instant` 100ms |

### 10. 无障碍

- 导航栏作为 `header` 语义，标题作为页面标题被首个朗读
- 返回按钮标签包含来源页名："返回家庭列表"
- 右侧图标按钮必须有独立标签
- 大标题收缩时读屏**仍能读到完整标题**，不能因为视觉收缩而丢失
- 触控热区 ≥ 44×44

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 形态 | 大标题 + 居中内联标题 | `TopAppBar`，标题左对齐 |
| 返回 | 圆形玻璃底返回键 + 边缘右滑 | 返回箭头 + 系统预测式返回 |
| 收缩 | `navigationBarTitleDisplayMode` | `TopAppBarScrollBehavior` |

标题对齐方式两端不同是刻意的，不要强行统一。

### 12. 验收清单

- [ ] 内联 44 / 标准 56 / 大标题 96，误差 ≤ 1pt
- [ ] 未滚动时透明，滚动到栏下方时切玻璃底，过渡无跳变
- [ ] 大标题收缩跟随滚动进度，不是固定时长动画
- [ ] 右侧最多 2 个操作，超过合并进"更多"
- [ ] 标题 ≤ 8 字，不使用省略号
- [ ] 返回按钮标签包含来源页名
- [ ] 收缩时读屏仍能读到完整标题
- [ ] 一级页面没有返回按钮

# 34 · TabBar

**视觉参考**：待补 ｜ **优先级** P0

### 1. 用途

顶层导航。在互不隶属的几个主区域之间切换。

- **用**：2–5 个平级的主区域
- **不要用**：超过 5 个（需要重新做信息架构）；二级页面（用 `WDNavigationBar`）；页面内的视图切换（用 `WDSegmentedControl`）

### 2. 解剖

悬浮玻璃胶囊 + 若干项目（图标 + 标签 + 选中标记）。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 高度 | 58 |
| 距左右边缘 | `space.5`（16） |
| 距底部安全区 | `space.3`（8） |
| 图标 | 22 |
| 标签 | 10 · 500（选中 600） |
| 圆角 | `radius.full` |
| 项目数 | 2–5 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| iOS 悬浮胶囊 | 默认，浮在内容之上，带 `elevation.2` |
| Android 全宽 | 贴底全宽，`surface.glass-strong`，选中项用胶囊底 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 未选 | 图标与标签 `text.tertiary` | — |
| 选中 | 图标与标签 `text.brand`，标签加粗，下方 4pt 圆点 | 200ms |
| 按下 | 图标缩放 0.94 | 100ms |
| 带角标 | 图标右上角计数徽标 | — |

### 6. 布局

- 浮在内容之上，内容底部需预留 58 + 8 + `space.5` = 82 的留白
- 项目等分，各占相同宽度
- 滚动时**可收缩为无标签的胶囊**，向上滚动立即展开

### 7. 内容

- 标签 ≤ 4 个汉字，用名词（"今天"、"家庭"）
- 不用图标代替标签（首次使用的用户认不出）
- 角标计数超 99 显示"99+"，为 0 时隐藏

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击未选项 | 切换，重置该区域的导航栈 |
| 点击已选项 | 该区域滚动到顶部（**不重置导航栈**） |
| 再次点击已选项且已在顶部 | 该区域滚动到顶部（无其他动作） |
| 左右滑动内容 | 若支持，与点击等效 |

### 9. 动效

选中态 200ms 变色与字重过渡；收缩 / 展开 `motion.spring.gentle`；
切换区域时**不做横向滑动动画**（会让人以为是同一页面的分页）。

### 10. 无障碍

- 容器角色为 `tablist`，每项角色 `tab`
- 朗读"第 n 项，共 m 项"，选中项标注 `aria-selected`
- 触控热区：单项宽度足够，高度 58 已满足
- 选中态不依赖颜色：同时有圆点与字重变化

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 形态 | 悬浮玻璃胶囊 | 贴底全宽 |
| 选中标记 | 图标下 4pt 圆点 | 图标外胶囊底 |
| 收缩 | 滚动时收缩为无标签胶囊 | 默认不收缩 |

### 12. 验收清单

- [ ] 高 58、距左右 16、距底部安全区 8，误差 ≤ 1pt
- [ ] 2–5 个项目，等分宽度
- [ ] 内容底部预留 ≥ 82 留白，最后一行不被遮挡
- [ ] 点击已选项回到顶部，且不重置导航栈
- [ ] 选中态同时有颜色、字重、圆点三个信号
- [ ] 标签 ≤ 4 字，且没有用图标代替标签
- [ ] 读屏读出"第 n 项，共 m 项"与选中状态

# 35 · Toolbar

**视觉参考**：待补 ｜ **优先级** P1

### 1. 用途

与**当前上下文**相关的一组操作。和 TabBar 的区别是：TabBar 切换区域，Toolbar 操作当前内容。

- **用**：编辑器（撤销/重做/格式）、画布（缩放/对齐）、多选状态下的批量操作
- **不要用**：页面级导航（用 `WDNavigationBar`）；主区域切换（用 `WDTabBar`）；少于 2 个操作

### 2. 解剖

玻璃胶囊容器 + 若干图标按钮 + 可选分割线 + 可选文字。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 容器高 | 48 |
| 图标按钮 | 36×36，图标 20 |
| 按钮间距 | `space.2`（4） |
| 容器内边距 | 6 |
| 圆角 | `radius.full` |
| 分割线 | 1pt × 24，色 `border.hairline` |

### 4. 变体

| 变体 | 位置 | 说明 |
| --- | --- | --- |
| 顶部 | 导航栏下方 | 与当前对象相关的操作 |
| 底部 | 内容上方 | 单手可达，用于高频操作 |
| 键盘上方 | 键盘附着 | 输入辅助（格式、插入） |

### 5. 状态

| 状态 | 视觉 |
| --- | --- |
| 默认 | `surface.glass-strong` + `border.hairline` + `elevation.1` |
| 按钮按下 | 按钮缩放 0.94 + `fill.pressed` |
| 按钮选中 | 按钮底 `gradient.mid` + 白色图标 |
| 按钮禁用 | 40%，不响应 |

### 6. 布局

- 内容宽度，水平居中；操作多时允许横向滚动
- 顶部变体与导航栏间距 `space.2`（4）
- 底部变体与内容间距 `space.4`（12），距安全区 `space.4`（12）
- 键盘上方时紧贴键盘，不叠加安全区

### 7. 内容

- 最多 7 个操作，超过时把低频操作收进"更多"
- 图标必须语义明确，含义模糊的图标要配短文字
- 破坏性操作不放进 Toolbar（容易误触）

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击按钮 | 执行操作 |
| 长按按钮 | 显示工具提示（文字标签） |
| 无可用操作 | 保持显示但按钮禁用，**不要隐藏整条工具栏**（隐藏会导致布局跳动） |

### 9. 动效

按钮按下 100ms；按钮选中态切换 160ms；工具栏本身不做进出动画。

### 10. 无障碍

- 每个图标按钮必须有标签，长按提示是补充不是替代
- 整条工具栏有分组标签（如"编辑工具"）
- 按钮的选中 / 禁用状态要能被读出
- 触控热区 ≥ 44×44（按钮视觉 36，热区向外扩 4）

### 11. 平台差异

iOS 用 `.toolbar { ToolbarItemGroup }` 或自定义浮层；
Android 用 `TopAppBar` 的 actions 或自定义 `Surface`。
键盘上方变体在 Android 上用 `Modifier.imePadding()` 附着。

### 12. 验收清单

- [ ] 容器高 48、按钮 36×36、圆角 `radius.full`，误差 ≤ 1pt
- [ ] 按钮触控热区 ≥ 44×44
- [ ] 超过 7 个操作时收进"更多"
- [ ] 无可用操作时按钮禁用而不是隐藏整条工具栏
- [ ] 每个图标按钮都有标签，长按显示提示
- [ ] 破坏性操作没有放进工具栏
- [ ] 键盘上方变体不叠加安全区

# 36 · FAB

**视觉参考**：待补 ｜ **优先级** P1

### 1. 用途

页面的**主操作**，悬浮在内容之上，滚动时保持可达。

- **用**：新建任务、记一笔、添加成员——一屏一个的创建类动作
- **不要用**：每屏已经有一个 `filled` 按钮（重复了主操作）；破坏性操作；多个并列动作（用 Toolbar）

### 2. 解剖

容器 + 图标（+ 展开后的一组子操作）。

### 3. 尺寸

| 档 | 尺寸 | 圆角 | 图标 |
| --- | --- | --- | --- |
| 标准 | 56×56 | `radius.fab` 19 | 24 |
| 大 | 64×64 | 22 | 28 |
| 小 | 40×40 | 14 | 20 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 圆角方（默认） | 区别于圆形，和卡片体系更协调 |
| 圆形 | 与系统规范一致时使用 |
| 可展开 | 点击展开 2–4 个子操作，图标旋转 45° 变关闭 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 默认 | `gradient.fill-light`（深色外观 `gradient.fill-dark`）+ `elevation.brand` | — |
| 按下 | 缩放 0.95 | 100ms |
| 滚动 | 向下滚动时缩小到 40 并降低不透明度；向上滚动恢复 | `motion.spring.gentle` |
| 展开 | 图标旋转 45°，子操作逐个出现 | 240ms，错峰 40ms |
| 禁用 | 40% | 无 |

### 6. 布局

- 距右边缘 `space.5`（18 视觉，取 18）
- 距底部安全区 18；有 Tab 栏时改为 92（Tab 栏高 58 + 间距 8 + 留白）
- 是页面**最后一个**进入无障碍焦点序列的交互元素（视觉上压在最上层，但逻辑顺序在内容之后）
- 子操作向上展开，纵向排列，间距 `space.3`（8）

### 7. 内容

- 图标必须配无障碍标签；展开态的子操作用"图标 + 文字"而不是纯图标
- 一个页面最多一个 FAB
- 展开态最多 4 个子操作，超过说明该用整页

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击 | 执行主操作 / 展开子操作 |
| 展开后点击遮罩 | 收起 |
| 展开后点击子操作 | 执行并收起 |
| 下拉滚动 | 缩小但不隐藏（隐藏后用户找不到） |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 按下 | `motion.duration.instant` 100ms |
| 展开 | 240ms，子操作错峰 40ms，`motion.spring.gentle` |
| 图标旋转 | 240ms `motion.spring.snappy` |
| 滚动缩放 | `motion.spring.gentle` |

### 10. 无障碍

- 标签写动作："新建任务"
- 展开态作为一个组朗读，子操作各自可聚焦
- 子操作展开时焦点移入第一个子操作
- 触控热区：标准 56 已满足；小号 40 需向外扩到 44
- 与 Tab 栏共存时，两者不重叠且都可点

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 形态 | 圆角方（与卡片体系一致） | Material 默认圆形，需显式改圆角 |
| 位置 | 距 Tab 栏上方 | 默认在 Tab 栏之上，注意 `Snackbar` 出现时上移 |
| 展开 | 自定义 | `FloatingActionButton` + 自定义子项 |

### 12. 验收清单

- [ ] 标准 56×56、圆角 19、图标 24，误差 ≤ 1pt
- [ ] 一个页面最多一个 FAB
- [ ] 距右 18、距底部安全区 18；有 Tab 栏时改为 92 且不重叠
- [ ] 展开态最多 4 个子操作，子项带文字
- [ ] 图标旋转 240ms，子操作错峰 40ms
- [ ] 向下滚动时缩小但不隐藏
- [ ] 小号 40 的热区补到 ≥ 44
- [ ] 展开时焦点进入第一个子操作，点击遮罩收起
