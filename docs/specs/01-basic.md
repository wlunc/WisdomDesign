# 基础组件规格（01–20）

单一职责、无内部状态机、直接对应平台原生控件。也是 M2 / M3 的实现范围。

# 01 · Button

**视觉参考**：画廊 01 · Button ｜ **优先级** P0 ｜ **两端同名** `WDButton` / `WdButton`

### 1. 用途

触发一个动作。是界面上唯一"会让事情发生"的基础组件。

- **用**：提交表单、确认操作、触发一个明确的动作
- **不要用**：导航到别的页面（用 `WDListRow` 或链接）；筛选（用 `WDChip`）；只有图标没有文字的场合（用 `WDIconButton`）
- **一屏一个主操作**。`filled` 变体每屏最多一个，其余操作降级为 `tonal` / `glass` / `plain`

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 容器 | 必有 | 胶囊底 + 内边距，高度由尺寸档决定 |
| 前置图标 | 可选 | `size.icon.sm`（16），与文字间距 `space.3`（8） |
| 标签 | 必有 | `type.headline`（17/22 · 600） |
| 后置图标 | 可选 | 同前置，只用于"有方向"的动作（下一步、展开） |
| 加载指示 | 条件 | 加载态替换标签，**容器宽度不变** |

前置与后置图标不同时出现——同一个按钮只表达一个方向。

### 3. 尺寸

| 档 | 高度 | 水平内距 | 字号 | 图标 | 圆角 | 最小宽度 |
| --- | --- | --- | --- | --- | --- | --- |
| `sm` | `size.control.sm` 32 | 12 | 13 | 14 | `radius.full` | — |
| `md`（默认） | `size.control.md` 44 | 16 | 15 | 16 | `radius.full` | — |
| `lg` | `size.control.lg` 52 | 20 | 16 | 20 | `radius.full` | — |

表单内的按钮可改用 `radius.md`，与输入框的圆角对齐。
只有图标的场合必须保持 `size.touch-target-min`（44×44）的热区，视觉可以更小。

### 4. 变体

| 变体 | 背景 | 文字 | 描边 | 阴影 | 用在哪 |
| --- | --- | --- | --- | --- | --- |
| `filled` | `gradient.fill`（浅深两端各自取值） | `text.on-fill` | 无 | `elevation.brand` | 唯一主操作 |
| `tonal` | `gradient.surface` | `text.on-soft` | 无 | 无 | 次级操作 |
| `glass` | `surface.glass-strong` | `text.primary` | `border.hairline` | `elevation.1` | 浮在图片或内容之上 |
| `outline` | 透明 | `text.primary` | `border.hairline-strong` | 无 | 中性操作 |
| `plain` | 透明 | `text.brand` | 无 | 无 | 行内操作、列表右侧 |
| `destructive` | `gradient.destructive` | 白 | 无 | `elevation.brand` | 删除、退出等不可逆操作 |

`filled` 的浅色端与深色端分别是 `derived.fill-light-1` / `derived.fill-light-2`，
配 `derived.text-on-fill` 对比度 5.4–6.9:1。**不允许把亮色渐变配白字**。

### 5. 状态

| 状态 | 视觉 | 动效 | 触觉 |
| --- | --- | --- | --- |
| 默认 | 见变体表 | — | — |
| 按下 | 缩放至 `motion.component.press-scale`（0.97），亮度降到 96% | `motion.duration.instant` 100ms | 轻 |
| 聚焦 | 外扩 3pt 光环，`text.brand` 32% 透明 | `motion.duration.fast` | — |
| 禁用 | 整体 40% 不透明度，去掉阴影 | 无 | 不响应 |
| 加载 | 标签原位换成指示器，容器宽度**不变**；保留原标签供读屏 | 指示器持续旋转 | 触发时轻 |
| 悬停 | 仅指针设备，亮度 98% | `motion.duration.instant` | — |

### 6. 布局

- 同一组按钮水平排列，间距 `space.3`（8）
- 竖排时**主操作在上**，间距 `space.4`（12）
- 纵向堆叠的按钮组可以全宽；水平并排的按钮内容宽度即可，不要等宽拉伸
- 宽度不足以放下全部文字时，标签**不换行**，容器向外扩；容器宽度受父级限制时标签截断

### 7. 内容

- 标签 2–6 个汉字，最多 12 个字符
- 动词开头，不用"确定/好的"这类无信息量的词；删除场景直接写"删除"
- 不用句号结尾
- 加载态文案由加载指示器承担，标签不改成"加载中"

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击 | 按下态 → 触发 `onClick`。若 `onClick` 内部会发起异步操作，调用方负责切到加载态 |
| 长按 | 默认不响应。上下文菜单场景由外层容器处理 |
| 拖拽 | 不响应 |
| 键盘 | 空格 / 回车触发；`Tab` 聚焦时显示聚焦光环 |
| 重复点击 | 加载态期间忽略后续点击，不排队 |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 按下 / 抬起 | `motion.duration.instant` 100ms，`cubic-bezier(.2, 1.5, .5, 1)` |
| 加载态切换 | `motion.duration.fast` 160ms 交叉淡化 |
| 聚焦光环 | `motion.duration.fast` 160ms |

按下用弹性曲线（回弹感来自曲线，不是弹簧动画）；状态切换用线性时长。

### 10. 无障碍

- **标签即朗读文本**，不需要额外的 `aria-label`
- 加载态朗读"提交，处理中"，不是"加载中"
- 禁用态用 `aria-disabled` 语义而非移除元素，保证读屏能发现它
- 触控热区不小于 44×44，`sm` 档视觉 32 但热区补到 44
- 文字随动态字体放大，容器高度同步增高，**不裁切**
- 文字与背景对比度 ≥ 4.5:1；图形边界 ≥ 3:1

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | 内部用系统 `Button` + `WDButtonStyle`，同时把 style 暴露出去 | `Surface(onClick)` 包 `Row`，用 `WDButtonVariant` 参数 |
| 系统行为 | 保留 `.disabled`、键盘导航、VoiceOver 角色 | 保留 Ripple；`Modifier` 是必选参数后的第一个可选参数 |
| 按压反馈 | `.scaleEffect` + `WdPressStyle` | `indication = null` + `animateFloatAsState` |

### 12. 验收清单

- [ ] 三个尺寸的高度分别为 32 / 44 / 52，误差 ≤ 1pt
- [ ] 六个变体的背景 / 文字 / 描边与变体表逐项一致，色值全部来自令牌
- [ ] `filled` 浅色外观配深色文字，对比度实测 ≥ 5.4:1
- [ ] 加载态切换时容器宽度不变，无跳动
- [ ] 禁用态仍可被读屏发现，且标注为不可用
- [ ] 动态字体放大到 AX3 不截断、不重叠
- [ ] 触控热区任意档位均 ≥ 44×44
- [ ] 深浅两种外观都验证过，浅色优先

# 02 · IconButton

**视觉参考**：画廊 02 ｜ **优先级** P0

### 1. 用途

纯图标的单一动作。空间紧张或动作含义无歧义时使用。

- **用**：导航栏的搜索/新增、工具条的撤销/重做、列表右侧的更多
- **不要用**：含义有歧义的图标；带文字的场合（用 `WDButton`）；破坏性操作（如删除，必须带文字说明）

### 2. 解剖

容器 + 图标两段。没有标签，**语义完全由无障碍标签提供**。

### 3. 尺寸

| 档 | 视觉尺寸 | 热区 | 图标 | 圆角 |
| --- | --- | --- | --- | --- |
| `sm` | 32×32 | 44×44 | `size.icon.sm/md` 16–20 | `radius.full` 或 `radius.sm` |
| `md`（默认） | 44×44 | 44×44 | `size.icon.lg` 24 | `radius.full` 或 `radius.sm` |

`sm` 档视觉 32，热区必须补到 44——通过加大点击区域而不是放大图标，用负内边距或 `contentShape` 实现。

### 4. 变体

| 变体 | 背景 | 图标色 | 描边 | 用在哪 |
| --- | --- | --- | --- | --- |
| `filled` | `gradient.mid` | 白 | 无 | 强调动作 |
| `tonal` | `gradient.surface` | `text.on-soft` | 无 | 次级动作 |
| `glass` | `surface.glass-strong` | `text.primary` | `border.hairline` | 浮在内容之上（导航栏） |
| `outline` | 透明 | `text.primary` | `border.hairline-strong` | 中性动作 |
| `plain` | 透明 | `text.brand` | 无 | 行内动作 |

### 5. 状态

与 Button 一致：默认 / 按下（缩放 0.97）/ 聚焦（3pt 光环）/ 禁用（40%）。
图标按钮**没有加载态**——加载状态下应当换成 `WDButton` 或骨架。

### 6. 布局

- 一行内最多 3 个，间距 `space.3`（8）
- 导航栏内的图标按钮与屏幕边缘间距 `space.5`（16）

### 7. 内容

- 必须提供无障碍标签，写**动作**而不是图标名：写"搜索"不写"放大镜"
- 图标不配文字时不做视觉截断，图标本身保持完整

### 8. 交互

点击 → 立即执行，**不做二次确认**。
破坏性动作不放在 IconButton 里——没有文字说明的删除按钮是事故源头。
长按：默认不响应；工具栏场景可显示工具提示。

### 9. 动效

同 Button：按下 `motion.duration.instant`，聚焦光环 `motion.duration.fast`。

### 10. 无障碍

- 必须有 `aria-label` / `accessibilityLabel`，否则读屏只能读出"按钮"
- 角色为 `button`，图标本身标记为装饰
- 热区 ≥ 44×44
- 图标与背景对比度 ≥ 3:1

### 11. 平台差异

iOS 用 `Image(systemName:)` + `.frame(minWidth: 44, minHeight: 44)`；
Android 用 `IconButton` 或 `Box(Modifier.size(44.dp).clickable(...))`。

### 12. 验收清单

- [ ] 每个实例都有无障碍标签，且写的是动作不是图标名
- [ ] `sm` 档视觉 32，实测热区 ≥ 44×44
- [ ] 没有出现无文字的破坏性操作
- [ ] 深浅两外观下图标对比度 ≥ 3:1

# 03 · TextField

**视觉参考**：画廊 03 ｜ **优先级** P0

### 1. 用途

单行文本输入。

- **用**：任务名称、成员名、金额、时间
- **不要用**：多行内容（用 TextArea）；选项选择（用 Picker / Radio）；布尔值（用 Switch）

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 字段标签 | 必有 | 常驻在输入框上方，`type.footnote`，用 `text.secondary` |
| 容器 | 必有 | 固定高度 46 |
| 前缀 | 可选 | 图标 17，或文字（货币符号），色 `text.tertiary` |
| 输入区 | 必有 | `type.body`（17），占位符 `text.tertiary` |
| 后缀 | 可选 | **最多一个**：单位 / 清除 / 显隐 / 计数 / 下拉 |
| 辅助文案 | 条件 | 错误时必有；常态可选。`type.footnote` |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 高度 | **46**（固定，所有变体一致） |
| 圆角 | `radius.md` 14 |
| 水平内距 | 12 |
| 前缀与输入区间距 | `space.3` 8 |
| 后缀与输入区间距 | `space.3` 8 |
| 标签与容器间距 | `space.2` 4 |
| 辅助文案与容器间距 | `space.2` 4 |
| 最小宽度 | 190 |

### 4. 变体

| 变体 | 背景 | 描边 | 用在哪 |
| --- | --- | --- | --- |
| `inset`（默认） | `fill.field` | 无 | 表单内 |
| `outline` | 透明 | `border.hairline-strong` | 白底卡片上，视觉更轻 |
| `glass` | `surface.glass-strong` | `border.hairline` | 浮在图片或内容之上 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 默认 | 见变体表，标签 `text.secondary` | — |
| 聚焦 | 描边换 `text.brand` 1.5pt + `text.brand` 18% 光环；标签可高亮 | `motion.duration.fast` 160ms |
| 错误 | 描边换 `status.danger`，下方辅助文案用 `status.danger` | 同聚焦 |
| 禁用 | 整体 40%，不允许聚焦 | 无 |
| 只读 | 背景用 `surface.card-sunken`，文字用 `text.secondary`，可选中不可编辑 | 无 |

### 6. 布局

- 表单里字段纵向排列，间距 `space.5`（16）
- 同一行最多两个字段，此时间距 `space.4`（12）
- 字段容器**默认全宽**，只有同一行两个字段时才各占一半

### 7. 内容

- 标签 2–8 个汉字，**必填，不允许只用占位符当标签**
- 占位符写示例而不是重复标签：标签"任务名称"，占位符"例如：整理储物间"
- 错误文案一句话说清"哪里错了 + 怎么改"："名称已被占用，换一个试试"
- 字数计数显示 `当前/上限`，接近上限时（≥90%）换 `status.warning`

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击容器任意位置 | 聚焦输入区 |
| 聚焦 | 键盘弹出，页面滚动避让，字段保持可见 |
| 输入 | 实时校验只做格式级（数字、邮箱）；内容级校验失焦后再做 |
| 清除按钮 | 清空并保持聚焦 |
| 显隐切换 | 明文/密文切换，图标同步换，**保持光标位置** |
| 回车 | 提交并收起键盘；多字段表单里跳到下一字段 |
| 失焦 | 触发完整校验 |

### 9. 动效

聚焦描边与光环 `motion.duration.fast` 160ms 线性；错误文案出现 160ms 淡入 + 4pt 下移。

### 10. 无障碍

- 字段标签与输入区必须关联，读屏先读标签再读内容
- 错误态读"任务名称，错误，名称已被占用"
- 后缀按钮各自有标签："清除内容"、"显示密码"、"选择单位"
- 输入字号不小于 16（避免 iOS 自动缩放），随动态字体放大时容器高度**同步增高，不裁切**
- 聚焦光环对比度 ≥ 3:1

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 键盘 | 系统键盘 + 安全区避让 | `WindowInsets.ime` 避让 |
| 回车键 | `.submitLabel(.next/.done)` | `ImeAction.Next/Done` |
| 焦点 | `@FocusState` | `FocusRequester` |

**实现注意**：高度固定 46，**不要给输入框容器设 `flex: 1` / `Modifier.weight()`**。
在纵向堆叠里 `flex-basis` 会归零，高度跟着内容变，同一组表单会出现三种高度。

### 12. 验收清单

- [ ] 所有变体、所有状态的容器高度都是 46，误差 ≤ 1pt
- [ ] 标签常驻，没有任何一个样例用占位符代替标签
- [ ] 后缀最多一个，不存在"清除 + 计数"同时出现
- [ ] 错误态有描边变化**且**有文字说明，两个都有
- [ ] 聚焦时光环可见，且字段不被键盘遮挡
- [ ] 输入字号 ≥ 16，动态字体放大后不裁切
- [ ] 读屏先读标签、再读内容、错误时读错误

# 04 · SearchField

**视觉参考**：画廊 04 ｜ **优先级** P0

### 1. 用途

在一个已知集合里查找。**搜索的对象是已知的，筛选的对象是未知的**——这是它和 Chip 的分界。

- **用**：在任务、成员、历史记录里按关键词查找
- **不要用**：几个固定选项之间切换（用 `WDSegmentedControl` 或 `WDChip`）；跳转到别的页面

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 容器 | 必有 | 胶囊底，与输入框同高 |
| 前导图标 | 必有 | 搜索图标 `size.icon.md`，色 `text.tertiary`，位置固定不随状态变动 |
| 输入区 | 必有 | `type.body` 17 |
| 清除按钮 | 条件 | 有值时出现，清空内容但保持聚焦 |
| 取消按钮 | 条件 | 聚焦时出现在**容器外**右侧，不挤占容器内空间 |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 高度 | **46**（与 `WDTextField` 一致，同一页面里两者高度必须相同） |
| 圆角 | `radius.full` |
| 水平内距 | 12 |
| 前导图标与输入区间距 | `space.3` 8 |
| 容器与取消按钮间距 | `space.4` 12 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 标准 | 空态 → 有值 → 聚焦三态 |
| 带取消 | 聚焦时展开取消按钮；不聚焦时不占位 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 空态（未聚焦） | 容器底 `surface.card`，占位符 `text.tertiary` | — |
| 聚焦 | 描边换 `text.brand` 1.5pt + 18% 光环；取消按钮展开 | 160ms |
| 有值 | 右侧出现清除按钮 | 160ms 淡入 |
| 无结果 | 容器保持正常；下方换成 `WDEmptyState` | — |
| 禁用 | 整体 40% | 无 |

### 6. 布局

- 位于页头或列表上方，左右边距 `space.5`（16）
- 与下方内容的间距 `space.4`（12）
- 聚焦展开取消按钮时，**容器宽度收窄，不是整体右移**——列表内容位置保持不动

### 7. 内容

- 占位符写清搜索范围：「搜索任务或成员」，不要只写「搜索」
- 输入 1 个字符即可开始搜，不需要最少字符数
- 无结果文案要给出下一步：「没找到"储物间"，换个词试试」

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 聚焦 | 键盘弹出，取消按钮展开 |
| 输入 | 300ms 防抖后过滤，输入过程中不阻塞 |
| 点击清除 | 清空内容，保持聚焦与取消按钮展开 |
| 点击取消 | 清空内容、收起键盘、取消按钮收回 |
| 回车 | 收起键盘，保留结果 |
| 结果更新 | 通过 `aria-live` 播报「找到 3 项」 |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 取消按钮展开 | `motion.duration.fast` 160ms，宽度与透明度同步 |
| 清除按钮出现 | `motion.duration.fast` 160ms 淡入 |
| 结果刷新 | 不做整列表动画，避免输入时闪烁 |

### 10. 无障碍

- 角色为 `searchbox`，朗读文本包含搜索范围
- 清除按钮标签「清除搜索内容」，取消按钮标签「取消搜索」
- 结果数量变化用 `aria-live="polite"` 播报，**不要播报每次按键**
- 前导图标标记为装饰
- 触控热区 ≥ 44×44；输入字号 ≥ 16

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | 自定义，或 `.searchable` 放在导航栏 | 自定义，或 `SearchBar` |

- [ ] 前导图标位置在任何状态下都不动

# 05 · Switch

**视觉参考**：画廊 05 ｜ **优先级** P0

### 1. 用途

**即时生效**的布尔开关。拨动即写入，没有确认按钮。

- **用**：共享给家人、每日提醒、免打扰
- **不要用**：需要点"保存"才生效的设置（用 `WDCheckbox`）；二选一（用 `WDSegmentedControl` 或 Radio）；会触发不可逆操作的开关

判断标准：如果打开后用户必须再点一次确认，就不该用 Switch。

### 2. 解剖

轨道 + 滑块两段。轨道承担状态色，滑块承担位置。整行可点时，标签在左、开关在右。

### 3. 尺寸

| 档 | 轨道 | 圆角 | 滑块直径 | 行程 |
| --- | --- | --- | --- | --- |
| 标准 | 51×31 | `radius.full` | 27（轨道高 − 4） | 20 |
| 紧凑 | 40×24 | `radius.full` | 20 | 16 |

滑块上下左右各留 2 的内边距。

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 标准 | 只有标签 |
| 带描述 | 标签下方一行 `type.footnote` 用 `text.secondary`，说明开关的后果（"关闭后不再收到推送"） |

描述只在"用户不看清后果就会误操作"时使用，不是默认。

### 5. 状态

| 状态 | 视觉 | 动效 | 触觉 |
| --- | --- | --- | --- |
| 关 | 轨道 `border.hairline-strong`，滑块白 | — | — |
| 开 | 轨道 `gradient.mid`，滑块白 | 轨道 260ms，滑块 300ms | 轻 |
| 按下 | 滑块临时放大到 1.06 | 100ms | — |
| 禁用 | 整体 40%，不响应 | 无 | 无 |

### 6. 布局

- 开关固定在行右侧，与右边缘间距 `space.5`（16）
- 整行可点：点击标签区域同样切换，热区不小于 `size.touch-target-min`
- 与上一行的间距 `space.4`（12）

### 7. 内容

- 标签 4–10 个汉字，动词或名词短语，不用疑问句
- 描述一行，最多 18 个汉字，超过换成两行说明文字而不是截断

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击轨道 | 切换，立即写入 |
| 拖动滑块 | 实时跟随手指，松手按位置吸附到最近的一端 |
| 点击标签区域 | 同点击轨道 |
| 写入失败 | 轨道回弹到原位置 + `WDBanner` 说明原因，**不做静默失败** |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 滑块位移 | `motion.component.switch-knob` 300ms，`cubic-bezier(.2, 1.5, .45, 1)` |
| 轨道变色 | `motion.component.switch-track` 260ms 线性 |
| 按下放大 | `motion.duration.instant` 100ms |

滑块用弹性曲线，轨道用线性——两者时长不同步是刻意的，视觉上滑块"甩"到位、底色随后跟上。

### 10. 无障碍

- 角色为 `switch`，状态为"开"/"关"，读屏读"共享给家人，开，开关"
- 带描述时，描述并入朗读内容
- 触控热区 ≥ 44×44
- 开关状态**不能只靠颜色**表达，滑块位置是主要信号，颜色是辅助
- 禁用态标注为不可用，不可从无障碍树中移除

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | 自定义 `ToggleStyle` | `Switch` + 自定义 `colors` / `thumbContent` |
| 尺寸 | 标准 51×31 | Material 默认较小，需要显式放大到 51×31 |
| 触觉 | `UIImpactFeedbackGenerator(.light)` | `HapticFeedbackType.TextHandleMove` |

### 12. 验收清单

- [ ] 轨道 51×31、滑块 27，行程 20，误差 ≤ 1pt
- [ ] 拖动过程中滑块跟随手指，松手正确吸附
- [ ] 点击标签区域也能切换
- [ ] 切换时有轻触觉
- [ ] 写入失败会回弹并给出说明，不是静默失败
- [ ] 读屏正确朗读"标签 + 开/关"
- [ ] 禁用态仍能被读屏发现
- [ ] 开关状态不依赖颜色单独表达

# 06 · Checkbox

**视觉参考**：画廊 06 ｜ **优先级** P0

### 1. 用途

多选，以及任务清单里的"完成"。

- **用**：多项可同时选中的列表、任务行的完成勾选
- **不要用**：单选项（用 Radio）；即时生效的开关（用 Switch）；筛选标签（用 Chip）

### 2. 解剖

方框 + 勾 + 光晕三段。勾是**描边画出来的**而不是图标，这样才能做描边动画。

| --- | --- |

| 光晕 | 选中瞬间向外扩散的径向光晕，只播一次 |

### 3. 尺寸

| 档 | 方框 | 圆角 | 标签 |
| --- | --- | --- | --- |
| 标准 | `size.checkbox` 26 | 9 | `type.subheadline` 15 |
| 紧凑 | 22 | 7 | `type.footnote` 13 |

方框与标签间距 `space.3`（8）。热区 ≥ 44×44。

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 标准 | 方框 + 标签 |
| 无标签 | 只用于表头全选，必须有独立的无障碍标签 |
| 任务行 | 与 `WDListRow` 组合，勾选后标题加删除线并降到 `text.tertiary` |

### 5. 状态

| 状态 | 视觉 | 动效 | 触觉 |
| --- | --- | --- | --- |
| 未选 | 描边 `border.hairline-strong` 1.5pt，底 `fill.field` | — | — |
| 已选 | 底 `gradient.mid`，无描边，顶部 1pt 内高光，`elevation.brand` 投影 | 勾 260ms 弹出，填充与投影同步 220ms | 轻 |
| 半选 | 同已选底，勾换成 12×2.4 的白色横杠 | 同已选 | 轻 |
| 按下 | 缩放至 `motion.component.checkbox-press`（0.90） | `motion.duration.instant` | 轻 |
| 禁用 | 整体 40%，**保留当前勾选状态** | 无 | 无 |
| 光晕 | 选中瞬间外扩，`brand` 42% → 透明 | `motion.component.checkbox-glow` 400ms | — |

### 6. 布局

- 纵向列表，行间距 `space.4`（12）
- 多列最多两列，列间距 `space.5`（16）
- 任务行内，方框在左，与标题间距 `space.3`（8）

### 7. 内容

- 标签 2–12 个汉字，名词短语或短句
- 不用问句（"是否共享？"），直接写状态（"共享给家人"）
- 任务行标题过长时截断，不换行

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击方框 | 切换，光晕播放一次 |
| 点击标签 | 同方框 |
| 任务行内点击整行 | 切换完成状态 |
| 半选点击 | 变为全选（不做三态循环） |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 勾的描边 | `motion.component.checkbox-draw` 260ms，`cubic-bezier(.2, 1.6, .5, 1)` |
| 填充与投影 | 220ms，同曲线 |
| 光晕扩散 | `motion.component.checkbox-glow` 400ms，只播一次 |
| 按下缩放 | `motion.duration.instant` 100ms |

### 10. 无障碍

- 角色为 `checkbox`，状态为"已选中 / 未选中 / 部分选中"
- 任务行读"整理储物间，未完成，复选框"
- 勾选完成时给出触觉反馈，同时用 `aria-live` 播报"已完成"
- 热区 ≥ 44×44，方框视觉 26
- 选中态不依赖颜色：勾的**形状**是主要信号
- 动态字体放大时方框尺寸不变，只放大标签，行高同步增高

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | 自定义 `ToggleStyle`；勾用 `Path` + `.trim(to:)` 驱动描边 | 自定义 `TriStateCheckbox`；勾用 `Canvas` + `drawPath` |
| 材质 | 系统触觉 | `HapticFeedback` |
| 妥协 | — | 若要贴 Material 规范可退回圆角方块，但必须保留渐变填充与描边动画 |

### 12. 验收清单

- [ ] 方框 26×26、圆角 9，误差 ≤ 1pt
- [ ] 勾是描边动画，不是直接出现的图标
- [ ] 选中时有光晕，且只播一次
- [ ] 半选显示横杠而不是勾
- [ ] 禁用态保留原勾选状态，不是清空
- [ ] 任务行勾选后标题加删除线
- [ ] 触控热区 ≥ 44×44
- [ ] 读屏能读出三态

# 07 · Radio

**视觉参考**：画廊 07 ｜ **优先级** P1

### 1. 用途

在一组互斥选项里选一个，且**选中即生效**。

- **用**：2–5 个并列选项，且用户需要看到全部选项才能决定（仅自己 / 共享给全家）
- **不要用**：超过 5 个选项（改用 `WDPicker`）；需要点"保存"才生效（改用 `WDCheckbox`）；两个选项且语义相反（改用 `WDSwitch` 或 `WDSegmentedControl`）

### 2. 解剖

圆形底 + 内圆点 + 标签。内圆点是**实心圆**而不是勾，用于和 Checkbox 在形状上区分。

### 3. 尺寸

| 档 | 外圆 | 内圆点 | 标签 |
| --- | --- | --- | --- |
| 标准 | 26 | 12 | `type.subheadline` 15 |
| 紧凑 | 22 | 10 | `type.footnote` 13 |

外圆与标签间距 `space.3`（8）；同组内两项间距 `space.4`（12）；热区 ≥ 44×44。

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 标准 | 兜底 |
| 带描述 | 选项下方一行 `type.footnote` 说明差异，仅在选项含义不易区分时使用 |

### 5. 状态

| 状态 | 视觉 | 动效 | 触觉 |
| --- | --- | --- | --- |
| 未选 | 描边 `border.hairline-strong` 1.5pt，底 `fill.field` | — | — |
| 已选 | 底 `gradient.mid`，内圆点白色 `scale(1)` | 内点 200ms 弹出，底 220ms | 轻 |
| 按下 | 缩放至 0.92 | 100ms | 轻 |
| 禁用 | 整体 40%，**保留选中状态** | 无 | 无 |

### 6. 布局

- 纵向排列，组内间距 `space.4`（12）
- 一组最多 5 项，超过改用 `WDPicker`
- 一组内**不换行**：换行会让用户误以为分成两组

### 7. 内容

- 标签 2–10 个汉字，名词短语
- 同组内所有选项的句式保持一致（都是名词，或都是"动词 + 宾语"）
- 不要加"请选择"之类的引导语，选项本身就是引导

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击选项 | 选中该项，同组其余项自动取消 |
| 点击已选项 | **保持选中**，不提供取消（单选组的语义是"必须有一个"） |
| 键盘 | 方向键在组内移动并即时选中，`Tab` 整组进出一个焦点 |

### 9. 动效

内圆点 200ms `cubic-bezier(.2, 1.5, .5, 1)`；外圈底色 220ms 线性；按下缩放 100ms。

### 10. 无障碍

- 每个选项角色为 `radio`，**整组用 `radiogroup` 包裹并给出组标签**（如"可见范围"）
- 读屏朗读"仅自己可见，已选中，单选按钮，第 1 项，共 2 项"
- 方向键切换时即时播报新选项
- 触控热区 ≥ 44×44
- 选中态不依赖颜色：内圆点的**有无**是主要信号

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | 自定义样式 + 分组容器 | `RadioButton` + `selectableGroup()` |
| 键盘 | 系统焦点引擎 | `Modifier.selectableGroup()` 提供方向键 |

### 12. 验收清单

- [ ] 外圆 26、内圆点 12，误差 ≤ 1pt
- [ ] 每个样例都有可见的选中态，浅深两外观都验证过
- [ ] 同组内互斥：选中一项后其余自动取消
- [ ] 点击已选项不会取消选中
- [ ] 一组不超过 5 项、不换行
- [ ] 整组有组标签，读屏能读出"第 n 项，共 m 项"
- [ ] 触控热区 ≥ 44×44

# 08 · Slider

**视觉参考**：画廊 08 ｜ **优先级** P0

### 1. 用途

在连续或较大范围里取值，且**具体数值不如大致位置重要**。

- **用**：完成度、提醒提前量、音量、字号
- **不要用**：需要精确输入数值（用 `WDTextField`）；小范围整数增减（用 `WDStepper`）；二值（用 `WDSwitch`）

### 2. 解剖

轨道 + 已填充段 + 手柄 + 数值标签四段。轨道与填充用同一条 6pt 高的线，靠颜色区分。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 轨道高 | 6 |
| 手柄 | 26（白色 + `elevation.1` + 1pt `border.hairline` 描边） |
| 圆角 | `radius.full` |
| 最小宽度 | 120 |
| 手柄与轨道端点的内缩 | 手柄半径 13，轨道两端各留 13 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 单值 | 默认 |
| 带刻度 | 离散取值，步长按刻度（如提前 1 天 / 2 天 / 1 周），松手吸附 |
| 范围 | 两个手柄，用于区间（如预算下限到上限）。两端手柄不允许交叉，最小间隔 = 1 步长 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 默认 | 轨道 `border.hairline-strong`，填充 `gradient.mid` | — |
| 拖拽 | 手柄放大到 1.15，数值标签跟随手柄移动 | 100ms |
| 聚焦 | 手柄外扩 3pt 光环 | 160ms |
| 禁用 | 整体 45%，手柄变灰，不响应 | 无 |

### 6. 布局

- 轨道上方放标签（如"完成度"），右侧放当前值（"62%"），两者在同一行
- 数值标签用等宽数字，避免拖动时宽度跳动
- 与上下元素间距 `space.4`（12）

### 7. 内容

- 数值格式固定：百分比带 `%`，时间带单位（"1 天前"），金额带货币符号
- 拖动过程中实时更新数值，**松手才算一次有效变更**
- 离散档位时显示档位名称而不是原始数字

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 拖动手柄 | 实时跟随，数值同步更新 |
| 点击轨道 | 跳到该位置并触发一次变更 |
| 拖到端点 | 到边界后不再移动，手柄给出阻力感 |
| 键盘 | 方向键 ±1 步长，`Home` / `End` 跳到两端 |
| 松手 | 触发一次 `onChange`，带轻触觉 |

### 9. 动效

手柄放大与数值更新 100ms（跟随手指，不能有延迟）；聚焦光环 160ms；
点击轨道跳到位置时 200ms 过渡（不是瞬移）。

### 10. 无障碍

- 角色为 `slider`，必须提供 `value` / `min` / `max`，可选 `step`
- 读屏朗读"完成度，62%，可调整"
- 支持读屏的增减手势（iOS 上滑下滑调整）
- 触控热区高度 ≥ 44（轨道视觉 6，热区向上向下各扩 19）
- 数值变化不做 `aria-live` 实时播报，只在松手后播报一次

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | 自定义，或 `Slider` + 自定义轨道 | `Slider` + `SliderDefaults.colors` |
| 触觉 | 到端点时 `UIImpactFeedbackGenerator(.rigid)` | `HapticFeedbackType.LongPress` |

### 12. 验收清单

- [ ] 轨道高 6、手柄 26，误差 ≤ 1pt
- [ ] 拖动实时跟随，无可感知延迟
- [ ] 数值标签用等宽数字，更新时不抖动
- [ ] 点击轨道能跳到该位置，且有 200ms 过渡
- [ ] 到端点后手柄不再移动
- [ ] 松手才触发一次变更，拖动过程中不触发
- [ ] 读屏能读出当前值与可调整状态
- [ ] 热区高度 ≥ 44

# 09 · Stepper

**视觉参考**：画廊 09 ｜ **优先级** P1

### 1. 用途

小范围整数增减，取值精度比 Slider 高、输入成本比 TextField 低。

- **用**：数量（买几个）、人数、重复次数
- **不要用**：范围超过 20（用 `WDTextField`）；连续值（用 `WDSlider`）

### 2. 解剖

减号按钮 + 数值 + 加号按钮，包在一个胶囊容器里。数值区不可编辑，避免键盘与步进冲突。

### 3. 尺寸

| 档 | 容器高 | 按钮宽 | 字号 |
| --- | --- | --- | --- |
| 标准 | 36 | 40 | 14 |
| 紧凑 | 30 | 32 | 13 |

容器圆角 `radius.full`；数值区最小宽 26，居中。

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 标准 | 用于表单 |
| 紧凑 | 用于列表行内 |
| 带单位 | 数值后加单位（如"3 个"），单位用 `text.secondary` |

### 5. 状态

| 状态 | 视觉 |
| --- | --- |
| 默认 | 容器 `surface.glass-strong` + `border.hairline`；按钮符号 `text.brand` |
| 按下 | 按钮区域 `fill.pressed`，`motion.duration.instant` |
| 到下限 | 减号按钮禁用（40%），加号正常 |
| 到上限 | 加号按钮禁用，减号正常 |
| 整体禁用 | 全部 45% |

### 6. 布局

- 表单里右对齐，与字段标签在同一行
- 与相邻元素间距 `space.4`（12）
- 容器宽度随内容变化，不拉伸

### 7. 内容

- 数值用等宽数字，位数变化时容器宽度**可以**变化，但要给出 100ms 宽度过渡避免抖动
- 到边界时不做提示文字，按钮置灰即可

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击 + / − | 步进 1，带轻触觉 |
| 长按 + / − | 连续步进，先慢后快 |
| 到达边界 | 按钮禁用，继续点击无效果、无触觉 |
| 键盘 | 方向键上下调整 |

### 9. 动效

数值切换 100ms 淡入（不是滑动，滑动会让连续步进时的数字糊成一片）；按钮按下 100ms；容器宽度变化 100ms。

### 10. 无障碍

- 容器角色为 `adjustable`（iOS）/ `progressBar`-like 可调整控件（Android）
- 读屏朗读"数量，3，可调整"，并支持直接的增减手势
- **不要**把两个按钮分别独立暴露成焦点——会让读屏用户按多次才能改一个值
- 每个按钮仍需独立的无障碍标签"减少数量" / "增加数量"，供直接点击
- 触控热区 ≥ 44×44（标准档按钮宽 40，热区向外扩 2）

### 11. 平台差异

iOS 无系统 Stepper，需自定义；
Android 无对应控件，用 `Surface` + 两个 `IconButton` 实现。
两端都必须自行保证连续步进的节奏一致。

### 12. 验收清单

- [ ] 标准档容器高 36、按钮宽 40，误差 ≤ 1pt
- [ ] 到上限时加号禁用、到下限时减号禁用，另一个仍可用
- [ ] 长按能连续步进，先慢后快
- [ ] 数值用等宽数字，位数变化时不抖动
- [ ] 读屏是"一个可调整控件"，不是两个独立按钮
- [ ] 触控热区 ≥ 44×44

# 10 · Chip

**视觉参考**：画廊 10 ｜ **优先级** P0

### 1. 用途

轻量标记与筛选。三种用法语义不同，**不要混在同一行**。

| 用法 | 语义 | 可点 |
| --- | --- | --- |
| 展示 | 只说明属性（"全家共享"） | 否 |
| 可选 | 过滤条件（"已完成"） | 是，切换选中 |

### 2. 解剖

容器 + 可选前导图标 + 文字 + 可选删除键。删除键的热区 28×28，不与容器重叠。

### 3. 尺寸

| 档 | 高度 | 水平内距 | 字号 | 圆角 |
| --- | --- | --- | --- | --- |
| 标准 | 32 | 12（带图标时左 10 右 14） | 13 | `radius.full` |
| 紧凑 | 28 | 10 | 12 | `radius.full` |

### 4. 变体

| 变体 | 背景 | 文字 | 描边 |
| --- | --- | --- | --- |
| 展示 | `surface.card` | `text.secondary` | `border.hairline` |
| 可选 · 未选 | `surface.card` | `text.secondary` | `border.hairline` |
| 可选 · 已选 | `gradient.surface` | `text.on-soft` | `text.brand` 42% |
| 可删除 | `surface.card` | `text.secondary` | `border.hairline` |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 默认 | 见变体表 | — |
| 按下 | 缩放至 0.96 | 100ms |

| 禁用 | 40% | 无 |

- 横向排列，间距 `space.3`（8）
- **允许横向滚动**（横向溢出不换行）——换行会让筛选区高度跳动

- 同一行内所有 Chip 高度一致

### 7. 内容

- 文字 2–6 个汉字

### 8. 交互

| 操作 | 结果 |
| --- | --- |

| 点击删除键 | 只删除该芯片，不触发整行点击 |

选中切换 200ms；删除时 240ms 淡出 + 宽度收缩（同排后续芯片左移）；
新芯片插入时 240ms 淡入 + 右移，错峰 20ms。

- 可选芯片角色为 `checkbox`（多选）或 `radio`（单选），朗读"已完成，已选中"
- 删除键标签"移除筛选：妈妈"
- 展示型芯片不作为焦点元素
- 触控热区：可选 32 高需补到 44；删除键 28×28 需补到 44
- 选中态不依赖颜色：已选芯片同时有底色变化和文字加粗

### 11. 平台差异

iOS 用 `Chip` 自定义（系统无对应控件）；

- [ ] 标准高度 32、紧凑高度 28，误差 ≤ 1pt
- [ ] 三种用法没有混在同一行
- [ ] 删除键有独立的触控热区，点击不会触发整行
- [ ] 已选态同时有底色与字重变化，不只靠颜色
- [ ] 横向溢出时滚动而不是换行
- [ ] 删除动画后同排芯片左移，无跳变
- [ ] 触控热区 ≥ 44×44

# 11 · Badge

**视觉参考**：画廊 11 ｜ **优先级** P0

### 1. 用途

状态与计数的紧凑表达。**徽标不单独承载信息**，必须依附在主体上。

- **用**：任务状态（已完成 / 已逾期）、未读数、在线点
- **不要用**：作为主要信息的载体（状态应当同时有文字）；装饰性点缀

### 2. 解剖

胶囊底 + 图标（可选）+ 文字。计数型是纯数字，叠在宿主的右上角。

### 3. 尺寸

| 形态 | 尺寸 | 字号 | 圆角 |
| --- | --- | --- | --- |
| 状态胶囊 | 高 24，水平内距 10 | 11 · 600 | `radius.full` |
| 圆点 | 7×7 | — | `radius.full` |
| 计数 | 高 20，最小宽 20 | 11 · 600 · 等宽 | `radius.full` |

计数徽标相对宿主右上角偏移 -4 / -4，白色描边 2 与宿主分隔。

### 4. 变体

| 变体 | 背景 | 文字 | 用于 |
| --- | --- | --- | --- |
| `shared` | `gradient.surface` | `text.on-soft` | 共享状态 |
| `schedule` | `gradient.mid` | 白 | 时间点 |
| `pending` | `surface.glass-strong` | `text.brand` | 进行中 |
| `success` | `status-soft.success` | `status.success` | 已完成 |
| `warning` | `status-soft.warning` | `status.warning` | 即将到期 |
| `danger` | `status-soft.danger` | `status.danger` | 已逾期 |

### 5. 状态

徽标本身是展示元素，没有按下态。计数为 0 时**整体隐藏**，不留空位。
计数超过 99 显示 `99+`。

### 6. 布局

- 徽标与主体文字间距 `space.2`（4）；一行内最多 2 个徽标
- 计数徽标随宿主一起移动，不参与宿主内部布局
- 状态胶囊在列表行内右对齐

### 7. 内容

- 状态胶囊文字 ≤ 4 个汉字，用名词短语（"已逾期"而不是"这个任务已经超过截止时间了"）
- 徽标文字不换行、不截断；放不下就说明这一处置放的信息过多

### 8. 交互

徽标不可点。宿主可点时，点击宿主触发宿主的动作，不单独触发徽标。

### 9. 动效

计数变化 160ms 淡入缩放（1 → 1.08 → 1）；状态切换 200ms 底色与文字同步过渡。
计数从 0 变 1 时才播放一次，从 1 变 2 只更新数字。

### 10. 无障碍

- 徽标不进入无障碍焦点序列，作为宿主朗读内容的一部分
- 宿主朗读为"提醒，3 条未读"而不是分成两个元素
- 状态胶囊的颜色不是唯一信号：**图标形状必须不同**（对勾 / 三角 / 实心禁止）
- 文字与底色对比度 ≥ 4.5:1

### 11. 平台差异

iOS 用 `Text` + `padding` + `background` 组合；
Android 用 `Badge` / `BadgedBox`，但状态胶囊需要自定义。

### 12. 验收清单

- [ ] 状态胶囊高 24、圆点 7、计数高 20，误差 ≤ 1pt
- [ ] 计数为 0 时完全隐藏，不留占位
- [ ] 计数超 99 显示 99+，宽度能容纳三个字符
- [ ] 计数徽标有白色描边，与宿主图标能分开
- [ ] 六种状态中，除颜色外**图标形状**也各不相同
- [ ] 读屏作为宿主的一部分朗读，不是独立元素

# 12 · Avatar

**视觉参考**：画廊 12 ｜ **优先级** P0

### 1. 用途

代表一个人。在家庭协作场景里，头像是"这是谁的"最省空间的答案。

- **用**：成员标识、任务归属、评论作者

圆形底 + 内容（首字 / 图标 / 照片）+ 可选在线点。

### 3. 尺寸

| 档 | 直径 | 首字号 | 用在哪 |

| `md` | 32 | 12 | 列表行（默认） |
| `lg` | 40 | 14 | 详情页 |

| 状态 | 视觉 |

### 7. 内容

- 首字取名字第一个字符；英文名取首字母大写

### 10. 无障碍

- 朗读成员名，如"妈妈"；不朗读"头像"或首字
- 首字 / 图标标记为装饰
- 在线状态并入朗读："妈妈，在线"

### 12. 验收清单

- [ ] 五档直径 20 / 28 / 32 / 40 / 56，误差 ≤ 1pt
- [ ] 同一成员在不同页面的头像配色一致
- [ ] 无照片时退回文字头像，不出现破图
- [ ] 在线点 10×10 且有 2pt 白描边
- [ ] 离线状态不显示灰点
- [ ] 读屏朗读成员名而不是首字
- [ ] 浅深两外观下头像与背景都能分辨

# 13 · AvatarStack

**视觉参考**：画廊 13 ｜ **优先级** P0

### 1. 用途

一眼看出"有多少人参与"。用于卡片头部、任务归属、共享状态。

- **用**：成员数 2 人及以上
- **不要用**：1 个人（直接用 `WDAvatar`）；需要精确知道每个人是谁（用完整列表）

### 2. 解剖

最多 4 个头像 + 溢出计数。溢出项显示 `+n`，底色用 `surface.glass-strong`。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 头像档位 | `sm` 28 或 `md` 32 |
| 重叠量 | 直径的 30%（28 → 8，32 → 9） |
| 描边 | 2pt，颜色取所在容器底色（卡片或画布） |
| 最大显示数 | 4 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 标准 | 最多 4 个 + 溢出计数 |
| 无溢出 | 总数 ≤ 4 时不显示 `+n` |

### 5. 状态

堆叠本身无状态。成员变动时（新增/离开）用 240ms 淡入淡出，不重排已有位置。

### 6. 布局

- 与右侧文字间距 `space.3`（8）
- 与其他元素竞争空间时，**优先压缩堆叠**（减少显示数量），而不是压缩文字
- 堆叠总宽 = 直径 + (显示数 − 1) × (直径 − 重叠量)

### 7. 内容

- `+n` 中的 n = 总人数 − 已显示数
- 少于 2 人不使用堆叠
- 溢出项用 `text.secondary` 而不是某个成员的配色

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击堆叠 | 展开完整成员列表（用 `WDBottomSheet`） |
| 点击单个头像 | 打开该成员资料 |
| 点击 `+n` | 同点击堆叠 |

### 9. 动效

展开时成员逐个进入，错峰 `motion.component.list-stagger`（20ms），240ms `motion.spring.gentle`。

### 10. 无障碍

- 作为**一个**元素朗读："家庭成员 6 人：我、妈妈、爸爸、妹妹，另有 2 人"
- 不逐个朗读每个头像，否则读屏用户要听 6 遍才能往下走
- 触控热区 ≥ 44×44（堆叠整体）

### 11. 平台差异

两端都需自定义。注意 iOS 的 `HStack` 负间距与 Android 的 `Row` + `offset` 在重叠处描边的绘制顺序，
必须让**右侧头像压在左侧之上**，否则描边会被盖住。

### 12. 验收清单

- [ ] 重叠量为直径的 30%，误差 ≤ 1pt
- [ ] 最多显示 4 个，超出显示 `+n`，n 计算正确
- [ ] 右侧头像压在左侧之上，描边不被遮挡
- [ ] 少于 2 人不显示堆叠
- [ ] 空间不足时优先减少显示数量，不压缩文字
- [ ] 读屏作为单个元素朗读，包含人数与姓名
- [ ] 触控热区 ≥ 44×44

# 15 · ProgressBar

**视觉参考**：画廊 15 ｜ **优先级** P0

### 1. 用途

线性进度。任务完成度、上传下载、多步骤流程。

- **用**：有一个明确的总量，进度可以量化
- **不要用**：等待时间未知且没有总量（用不确定态或 Skeleton）；强调单一指标（用 `WDProgressRing`）

### 2. 解剖

轨道 + 填充两段。轨道用浅色，填充用中蓝，两者颜色差是唯一的进度信号。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 高度 | 6 |
| 圆角 | `radius.full` |
| 最小宽度 | 100 |
| 分段模式的段间距 | 2 |

### 4. 变体

| 变体 | 说明 | 用在哪 |
| --- | --- | --- |
| 确定 | 按百分比填充 | 上传、下载 |
| 分段 | 用 n 段表示"n 项里完成几项" | 家务完成度（比百分比直观） |
| 不确定 | 一段来回移动，不表达进度 | 等待时间未知 |
| 完成 | 填满 + `status.success` 底色 | 流程结束 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 进行中 | 填充 `gradient.mid` | 数值变化 240ms 线性 |
| 完成 | 填充换 `status.success` | 到达 100% 时 300ms 过渡 + 一次成功触觉 |
| 不确定 | 一段 35% 宽来回移动 | 1.4s 循环 |
| 禁用 | 整体 45% | 无 |

### 6. 布局

- 轨道上方放说明文字，右侧放数值（"45%"），两者同一行
- 与上下元素间距 `space.4`（12）
- 默认全宽；卡片内跟随卡片内边距
- 多段进度纵向排列，间距 `space.3`（8）

### 7. 内容

- 百分比用等宽数字
- 分段模式显示"3 / 5"而不是"60%"
- 数值不超过 100%，超过时截断并记录错误

### 8. 交互

不可交互。需要用户操作才能推进时，用 `WDButton` 而不是可点进度条。

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 数值变化 | 240ms 线性（不用缓出，缓出会让接近完成时看起来卡住） |
| 首次出现 | `motion.component.progress-easeout` 3200ms 缓出 |
| 不确定态 | 1.4s 循环，`ease-in-out` |

不确定态**超过 1 秒**才显示，避免一闪而过。

### 10. 无障碍

- 角色为 `progressbar`，必须提供 `valuenow` / `valuemin` / `valuemax`
- 朗读"上传进度，45%"
- 不确定态不提供 `valuenow`，朗读"加载中"
- 进度变化不做实时 `aria-live` 播报，只在跨越 25% / 50% / 75% / 100% 时播报
- 填充与轨道的对比度 ≥ 3:1

### 11. 平台差异

iOS 用 `ProgressView(value:)` + 自定义 `tint`；
Android 用 `LinearProgressIndicator(value)` + `trackColor`，不确定态用 `indeterminate = true`。

### 12. 验收清单

- [ ] 高度 6、圆角 `radius.full`
- [ ] 填充与轨道对比度 ≥ 3:1，浅深两外观都验证
- [ ] 数值不超 100%，超出时不出视觉异常
- [ ] 分段模式显示"3 / 5"，段数等于总量
- [ ] 不确定态在 1 秒后才出现
- [ ] 到达 100% 时有成功触觉且只触发一次
- [ ] 读屏能读出当前值与总量

# 16 · ProgressRing

**视觉参考**：画廊 16 ｜ **优先级** P0

### 1. 用途

环形进度。用于**需要强调的单一指标**，因为环比线占用更多视觉重量。

- **用**：一张卡片里的核心指标（本周家务完成度）、连续打卡
- **不要用**：一行里出现 3 个以上（视觉过载）；纯等待（用不确定态）

### 2. 解剖

轨道环 + 进度弧 + 环内内容（数值或图标）。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 直径 | 60（标准）/ 44（紧凑） |
| 线宽 | 6（标准）/ 5（紧凑） |
| 起点 | 12 点方向，顺时针 |
| 环内留白 | 直径 − 2 × 线宽 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 百分比 | 环内显示"60%" |
| 计数 | 环内显示"3/5"，用于离散总量 |
| 完成 | 环色换 `status.success`，环内显示对勾 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 增长 | 弧从 0 长到目标值 | 3200ms 缓出，数字同步递增 |
| 完成 | 环色转 `status.success` | 弹一下 + 成功触觉，只播一次 |
| 停滞 | 环色降饱和到 70% | 无 |

### 6. 布局

- 环内数字用 `type.title2` 等宽
- 与右侧文字间距 `space.5`（16）
- 一张卡最多一个环
- 环与文字垂直居中对齐

### 7. 内容

- 环内数字不超过 4 个字符（"60%"、"3/5"、"完成"）
- 环外必须有说明文字，环本身不解释自己代表什么
- 计数模式的分子不超过分母

### 8. 交互

默认不可交互。需要点击时整块（环 + 文字）作为热区，不要只让环可点。

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 首次增长 | `motion.component.progress-easeout` 3200ms 缓出 |
| 完成反馈 | `motion.spring.bouncy` 一次，配合成功触觉 |
| 数值更新 | 数字 240ms 过渡，与弧同步 |

**不用线性**：线性增长在接近结束时看起来像卡住。

### 10. 无障碍

- 作为整体朗读"本周家务，已完成 3 项，共 5 项，60%"
- 环本身标记为装饰，信息由文字承担
- 旋转的进度弧不触发持续播报，只在完成时播报一次
- 环与轨道对比度 ≥ 3:1；环内数字与环内底色对比度 ≥ 4.5:1

### 11. 平台差异

iOS 用 `Circle().trim(from:to:)` + `.stroke(style:)`；
Android 用 `Canvas` + `drawArc`，或用 `CircularProgressIndicator` 的 `progress` 参数自定义线宽。
两端都要保证线帽是**圆头**（`strokeCap: .round` / `StrokeCap.Round`）。

### 12. 验收清单

- [ ] 直径 60、线宽 6，起点在 12 点方向且顺时针
- [ ] 线帽为圆头
- [ ] 增长用缓出，数字与弧同步，结束不卡顿
- [ ] 完成后环色转成功色并只弹一次
- [ ] 环内数字 ≤ 4 个字符，用等宽数字
- [ ] 环与轨道对比度 ≥ 3:1，环内数字 ≥ 4.5:1
- [ ] 读屏朗读"总量 + 已完成 + 百分比"，不是只读百分比

# 17 · Card

**视觉参考**：画廊 17 ｜ **优先级** P0

### 1. 用途

把一组相关内容圈在一起。**卡片是分组手段，不是装饰**。

- **用**：一组相关的信息、一张图上加一段文字、需要整体可点的内容块
- **不要用**：单个列表项（用 `WDListRow`）；只是为了"看起来有层次"而加卡片；卡片里再套卡片

判断标准：如果去掉卡片边界、改用间距也能读明白，就不要用卡片。

### 2. 解剖

容器 + 内边距 + 内容三段。内容可以是任意组合，但容器本身不带任何内置结构。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 内边距 | `space.5` **16（固定，所有变体一致）** |
| 圆角 | `radius.xl` 24 |
| 卡间距 | `space.4` 12 |
| 分组间距 | `space.7` 24 |
| 最小宽度 | 不设，由父级决定 |

嵌套时内层圆角 = 外层圆角 − 内边距（24 − 16 = 8，即 `radius.xs`）。

### 4. 变体

| 变体 | 背景 | 描边 | 阴影 | 用在哪 |
| --- | --- | --- | --- | --- |
| `elevated`（默认） | `surface.card` | `border.hairline` | `elevation.1` | 主要内容卡片 |
| `glass` | `surface.glass-strong` | `border.hairline` | `elevation.1` + 背景模糊 | **浮在内容或图片之上时** |
| `outline` | 透明 | `border.hairline` | 无 | 密集列表、设置项 |
| `sunken` | `surface.card-sunken` | 无 | 无 | 卡内嵌块、次级信息 |
| `media` | `surface.card` | `border.hairline` | `elevation.1` | 顶部图片 + 文字区 |

**只有 `glass` 带背景模糊**。其余变体一律实底——在同一个圆角上叠"半透明 + 描边 + 内高光 + 背景模糊"，
浏览器在圆角处采样背景会产生一圈重影，这是肉眼可见的瑕疵。

### 5. 状态

| 状态 | 视觉 |
| --- | --- |
| 静态 | 见变体表 |
| 可点 · 按下 | 整卡亮度降到 96%，`motion.duration.instant` |
| 可点 · 禁用 | 整体 40% |

卡片默认**不可点**。只有整卡确实是一个动作时才加按下反馈，且这种情况下不应再在卡内放箭头。

### 6. 布局

- 卡片之间 `space.4`（12），分组之间 `space.7`（24）
- **用间距表达分组，不要用分割线**
- 卡片宽度由父级决定，默认撑满可用宽度
- 卡内元素纵向排列，间距 `space.3`（8）；主标题与副标题间距 `space.1`（2）

### 7. 内容

- 一张卡表达一件事。卡内出现两个不相关的主题就应该拆成两张
- 标题一行，最多 20 个汉字，超出截断
- 正文最多三行，超出截断并在末尾加省略号

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击（可点卡） | 整卡响应，按下时整卡降亮度 |
| 点击（静态卡） | 不响应，也不显示任何按下反馈 |
| 卡内子元素可点 | 子元素优先响应，事件不冒泡到整卡 |

### 9. 动效

卡片本身不做进出动画（避免列表滚动时抖动）。
按下反馈 `motion.duration.instant` 100ms；`media` 变体的图片加载完成用 160ms 淡入，不用缩放。

### 10. 无障碍

- 静态卡不进入无障碍焦点序列，内容逐项朗读
- 可点卡作为整体朗读，角色为 `button`，朗读文本由卡内标题提供
- 卡内不要出现嵌套的可点区域（整卡可点时）
- 文字与卡片底色的对比度 ≥ 4.5:1；`outline` 变体描边与背景对比度 ≥ 3:1

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 圆角 | `RoundedRectangle(cornerRadius:style: .continuous)` 连续曲率 | `RoundedCornerShape`，数值 **+2** 补偿曲率差异 |
| 模糊 | iOS 26 用 `glassEffect`，17–25 用 `.ultraThinMaterial` | Haze 库；降级为 88% 纯色 + 描边 |
| 可点 | `Button { } label: { }` + `.buttonStyle(.plain)` | `Surface(onClick = ...)` |

### 12. 验收清单

- [ ] 所有变体内边距都是 16，误差 ≤ 1pt
- [ ] 只有 `glass` 用了背景模糊，其余变体是实底
- [ ] 卡片圆角处没有可见重影或双层描边
- [ ] 嵌套时内层圆角 = 外层圆角 − 内边距
- [ ] 分组之间用 24pt 间距，没有用分割线代替间距
- [ ] 静态卡没有按下反馈
- [ ] 可点卡内的子元素可点区域不会误触发整卡
- [ ] 深浅两外观下卡片与背景都能分辨（对比度 ≥ 3:1）

# 18 · ListRow

**视觉参考**：画廊 18 ｜ **优先级** P0

### 1. 用途

列表里的一行。承载"一条记录 + 一个动作"。

- **用**：设置项、任务项、成员项、任意可枚举的内容
- **不要用**：一行的内容超过三行文字（改用 `WDListSection` 里的卡片）；需要横向比较多个字段的场合（用 Table）

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 前导 | 可选 | 图标底座 34×34（`radius.sm`）或头像，或勾选框 |
| 文本区 | 必有 | 标题 `type.subheadline`；副标题 `type.caption1` 用 `text.secondary` |
| 尾部 | 可选 | 值文本 / 徽标 / 头像 / 箭头，**最多一个** |
| 分隔线 | 条件 | 从文本区起始内缩，末行不显示 |

### 3. 尺寸

| 行数 | 行高 |
| --- | --- |
| 单行 | 44 |
| 双行 | 60 |
| 三行 | 76 |

水平内距 16（首尾一致）；各段间距 `space.4`（12）；分隔线左内缩 = 16 + 34 + 12 = 62。

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 单行 / 双行 / 三行 | 按内容量选择，不为了"好看"加副标题 |
| 带选择 | 选中时左侧 3pt 品牌色条 + `brand` 8% 透明底 |
| 带勾选 | 前导换成 `WDCheckbox`，任务行形态 |
| 禁用 | 整体 40%，不响应 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 默认 | 透明底 | — |
| 按下 | 整行 `fill.pressed` | `motion.duration.instant` 100ms |
| 选中 | 左侧 3pt 品牌条 + 浅底 | `motion.duration.fast` 160ms |
| 禁用 | 整体 40% | 无 |

### 6. 删除

| 阶段 | 规格 |
| --- | --- |
| 左滑 | 整行左移，右侧露出「删除」，宽 86，底 `gradient.destructive`，白色图标 + 文字 |
| 松手 | 位移 < 阈值时吸附回 0，**不删除**；≥ 阈值时直接删除，不再要求二次确认 |
| 删除后 | 底部弹撤销条，停留 5 秒，可一键恢复；超时后真正删除 |
| 无障碍 | 提供"删除"的自定义操作，不要求用户必须会左滑 |
| 撤销 | 恢复整行位置 + 淡入，`motion.duration.fast` |

**不做二次确认弹窗**——撤销条比弹窗少一步，且不会打断连续操作。

### 7. 多选

长按进入多选：顶部显示"已选 n 项"，底部换成「取消 / 删除」工具条，行前导换成勾选框。
批量删除同样给撤销，一次撤销恢复整批。退出多选时清空选择。

### 8. 内容

- 标题一行，最多 20 个汉字，超出截断
- 副标题一行，最多 24 个汉字，超出截断
- 尾部值文本右对齐，数字用等宽
- 末行不画分隔线

### 9. 交互

| 操作 | 结果 |
| --- | --- |
| 点击 | 整行响应；尾部有箭头表示进入下一级 |
| 长按 | 进入多选 |
| 左滑 | 露出删除 |
| 右滑 | 默认不响应；可配置为"标记完成"，但不要和左滑同时存在竞争动作 |

### 10. 无障碍

- 整行作为一个元素朗读："整理储物间，18:00 前，未完成，按钮"
- 前导图标标记为装饰；头像朗读成员名
- 分隔线不进入无障碍树
- 触控热区 = 整行高度，任意档位均 ≥ 44
- 提供"删除"自定义操作，左滑只是快捷方式

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 左滑 | `.swipeActions`，系统提供手势与吸附 | `SwipeToDismissBox`，需要自己实现吸附与阈值 |
| 多选 | `.environment(\.editMode)` 或自定义 | 自定义 `SelectionContainer` |
| 分隔线 | 系统 `List` 自带 | 手动 `Divider`，注意末行不画 |

### 12. 验收清单

- [ ] 三种行数的高度分别为 44 / 60 / 76，误差 ≤ 1pt
- [ ] 分隔线从文本区起始内缩，末行不显示
- [ ] 尾部最多一个元素，不存在"箭头 + 徽标"并存
- [ ] 左滑未达阈值松手会回弹，不删除
- [ ] 删除后出现撤销条，停留 5 秒，能恢复
- [ ] 读屏提供"删除"操作，不强制用户左滑
- [ ] 按住进多选后，退出时选择被清空
- [ ] 动态字体放大后行高同步增高，文字不裁切

# 19 · ListSection

**视觉参考**：画廊 19 ｜ **优先级** P0

### 1. 用途

把列表项分组。**分组的边界靠间距和标题，不靠分割线**。

- **用**：同一页面有多组语义不同的内容（今天 / 本周）
- **不要用**：只有一组内容（直接用 `WDListRow` 列表）；分组内只有一项且不需要标题

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 分组标题 | 必有 | `type.overline` 12 · 500 · 字距 +0.6，色 `text.secondary` |
| 标题右侧动作 | 可选 | 分组级操作（"编辑"/"全部"），`text.brand`，**最多一个** |
| 内容容器 | 必有 | 一个卡片，内部是 `WDListRow` 序列 |
| 页脚 | 可选 | 汇总信息，`type.footnote`，色 `text.secondary` |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 标题与内容间距 | `space.3`（8） |
| 内容与页脚间距 | `space.2`（4） |
| 分组与分组之间 | `space.7`（24） |
| 页面左右边距 | `space.5`（16） |

标题左侧与卡片内文本对齐时额外缩进 `space.1`（2）。

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 标准 | 标题 + 卡片 |
| 带动作 | 标题右侧加一个文字动作 |
| 带页脚 | 卡片下方加一行汇总 |

### 5. 状态

分组本身无状态。空分组**整个隐藏**（连标题一起），不要显示空标题。

### 6. 布局

- 分组纵向排列，间距 24
- 分组内行与行之间由 `WDListRow` 自己处理分隔线
- 同一页面最多 4 个分组，超过时考虑用 Tab 拆分
- 分组标题**左对齐**，与卡片左边缘对齐，不要居中

### 7. 内容

- 标题 ≤ 6 个汉字，用时间或类别名词（"今天"、"本周"、"家庭共享"）
- 标题与页脚不用来放操作说明
- 页脚一行，≤ 20 个汉字，写汇总而不写引导语（"共 2 项，已完成 1 项"而不是"点击查看更多"）

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击标题右侧动作 | 执行分组级操作 |
| 点击标题文字 | 不响应（标题不是按钮） |
| 点击页脚 | 不响应 |

### 9. 动效

无。分组不做进出动画，避免列表滚动时抖动。

### 10. 无障碍

- 分组标题作为 `header` 语义，读屏用户可快速跳转到分组
- 读屏顺序：标题 → 标题右侧动作 → 组内各行 → 页脚
- 页脚作为分组的补充说明朗读
- 分组标题与背景对比度 ≥ 4.5:1

### 11. 平台差异

iOS 用 `Section(header:)` 放进 `List`，或自定义 `LazyVStack` + `pinnedViews`；
Android 用 `stickyHeader` 或直接自定义 `Column`，注意分组之间不要用 `Divider` 代替间距。

### 12. 验收清单

- [ ] 分组之间间距 24，且**没有用分割线**代替间距
- [ ] 标题字号 12、字重 500、字距 +0.6
- [ ] 标题与卡片左边缘对齐
- [ ] 空分组整体隐藏，不出现空标题
- [ ] 标题右侧最多一个动作
- [ ] 页脚只写汇总信息，不写引导语
- [ ] 读屏能把标题识别为分组标题

# 20 · Icon

**视觉参考**：画廊 20 ｜ **优先级** P0

### 1. 用途

表达概念或状态的最小图形单位。**图标不单独承载操作**。

- **用**：配合文字做视觉锚点；需要快速识别的位置（Tab 栏、列表前导）
- **不要用**：单独表达一个动作（必须包在 `WDIconButton` 里）；需要用颜色区分的状态（图标形状本身要能区分）

### 2. 解剖

图标 + 可选底座两段。

| 底座 | 尺寸 | 圆角 | 背景 | 图标色 |
| --- | --- | --- | --- | --- |
| 无 | — | — | — | `currentColor` |
| 浅底座（默认） | 34×34 | `radius.sm` | `gradient.surface` | `text.on-soft` |
| 深底座 | 34×34 | `radius.sm` | `gradient.mid` | 白 |
| 大底座 | 40×40 | `radius.lg` | `gradient.surface` | `text.on-soft` |

### 3. 尺寸

| 档 | 尺寸 | 用在哪 |
| --- | --- | --- |
| `sm` | 16 | 行内文字旁、尾部 |
| `md` | 20 | 表单前缀、列表 |
| `lg` | 24 | 导航栏、Tab 栏、工具栏 |
| `xl` | 28 | 强调、空状态 |

同一层级内不混用档位。描边粗细按尺寸匹配：24pt 图标线宽约 1.8–2。

### 4. 变体

同一语义在两端各有一套：iOS 用 SF Symbols（优先 `.rounded` 变体），Android 用 Material Symbols Rounded。
两端靠**语义名称**对照，不逐像素对齐。

### 5. 状态

图标本身没有状态，状态由容器承担（按钮的按下/禁用、Tab 的选中）。
唯一例外：Tab 栏选中态换 `text.brand` 并把标签加粗，**不换图标形状**。

### 6. 布局

- 图标与文字的间距 `space.3`（8）
- 图标与容器边缘的间距不小于 `space.3`（8）
- 图标在容器内居中，不做基线对齐

### 7. 内容 · 语义对照表

| 语义 | SF Symbols | Material Symbols |
| --- | --- | --- |
| 首页 | `house.fill` | `home` |
| 成员 | `person.2.fill` | `group` |
| 日历 | `calendar` | `calendar_month` |
| 提醒 | `bell.fill` | `notifications` |
| 搜索 | `magnifyingglass` | `search` |
| 设置 | `gearshape.fill` | `settings` |
| 新增 | `plus` | `add` |
| 更多 | `ellipsis` | `more_horiz` |
| 进入 | `chevron.right` | `chevron_right` |
| 完成 | `checkmark.circle.fill` | `check_circle` |
| 删除 | `trash` | `delete` |

新增图标必须同时补齐两端的名称，缺一个视为未完成。

### 8. 交互

图标本身不可点。可点时包在 `WDIconButton` 里，热区 ≥ 44×44。

### 9. 动效

图标不单独做动画。选中态变化用 `motion.duration.fast` 160ms 变色，
不用旋转或缩放——旋转图标会让界面显得廉价。

### 10. 无障碍

- 装饰性图标标记为隐藏，不进入无障碍树
- 作为唯一视觉信息的图标（如状态点）必须有文字或无障标签
- 图标与背景对比度 ≥ 3:1
- 不依赖颜色区分图标含义，形状必须不同

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 图标集 | SF Symbols，优先 `.rounded` | Material Symbols Rounded |
| 尺寸控制 | `.font(.system(size:))` + `.imageScale` | `Icon(painter, Modifier.size())` |
| 多色 | `.symbolRenderingMode(.hierarchical)` | `Icon` 单色，多色需自绘 |

### 12. 验收清单

- [ ] 四个尺寸档位分别为 16 / 20 / 24 / 28，同一层级不混用
- [ ] 两端语义名称对照表已补齐，没有只做一端的图标
- [ ] 图标底座尺寸 34×34、圆角 `radius.sm`
- [ ] 没有任何一个可点图标游离在按钮之外
- [ ] 装饰图标不进入无障碍树
- [ ] Tab 选中态只换色和字重，不换图标形状
- [ ] 图标与背景对比度 ≥ 3:1
