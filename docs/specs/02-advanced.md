# 21 · SegmentedControl

**视觉参考**：高级画廊 21 ｜ **优先级** P0

### 1. 用途

2–5 个互斥选项之间切换，**切换即时生效，内容在同一页面内替换**。

- **用**：同一份数据的不同视图（今天 / 本周 / 全部）
- **不要用**：超过 5 项（用 `WDPicker`）；需要点保存才生效（用 `WDRadio`）；跳转到不同页面（用 `WDTabBar`）

分界线：切完之后**页面标题不变**，只是内容换了，就是 SegmentedControl。

### 2. 解剖

| 段 | 说明 |
| --- | --- |
| 容器 | 胶囊，内边距 3，底 `surface.card` 或玻璃 |
| 选中指示块 | 圆角胶囊，随选中项滑动；底色 `surface.card-solid` + `elevation.1` |
| 各段 | 等宽，文字居中，竖向居中 |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 容器高 | 38（内容 32 + 上下内边距 3） |
| 单段最小宽 | 56 |
| 段水平内距 | 14 |
| 字号 | 13 · 500（选中 600） |
| 圆角 | `radius.full` |

### 4. 变体

| 变体 | 容器底 | 用在哪 |
| --- | --- | --- |
| 玻璃 | `surface.glass` + `border.hairline` | 浮在内容或图片之上 |
| 实底 | `fill.field` | 页面内常规位置 |

2–5 段均可；段宽等分，不按文字长度分配。

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 未选 | 文字 `text.secondary` | — |
| 选中 | 指示块滑到该段；文字 `text.primary` 600 | 指示块 280ms `motion.spring.snappy`；文字 160ms |
| 按下 | 该段文字临时降到 70% 不透明度 | 100ms |
| 禁用 | 整体 40%，不响应 | 无 |

### 6. 布局

- 默认**内容宽度**（按段数与最小宽撑开）；需要撑满时用全宽并在两端留 `space.5`
- 与下方内容间距 `space.5`（16）
- 不与返回按钮、标题放在同一行

### 7. 内容

- 每段 2–4 个汉字，等长最佳
- 段文字不用标点、不用换行
- 同一组内句式一致（都是名词，或都是时间范围）

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击未选项 | 切换，指示块滑动，内容替换 |
| 点击已选项 | **不重复触发**，不重置内容滚动位置 |
| 横向拖动指示块 | 支持时实时跟随，松手吸附；不支持时只响应点击 |
| 键盘 | 方向键在段之间移动并即时切换 |

内容切换时**保留各视图自己的滚动位置**，不共用。

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 指示块滑动 | 280ms，`motion.spring.snappy` |
| 文字颜色与字重 | `motion.duration.fast` 160ms |
| 内容替换 | 不做交叉淡化——同页面切换用直接替换，避免重影 |

### 10. 无障碍

- 容器角色为 `tablist`，每段角色为 `tab`，并标注"第 n 项，共 m 项"
- 选中项标注 `aria-selected="true"`
- 内容区角色为 `tabpanel`，与对应 tab 关联
- 触控热区：单段高度 38 需补到 44（纵向向外扩 3）
- 选中态不依赖颜色：指示块的位置与文字字重同时变化

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | 自定义（系统 `Picker(.segmented)` 外观不可控） | `SingleChoiceSegmentedButtonRow` |
| 指示块 | `matchedGeometryEffect` | `Modifier.offset` + `animateDpAsState` |

### 12. 验收清单

- [ ] 容器高 38、单段最小宽 56，误差 ≤ 1pt
- [ ] 段宽等分，不按文字长度分配
- [ ] 指示块滑动用弹簧曲线，280ms 内到位
- [ ] 点击已选项不重复触发，滚动位置不重置
- [ ] 切换视图时各视图保持各自滚动位置
- [ ] 触控热区 ≥ 44
- [ ] 读屏能读出"第 n 项，共 m 项"与选中状态

# 22 · Picker

**视觉参考**：高级画廊 22 ｜ **优先级** P1

### 1. 用途

从 **5 个以上**的选项里选一个。

- **用**：分类、成员、频率、单位等选项较多的单选
- **不要用**：≤ 5 项（用 `WDSegmentedControl` 或 `WDRadio`）；多选（用 `WDCheckbox` 列表）；日期（用 `WDDatePicker`）

### 2. 解剖

| 段 | 说明 |
| --- | --- |
| 触发入口 | 一行，左侧标签，右侧当前值 + `chevron-down` |
| 弹出层 | 选项列表，可滚动，当前项打勾 |
| 遮罩 | 点击关闭（不提交） |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 触发入口高 | 44 |
| 选项行高 | 44 |
| 弹出层最小宽 | 180，最大宽 = 屏幕宽 − 32 |
| 圆角 | `radius.md` 14 |
| 选项水平内距 | 14 |

### 4. 变体

| 形态 | 说明 | 用在哪 |
| --- | --- | --- |
| 菜单 | 从触发入口下方展开 | 选项 ≤ 10 |
| 滚轮 | 底部弹出滚轮 | 选项多且需要快速滚动 |
| 内联 | 直接平铺在页面里 | 选项 ≤ 8 且表单需要一眼看全 |

同一表单里只用一种形态。

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 默认 | 值为 `text.primary`，箭头 `text.tertiary` | — |
| 未选 | 显示"请选择"，色 `text.tertiary` | — |
| 展开 | 弹出层淡入 + 从触发入口方向缩放 0.96 → 1 | 240ms `motion.spring.gentle` |
| 已选 | 当前项左侧打勾，其余等高占位 | — |
| 禁用 | 整体 40% | 无 |

### 6. 布局

- 触发入口在表单里右对齐，与标签同一行
- 弹出层从触发入口对齐展开，空间不足时自动翻转方向
- 弹出层与触发入口间距 `space.2`（4）

### 7. 内容

- 选项文字 2–8 个汉字，左对齐
- 支持分组标题（`type.overline`），分组内选项缩进 `space.5`
- 当前值超长时截断，不换行

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击触发入口 | 展开 |
| 点击选项 | 选中、关闭、触发一次 `onChange` |
| 点击遮罩 / `Esc` | 关闭，不改变当前值 |
| 展开后滚动 | 选项列表内部滚动，遮罩不滚动 |

展开时**把当前选项滚到可视区中间**，不要让用户自己找。

### 9. 动效

弹出层 240ms `motion.spring.gentle`，从触发入口方向缩放入场；关闭 160ms 淡出。
勾选标记出现 160ms，不做位移。

### 10. 无障碍

- 触发入口角色为 `button`，朗读"分类，当前值：家务，展开选择"
- 弹出层角色为 `listbox`，选项角色为 `option`，当前项标注 `aria-selected`
- 展开后焦点进入弹出层，`Esc` 关闭后焦点回到触发入口
- 触控热区 ≥ 44

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 菜单形态 | `Menu` | `DropdownMenu` |
| 滚轮形态 | `Picker` + `.wheel` | `NumberPicker` 或自定义 |

两端都保留系统控件的键盘与读屏行为，只统一触发入口的样式。

### 12. 验收清单

- [ ] 触发入口高 44、选项行高 44，误差 ≤ 1pt
- [ ] 展开时当前选项自动滚到可视区中间
- [ ] 点击遮罩关闭且不改变当前值
- [ ] 空间不足时弹出方向自动翻转，不被裁切
- [ ] 未选状态显示"请选择"而不是空白
- [ ] 同一表单里只出现一种 Picker 形态
- [ ] 读屏能读出当前值，选中项标注 `aria-selected`

# 23 · DatePicker

**视觉参考**：高级画廊 23 ｜ **优先级** P1

### 1. 用途

选日期、时间或时间范围。

- **用**：截止日期、提醒时间、体检预约
- **不要用**：自由文本输入日期（格式错误率高）；只需要"今天/明天"两个选项（用 Chip）

### 2. 解剖

| 段 | 说明 |
| --- | --- |
| 触发入口 | 一行，左侧标签，右侧当前值 + `calendar` 图标 |
| 快捷选项 | 可选，「今天 / 明天 / 下周一」三个 Chip |
| 选择器 | 系统日历 / 滚轮 |
| 清除 | 可选，用于"无截止日期" |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 触发入口高 | 44 |
| 快捷 Chip 高 | 32 |
| 日历单元 | 44×44 |
| 圆角 | 触发入口 `radius.md`，弹出层 `radius.xl` |

### 4. 变体

| 形态 | 说明 |
| --- | --- |
| 日期 | 只选日期 |
| 时间 | 只选时间 |
| 日期 + 时间 | 两段式，先日期后时间 |
| 范围 | 起止两个日期，起始不得晚于结束 |

### 5. 状态

| 状态 | 视觉 |
| --- | --- |
| 未选 | "设置日期"，色 `text.tertiary` |
| 已选 | 格式化后的日期，色 `text.primary` |
| 今天 | 日历上带圆点标记 |
| 选中 | 实心圆底 `text.brand` + 白字 |
| 已过期 | 日期文字用 `status.danger` |
| 禁用 | 40%，日历中不可选的日期降到 30% |

### 6. 布局

- 触发行在表单里右对齐
- 快捷 Chip 放在触发行下方，左对齐，横向可滚动
- 日历弹出时占据底部或内联展开，不与键盘同时出现

### 7. 内容

- 日期格式跟随系统区域设置，**不硬编码为 YYYY-MM-DD**
- 相对日期用自然语言："今天"、"明天"、"3 天后"
- 范围显示"10月3日 – 10月7日"，中间用短横线

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击触发入口 | 展开日历，默认定位到当前值所在的月份 |
| 点击快捷 Chip | 直接选定并关闭 |
| 点击日期 | 选中；范围模式下第二次点击设置结束日期 |
| 切换月份 | 左右滑动或箭头，`motion.duration.fast` |
| 清除 | 清空值，触发一次 `onChange(nil)` |

### 9. 动效

日历展开 340ms `motion.spring.gentle`；月份切换 160ms 横向位移；
选中日期 200ms `motion.spring.snappy` 缩放反馈。

### 10. 无障碍

- 触发行朗读"截止日期，已选，2026年10月3日，按钮"
- 日历网格中每个日期朗读完整日期与状态（"10月3日，星期五，已选中"）
- 触控热区 ≥ 44×44（日历单元本身就是 44）
- 不用颜色单独表示"今天"，同时有圆点标记
- 时间选择支持直接输入，避免滚轮被迫长时间滑动

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 日期 | 图形日历 | M3 `DatePicker` |
| 时间 | 滚轮 | M3 `TimePicker` |

**保留各自原生控件**，只统一触发入口与快捷 Chip 的样式——日期选择是平台差异最大的控件，强行统一会破坏用户习惯。

### 12. 验收清单

- [ ] 触发行高 44、日历单元 44×44，误差 ≤ 1pt
- [ ] 日期格式跟随区域设置，不硬编码格式
- [ ] 展开时定位到当前值所在月份
- [ ] 快捷选项（今天/明天）可用，且与日历结果一致
- [ ] 范围模式下不允许结束早于开始
- [ ] 过期日期用 danger 色提示
- [ ] 读屏读出完整日期与状态，不只读数字
- [ ] 触控热区 ≥ 44×44

# 24 · FormRow

**视觉参考**：高级画廊 24 ｜ **优先级** P1

### 1. 用途

表单里的一行：一个标签配一个控件。**它定义的是排布与对齐，不是控件本身**。

- **用**：设置页、新建表单里成组出现的"标签 + 控件"
- **不要用**：内容型列表（用 `WDListRow`）；只有一行输入且没有标签（直接用 `WDTextField`）

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 标签 | 必有 | `type.subheadline` 15，色 `text.primary` |
| 控件 | 必有 | 任意输入类组件 |
| 说明文字 | 可选 | `type.footnote` 13，色 `text.secondary` |
| 错误文字 | 条件 | 同为 `type.footnote`，色 `status.danger`；**替换**说明文字，不叠加 |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 行最小高 | 44 |
| 标签与控件间距 | `space.4`（12） |
| 行与行之间 | `space.5`（16） |
| 说明 / 错误文字与控件间距 | `space.2`（4） |
| 标签列宽（左右排布） | 96，超出时标签换到上方排布 |

### 4. 变体

| 变体 | 排布 | 用在哪 |
| --- | --- | --- |
| 左右 | 标签居左、控件居右 | 控件窄（开关、步进器、选择器） |
| 上下 | 标签在上、控件在下并全宽 | 控件宽（输入框、多行） |
| 分组 | 多行合并进一个卡片，行内用分割线 | 设置页 |

### 5. 状态

| 状态 | 视觉 |
| --- | --- |
| 默认 | 标签 `text.primary` |
| 聚焦 | 该行的分割线或描边换 `text.brand` |
| 错误 | 说明文字换成 danger 色错误文案 |
| 禁用 | 标签与控件整体 40% |

### 6. 布局

- 同一表单里**排布方式必须统一**，不要一半左右一半上下
- 关联的字段放在相邻行，中间不插无关字段
- 分组时行与行之间的分割线从标签起始处内缩
- 页面左右边距 `space.5`（16）

### 7. 内容

- 标签 2–8 个汉字，名词短语，**不加冒号**
- 标签与控件的值语义要区分：标签"截止日期"，值"明天"，不要两边都写日期
- 说明文字一行，≤ 20 个汉字；错误文字一行，越短越好
- 错误文字必须说清"哪里错 + 怎么改"

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击标签 | 聚焦对应控件（左右排布时） |
| 点击整行 | 仅当行内只有一个控件且控件本身可聚焦时，聚焦该控件 |
| 校验失败 | 就地显示错误文字，**不弹窗、不滚动到顶部** |
| 提交时校验 | 滚动到第一个错误的行并聚焦 |

### 9. 动效

错误文字出现 160ms 淡入 + 4pt 下移；行高随之增加，用 `motion.duration.fast` 过渡，避免整表跳动。

### 10. 无障碍

- 标签与控件必须关联，读屏先读标签再读控件
- 出错时读"截止日期，错误，日期不能早于今天"
- 左右排布时，点击标签也能聚焦控件（标签的可点区域与行等高）
- 分组时每个分组有组标签（如"提醒设置"）

### 11. 平台差异

iOS 用 `LabeledContent` 或自定义 `HStack`；
Android 用 `Row` + `Modifier.semantics { }` 建立标签与控件的关联。
两端的"标签关联控件"都要显式声明，不能只靠视觉相邻。

### 12. 验收清单

- [ ] 行最小高 44，行间距 16
- [ ] 同一表单内排布方式统一，没有混用左右与上下
- [ ] 标签不加冒号
- [ ] 错误文字替换说明文字，不叠加显示
- [ ] 校验失败就地显示，不弹窗
- [ ] 提交时能滚动到第一个错误行并聚焦
- [ ] 读屏先读标签再读控件，错误时读出错误

# 25 · Alert

**视觉参考**：高级画廊 25 ｜ **优先级** P0

### 1. 用途

需要用户**立刻做决定**，且决定之前不能继续往下走。

- **用**：删除确认、放弃未保存的修改、权限被拒后引导去设置
- **不要用**：只是告知结果（用 `WDToast`）；可以撤销的操作（用撤销条）；收集输入（用 `WDBottomSheet`）；错误提示（用 `WDBanner`）

准入标准：**如果这个决定可以撤销，就不要用 Alert。**

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 遮罩 | 必有 | 阻止与下层交互，底色为页面底色的 40% 黑 |
| 卡片 | 必有 | `surface.card-solid` + `elevation.3` + `radius.xl` |
| 标题 | 必有 | `type.headline` 17 · 600，居中 |
| 正文 | 可选 | `type.footnote` 13，色 `text.secondary`，居中，最多 3 行 |
| 按钮组 | 必有 | 横向等分；两按钮时中间用 1pt 分割线 |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 卡片宽 | 270（固定，不随内容变化） |
| 卡片圆角 | `radius.xl` 24 |
| 标题区上下内距 | 16 / 6 |
| 正文区左右内距 | 16，下内距 14 |
| 按钮高 | 44 |
| 按钮字号 | 16（破坏性按钮用 `status.danger`） |

### 4. 变体

| 变体 | 按钮组 | 用在哪 |
| --- | --- | --- |
| 双按钮 | 取消 + 确认，取消在左 | 默认 |
| 单按钮 | 只有一个"知道了" | 纯告知但仍需阻断 |
| 危险 | 确认按钮用 danger 色 | 删除、清空等不可逆操作 |
| 带输入 | 卡片内嵌一个 `WDTextField` | 需要输入名称才能继续（如重命名） |

### 5. 状态

| 状态 | 视觉 |
| --- | --- |
| 出现 | 遮罩 160ms 淡入；卡片 240ms 从 0.92 缩放到 1 + 淡入 |
| 按钮按下 | 按钮底色 `fill.pressed` |
| 长文案 | 正文超过 3 行时卡片内部滚动，卡片高度不超过屏幕的 60% |

### 6. 布局

- 卡片在遮罩内**水平居中、垂直居中偏上**（垂直居中会显得重心过低）
- 卡片与屏幕左右最小间距 `space.8`（32）
- 按钮等宽；两按钮之间分割线与卡片等宽

### 7. 内容

- 标题 ≤ 12 个汉字，一句话说清要决定什么（"删除这条任务？"）
- 正文 ≤ 60 个汉字，补充后果（"删除后无法恢复，其他成员也看不到了"）
- 按钮文案用**动词**："删除"、"放弃修改"，不用"确定 / 取消"这种没有信息量的词
- 取消按钮保留"取消"即可，它本身就是标准语义

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击确认 | 执行动作并关闭 |
| 点击取消 | 关闭，不执行 |
| 点击遮罩 | **不关闭**——Alert 的前提是必须做出选择 |
| `Esc` / 返回键 | 等价于取消 |
| 重复点击确认 | 第一次点击后禁用按钮，防止重复提交 |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 遮罩淡入 | `motion.duration.fast` 160ms 线性 |
| 卡片入场 | `motion.duration.base` 240ms，缩放 0.92 → 1 |
| 关闭 | 160ms 淡出，不做缩放 |

### 10. 无障碍

- 角色为 `alertdialog`，标题与正文自动朗读
- 出现时**焦点移入卡片**，并限制在卡片内（焦点陷阱）
- 关闭后焦点**归还到触发元素**
- 破坏性按钮的朗读包含后果："删除，删除后无法恢复"
- 按钮触控热区 ≥ 44

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | `.alert`，或自定义以支持带输入 | `AlertDialog` |
| 按钮顺序 | 取消在左、确认在右 | Material 默认确认在右 |
| 遮罩点击 | 系统默认不关闭 | 系统默认可关闭，需显式禁用 |

### 12. 验收清单

- [ ] 卡片宽 270，圆角 `radius.xl`
- [ ] 卡片位置为垂直居中偏上，不是正中
- [ ] 点击遮罩不关闭
- [ ] `Esc` / 返回键等价于取消
- [ ] 确认按钮点击后立即禁用，不会重复提交
- [ ] 正文超过 3 行时卡片内滚动，总高不超屏幕 60%
- [ ] 出现时焦点进入并被限制在卡片内，关闭后归还
- [ ] 按钮文案是动词，不是"确定"
- [ ] 危险操作的按钮使用 danger 色，且朗读包含后果

# 28 · Toast

**视觉参考**：高级画廊 28 ｜ **优先级** P0

### 1. 用途

**非阻塞**的轻提示，告知"刚刚发生了一件事"。

- **用**：保存成功、已复制、已同步、任务已删除（带撤销）
- **不要用**：需要用户决策（用 `WDAlert`）；需要用户处理且不能错过的错误（用 `WDBanner`）；加载中（用进度组件）

分界线：**Toast 会自己消失，所以它承载的信息必须是"不看也没关系"的。**

### 2. 解剖

玻璃胶囊 + 状态图标 + 文字 + 可选操作按钮。底部距安全区 `space.5`（16）。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 高度 | 46（单行）；多行时自适应，最多 2 行 |
| 最小宽度 | 120 |
| 最大宽度 | 屏幕宽 − 2 × `space.6`（40） |
| 水平内距 | 18 |
| 圆角 | `radius.full` |
| 图标 | 16 |

### 4. 变体

| 变体 | 图标 | 用在哪 |
| --- | --- | --- |
| 成功 | `check` + `text.brand` | 保存、同步完成 |
| 信息 | `info` | 中性提示 |
| 失败 | `x-circle` + `status.danger` | 操作未成功，但可重试 |
| 带操作 | 右侧加一个文字按钮（"撤销"） | 删除后撤销 |

### 5. 状态

| 状态 | 时长 |
| --- | --- |
| 出现 | 320ms 上移淡入 |
| 停留（纯提示） | 3 秒 |
| 停留（带操作） | 5 秒 |
| 消失 | 160ms 淡出 |
| 手指悬停 | 暂停计时 |

### 6. 布局

- 底部居中，距安全区 `space.5`（16）
- 同时只显示**一条**；新 Toast 顶掉旧 Toast，不排队堆叠
- 与底部 Tab 栏共存时出现在 Tab 栏上方 `space.4`（12）

### 7. 内容

- 一句话 ≤ 20 个汉字，说结果不说过程（"任务已保存"而不是"正在保存任务"）
- 不用"成功！"这类只有情绪没有信息的文案
- 带操作时按钮文案具体："撤销"而不是"好"

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击 Toast | 无操作时为无响应（不关闭）；带操作时触发该操作并关闭 |
| 点击页面其他区域 | **不关闭**，Toast 自己会消失 |
| 向上滑 | 立即关闭 |
| 连续触发 | 复用同一个 Toast，重置计时并替换内容 |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 出现 | `motion.component.toast-in` 320ms，上移 12pt + 淡入，`motion.spring.gentle` |
| 消失 | `motion.duration.fast` 160ms 淡出（不做位移，避免和出现方向相反显得突兀） |

### 10. 无障碍

- 成功 / 信息用 `aria-live="polite"`
- 失败用 `role="alert"`，会被立即播报
- 带操作时朗读"任务已删除，撤销，按钮"
- Toast 出现**不抢焦点**——它是非阻塞提示
- 文字与底色对比度 ≥ 4.5:1（玻璃底上必要时加底色托底）

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | 自定义浮层，挂在 window 上避免被容器裁切 | `Snackbar` + `SnackbarHost` |
| 位置 | 底部居中 | Material 默认底部左对齐，需要改为居中 |
| 时长 | 自定义 | `SnackbarDuration.Short / Long` |

### 12. 验收清单

- [ ] 单行高 46、圆角 `radius.full`，误差 ≤ 1pt
- [ ] 同时只显示一条，连续触发时复用而不是堆叠
- [ ] 纯提示停留 3 秒，带操作停留 5 秒
- [ ] 手指悬停时暂停计时
- [ ] 失败态用 `role="alert"`，成功态用 `polite`
- [ ] Toast 出现不抢焦点
- [ ] 与底部 Tab 栏共存时不被遮挡
- [ ] 出现在 window 层，不被局部容器裁切

# 29 · Banner

**视觉参考**：高级画廊 29 ｜ **优先级** P0

### 1. 用途

**常驻**的页面级提示。需要用户看到、可能需要处理，但不阻断当前操作。

- **用**：权限被限制、网络不可用、试用期剩余天数、批量操作的部分失败
- **不要用**：一次性结果（用 `WDToast`）；需要立刻决策（用 `WDAlert`）；装饰性强调

分界线：**Banner 不自动消失**，所以它承载的信息必须值得占一块常驻空间。

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 状态图标 | 必有 | 18pt，形状区分状态（对勾 / 信息 / 三角 / 实心禁止） |
| 文案 | 必有 | `type.footnote` 13，最多 2 行 |
| 操作按钮 | 可选 | 文字按钮，最多一个 |
| 关闭键 | 可选 | 可关闭的提示才有 |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 最小高 | 44（单行） |
| 内边距 | 12 |
| 圆角 | `radius.lg` 18 |
| 图标与文案间距 | `space.3`（8） |
| 文案与操作间距 | `space.3`（8） |

### 4. 变体

| 变体 | 底色 | 文字与图标 | 用在哪 |
| --- | --- | --- | --- |
| 成功 | `status-soft.success` 渐变 | `status.success` | 同步完成 |
| 信息 | `status-soft.info` 渐变 | `status.info` | 中性说明 |
| 警示 | `status-soft.warning` 渐变 | `status.warning` | 快到期、接近上限 |
| 错误 | `status-soft.danger` 渐变 + 文字加粗 | `status.danger` | 操作失败、需处理 |

底色一律用**同色 20% 左右的渐变**，不用纯色块。

### 5. 状态

| 状态 | 说明 |
| --- | --- |
| 常驻 | 直到条件解除才消失（如网络恢复） |
| 可关闭 | 右上角有关闭键，关闭后本次会话不再出现 |
| 出现 | 240ms 淡入 + 8pt 下移，不循环 |

### 6. 布局

- 页面顶部，或所在分组内顶部，左右边距 `space.5`（16）
- 与下方内容间距 `space.4`（12）
- 同一页面最多 2 条，多条时按严重度排序：错误 → 警示 → 信息

### 7. 内容

- 一句话说清"发生了什么 + 需要做什么"："网络不可用，改动已暂存本地"
- ≤ 40 个汉字，超过 2 行说明这条信息不该用 Banner 承载
- 操作按钮文案具体："去设置"、"重试"，不用"知道了"

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击操作按钮 | 执行对应动作，Banner 可保留或关闭 |
| 点击关闭键 | 关闭，本次会话不再出现（持久化到会话级，不写磁盘） |
| 点击 Banner 本体 | 无操作时无响应 |

### 9. 动效

出现 240ms 淡入 + 8pt 下移；关闭 160ms 淡出 + 高度收起。
**不做循环动画**，也不做呼吸效果——常驻元素持续动会持续抢注意力。

### 10. 无障碍

- 信息 / 成功用 `role="status"`，警示 / 错误用 `role="alert"`
- 错误态的图标与文字同时变化，不依赖颜色
- 关闭键标签"关闭提示"，并按内容补充："关闭网络提示"
- 不抢焦点；若在页面加载时就存在，随内容一起被朗读

### 11. 平台差异

两端都需自定义。iOS 可参考 `SafeAreaInset` 固定在导航栏下方；
Android 可参考 `Snackbar` 的常驻变体，但不要用 `Snackbar` 做常驻提示（它默认会消失）。

### 12. 验收清单

- [ ] 圆角 `radius.lg`、内边距 12，误差 ≤ 1pt
- [ ] 四种状态的底色都是同色渐变，不是纯色块
- [ ] 错误态文案加粗，且图标形状与其他状态不同
- [ ] 不自动消失、无循环动画
- [ ] 同一页面不超过 2 条，按严重度排序
- [ ] 可关闭的提示关闭后本次会话不再出现
- [ ] 读屏角色正确（信息用 status，错误用 alert）

# 30 · EmptyState

**视觉参考**：高级画廊 30 ｜ **优先级** P1

### 1. 用途

没有内容时，说明**为什么没有**以及**接下来能做什么**。

- **用**：首次进入列表、搜索无结果、权限受限、加载失败
- **不要用**：内容还在加载（用 `WDSkeleton`）；内容确实为空但用户不关心（直接留白）

### 2. 解剖

圆形图标底座 + 标题 + 说明 + 一个主操作。四段都可选，但至少要有标题。

| 段 | 规格 |
| --- | --- |
| 图标底座 | 56×56 圆形，`gradient.surface` 底 + `text.on-soft` 图标 26 |
| 标题 | `type.headline` 17 · 600 |
| 说明 | `type.subheadline` 15，`text.secondary`，最多 2 行，居中 |
| 主操作 | `WDButton` filled 或 tonal，最多一个 |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 底座 | 56×56 |
| 底座与标题间距 | `space.4`（12） |
| 标题与说明间距 | `space.2`（4） |
| 说明与操作间距 | `space.5`（16） |
| 文本最大宽 | 32 个汉字宽（约 240） |

### 4. 变体

| 变体 | 标题示例 | 操作 |
| --- | --- | --- |
| 首次空 | "还没有任务" | "新建第一个任务" |
| 搜索无结果 | "没找到"储物间"" | "清除筛选" |
| 权限受限 | "需要通知权限" | "去设置" |
| 加载失败 | "加载失败" | "重试" |

四种的差别不在视觉，而在**文案与操作**，配色保持一致。

### 5. 状态

空状态本身无状态。加载失败的变体可以重复触发"重试"，重试期间按钮进入加载态。

### 6. 布局

- 在**内容区域**内垂直居中，不是屏幕正中（要扣掉导航栏与 Tab 栏）
- 左右边距 `space.8`（32），避免文字贴边
- 与页面顶部至少留 `space.9`（40）

### 7. 内容

- 标题 ≤ 12 个汉字，陈述事实（"还没有任务"）
- 说明 ≤ 40 个汉字，给出原因或下一步，**不写"这里什么都没有"这类废话**
- 操作文案是动词短语，且与标题呼应
- 搜索无结果时，标题里带上用户输入的关键词，让用户确认搜的是什么

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击主操作 | 执行对应动作 |
| 无操作时 | 整块不可交互，不做按下反馈 |

### 9. 动效

不做入场动画。加载失败重试时按钮进入加载态即可。
**空状态做动画会显得轻浮**，且用户已经处于受挫状态。

### 10. 无障碍

- 作为一组朗读：标题 → 说明 → 操作
- 图标底座标记为装饰
- 读屏用户进入空页面时，标题应能被首个朗读到
- 文字对比度 ≥ 4.5:1，说明文字用 `text.secondary` 已满足

### 11. 平台差异

两端都需自定义。注意 iOS 的 `ContentUnavailableView` 可以直接用，
但它的默认排版与我们的间距规格不同，需要对齐后再用。

### 12. 验收清单

- [ ] 图标底座 56×56，误差 ≤ 1pt
- [ ] 在内容区内垂直居中，不被导航栏或 Tab 栏挤压
- [ ] 文本最大宽约 240，不贴边
- [ ] 四种变体的视觉一致，只有文案与操作不同
- [ ] 说明文字给出原因或下一步，不是废话
- [ ] 搜索无结果时标题包含关键词
- [ ] 没有入场动画
- [ ] 加载失败可重试，重试时按钮进入加载态

# 31 · Skeleton

**视觉参考**：高级画廊 31 ｜ **优先级** P1

### 1. 用途

内容加载中的占位，**保持布局稳定**，避免内容出现时页面跳动。

- **用**：首次加载列表、卡片、详情页
- **不要用**：加载时间可预期且很短（< 300ms）；加载失败（用 `WDEmptyState`）

### 2. 解剖

灰色块 + 微光扫过。骨架的**形状必须和真实内容一致**——形状不一致的骨架比没有骨架更糟，
因为它会误导用户对内容的预期。

### 3. 尺寸

| 形态 | 规格 |
| --- | --- |
| 文本行 | 高 11，圆角 6，宽度按真实文本比例（70% / 45%） |
| 列表行 | 与 `WDListRow` 等高（44 / 60 / 76） |
| 卡片 | 与真实卡片同尺寸、同圆角、同内边距 |
| 头像 | 圆形，直径同真实头像 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 文本 | 3–4 行文本块 |
| 列表 | 5–6 行列表项，前导圆形 + 两行文本 |
| 卡片 | 卡片轮廓 + 卡内两行 + 一个按钮宽度的块 |

### 5. 状态

只有一种状态（加载中）。加载完成后骨架**整块替换**为真实内容，不做逐块替换。

### 6. 布局

- 骨架的外边距、间距与真实内容**完全一致**
- 骨架数量取真实内容的典型数量（列表取 5–6 行，不要渲染 50 行）
- 骨架不滚动

### 7. 内容

骨架内**不写任何文字**。写"加载中…"会让页面在加载完成时发生文本跳动。
需要说明进度时用 `WDProgressBar` 的不确定态。

### 8. 交互

不可交互。骨架出现时，页面滚动应被禁用（内容高度还没确定）。

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 微光扫过 | `motion.component.skeleton-shimmer` 2200ms 线性，循环 |
| 替换为内容 | 160ms 交叉淡化 |

开启"减弱动态效果"时**停止微光**，显示静态灰块。

### 10. 无障碍

- 骨架容器标注 `aria-busy="true"`
- 整个骨架区朗读**一次**"加载中"，不要每个灰块都朗读
- 加载完成后朗读"内容已加载"，并把焦点保持在原位置
- 灰块与背景对比度约 1.5:1 即可，不需要文字级对比度（它不是文字）

### 11. 平台差异

两端都需自定义。注意 Android 的 `Modifier.placeholder` 需要额外依赖；
两端实现同一套微光节奏（2200ms）以保证观感一致。

### 12. 验收清单

- [ ] 骨架形状与真实内容一致，替换时**无布局跳动**
- [ ] 外边距、间距、圆角与真实内容完全相同
- [ ] 骨架内没有任何文字
- [ ] 列表骨架 5–6 行，不渲染全量数据
- [ ] 微光 2200ms 循环；减弱动态效果时静止
- [ ] 容器标注 `aria-busy`，只朗读一次"加载中"
- [ ] 加载完成后整块替换，不逐块闪烁

# 32 · PullToRefresh

**视觉参考**：高级画廊 32 ｜ **优先级** P1

### 1. 用途

用户主动请求刷新。**只用于内容会变化且用户有刷新动机的列表**。

- **用**：消息列表、家庭动态、协作任务
- **不要用**：静态内容（设置页）；实时推送已经覆盖的场景

### 2. 解剖

下拉指示器 + 文字状态 + 刷新中的进度环。

| 阶段 | 显示 |
| --- | --- |
| 下拉未达阈值 | 环从左到右画出进度，文字"下拉刷新" |
| 达到阈值 | 环变成完整圆，文字"松开刷新" |
| 刷新中 | 环旋转，文字"正在刷新" |
| 完成 | 环收起，列表内容回到原位 |

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 触发阈值 | 64（下拉超过此距离松手才刷新） |
| 指示器直径 | 24 |
| 环线宽 | 2 |
| 指示器与首行间距 | `space.4`（12） |
| 最大下拉距离 | 120（超过后阻力显著增加） |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 品牌进度 | 环用 `text.brand`，默认 |
| 极简 | 只有环，没有文字（空间极紧时） |

### 5. 状态

| 状态 | 视觉 |
| --- | --- |
| 空闲 | 指示器隐藏在列表上方 |
| 下拉中 | 指示器跟随下拉距离显出，透明度 0 → 1 |
| 刷新中 | 指示器固定显示，环旋转 |
| 完成 | 160ms 后收起 |

### 6. 布局

- 指示器水平居中
- 指示器出现时**不下推列表内容**，而是覆盖在列表上方（避免内容位移）
- 刷新完成后列表回到顶部位置，不保留偏移

### 7. 内容

- 文字三态固定为"下拉刷新 / 松开刷新 / 正在刷新"
- 不显示上一次刷新时间（那是 Banner 或页脚的职责）
- 刷新失败时收起指示器并弹 `WDToast`，不把错误文字挤在下拉区

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 下拉 | 阻力递增；超过 64 后松手触发刷新 |
| 阈值处 | 触发一次轻触觉（**只触发一次**，不随手指抖动重复触发） |
| 刷新中再下拉 | 不响应 |
| 刷新超时 | 10 秒后收起诉失败 |
| 键盘操作 | 提供"刷新"辅助操作，不强制手势 |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 指示器跟随 | 实时，无动画 |
| 回弹 | `motion.spring.snappy` |
| 环旋转 | 刷新期间持续，`prefers-reduced-motion` 时改为静态环 |

### 10. 无障碍

- 提供"刷新"的自定义辅助操作，读屏用户不需要会下拉
- 刷新开始与结束各播报一次："正在刷新" / "刷新完成"
- 触觉在阈值处触发一次
- 减弱动态效果时，环不做旋转，改为静态进度

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 实现 | `.refreshable` | `PullToRefreshBox` |
| 指示器 | 系统提供，样式不可控 | 可自定义 `indicator` |

两端都要保证"不下推内容"这一条，系统默认行为可能不同，需要显式调整。

### 12. 验收清单

- [ ] 触发阈值 64，最大下拉 120，误差 ≤ 2pt
- [ ] 指示器覆盖在列表上方，**不下推内容**
- [ ] 阈值处触觉只触发一次
- [ ] 三态文案正确切换
- [ ] 刷新中再次下拉不重复触发
- [ ] 10 秒超时收起诉失败，失败用 Toast 提示
- [ ] 提供"刷新"辅助操作，不强制手势
- [ ] 减弱动态效果时环不旋转

# 33 · NavigationBar

**视觉参考**：高级画廊 33 ｜ **优先级** P0

### 1. 用途

页面级导航容器：告诉用户"这是哪"，并提供返回与页面级操作。

- **用**：每个二级及以上页面
- **不要用**：Tab 内的一级页面加返回按钮（一级页面没有返回）；把页面内容塞进导航栏

### 2. 解剖

| 段 | 是否必有 | 说明 |
| --- | --- | --- |
| 返回 / 关闭 | 条件 | 二级页必有；一级页没有 |
| 标题 | 必有 | 内联模式 `type.headline` 17 · 600，居中或左对齐（跟平台） |
| 右侧操作 | 可选 | **最多 2 个**图标按钮，间距 `space.3`（8） |
| 大标题 | 条件 | 大标题模式才有，`type.largeTitle` 34 · 700，左对齐 |

### 3. 尺寸

| 模式 | 高度 | 组成 |
| --- | --- | --- |
| 内联（紧凑） | 44 | 状态栏下的单行 |
| 标准 | 56 | 单行 + 上下留白 |
| 大标题 | 96 | 内联行 44 + 大标题区 52 |

图标按钮 32×32 视觉，热区 44×44。左右边距 `space.5`（16）。

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 透明 | 页面顶部，内容未滚动时无底色 |
| 玻璃 | 内容滚动到栏下方时切换为 `surface.glass` + `border.glass-top` |
| 大标题 | 标题独立成行，滚动时收缩为内联 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 未滚动 | 透明底，无分割线 | — |
| 已滚动 | `surface.glass` + 底部 1pt `border.hairline` | 240ms 交叉淡化 |
| 大标题收缩 | 大标题缩到内联标题的位置并降字号 | `motion.spring.gentle` |
| 返回按下 | 按钮缩放 0.97 + `fill.pressed` | 100ms |

### 6. 布局

- 导航栏固定在顶部，内容在其下方滚动
- 大标题模式下，大标题与内容左边缘对齐（`space.5`）
- 右侧操作最多 2 个，超过时合并进"更多"
- 页面内容顶部需预留 `space.7`（24）起始留白

### 7. 内容

- 标题 ≤ 8 个汉字，用页面名而不是动作名（"家庭"而不是"查看家庭"）
- 标题不用缩写、不用省略号；放不下时优先缩短文案
- 返回按钮**只显示箭头不显示文字**（除非空间充裕且需要指明来源页）

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击返回 | 返回上一页 |
| 点击大标题 | 列表滚动到顶部 |
| 向下滚动 | 大标题收缩为内联，导航栏转玻璃底 |
| 向上滚动到顶 | 大标题恢复，导航栏转透明 |
| 边缘右滑（iOS） | 返回上一页 |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 大标题收缩 / 展开 | `motion.spring.gentle`，跟随滚动进度而非固定时长 |
| 玻璃底切换 | `motion.duration.base` 240ms 交叉淡化 |
| 返回按下 | `motion.duration.instant` 100ms |

### 10. 无障碍

- 导航栏作为 `header` 语义，标题作为页面标题被首个朗读
- 返回按钮标签包含来源页名："返回家庭列表"
- 右侧图标按钮必须有独立标签
- 大标题收缩时读屏**仍能读到完整标题**，不能因为视觉收缩而丢失
- 触控热区 ≥ 44×44

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 形态 | 大标题 + 居中内联标题 | `TopAppBar`，标题左对齐 |
| 返回 | 圆形玻璃底返回键 + 边缘右滑 | 返回箭头 + 系统预测式返回 |
| 收缩 | `navigationBarTitleDisplayMode` | `TopAppBarScrollBehavior` |

标题对齐方式两端不同是刻意的，不要强行统一。

### 12. 验收清单

- [ ] 内联 44 / 标准 56 / 大标题 96，误差 ≤ 1pt
- [ ] 未滚动时透明，滚动到栏下方时切玻璃底，过渡无跳变
- [ ] 大标题收缩跟随滚动进度，不是固定时长动画
- [ ] 右侧最多 2 个操作，超过合并进"更多"
- [ ] 标题 ≤ 8 字，不使用省略号
- [ ] 返回按钮标签包含来源页名
- [ ] 收缩时读屏仍能读到完整标题
- [ ] 一级页面没有返回按钮

# 34 · TabBar

**视觉参考**：高级画廊 34 ｜ **优先级** P0

### 1. 用途

顶层导航。在互不隶属的几个主区域之间切换。

- **用**：2–5 个平级的主区域
- **不要用**：超过 5 个（需要重新做信息架构）；二级页面（用 `WDNavigationBar`）；页面内的视图切换（用 `WDSegmentedControl`）

### 2. 解剖

悬浮玻璃胶囊 + 若干项目（图标 + 标签 + 选中标记）。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 高度 | 58 |
| 距左右边缘 | `space.5`（16） |
| 距底部安全区 | `space.3`（8） |
| 图标 | 22 |
| 标签 | 10 · 500（选中 600） |
| 圆角 | `radius.full` |
| 项目数 | 2–5 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| iOS 悬浮胶囊 | 默认，浮在内容之上，带 `elevation.2` |
| Android 全宽 | 贴底全宽，`surface.glass-strong`，选中项用胶囊底 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 未选 | 图标与标签 `text.tertiary` | — |
| 选中 | 图标与标签 `text.brand`，标签加粗，下方 4pt 圆点 | 200ms |
| 按下 | 图标缩放 0.94 | 100ms |
| 带角标 | 图标右上角计数徽标 | — |

### 6. 布局

- 浮在内容之上，内容底部需预留 58 + 8 + `space.5` = 82 的留白
- 项目等分，各占相同宽度
- 滚动时**可收缩为无标签的胶囊**，向上滚动立即展开

### 7. 内容

- 标签 ≤ 4 个汉字，用名词（"今天"、"家庭"）
- 不用图标代替标签（首次使用的用户认不出）
- 角标计数超 99 显示"99+"，为 0 时隐藏

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击未选项 | 切换，重置该区域的导航栈 |
| 点击已选项 | 该区域滚动到顶部（**不重置导航栈**） |
| 再次点击已选项且已在顶部 | 该区域滚动到顶部（无其他动作） |
| 左右滑动内容 | 若支持，与点击等效 |

### 9. 动效

选中态 200ms 变色与字重过渡；收缩 / 展开 `motion.spring.gentle`；
切换区域时**不做横向滑动动画**（会让人以为是同一页面的分页）。

### 10. 无障碍

- 容器角色为 `tablist`，每项角色 `tab`
- 朗读"第 n 项，共 m 项"，选中项标注 `aria-selected`
- 触控热区：单项宽度足够，高度 58 已满足
- 选中态不依赖颜色：同时有圆点与字重变化

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 形态 | 悬浮玻璃胶囊 | 贴底全宽 |
| 选中标记 | 图标下 4pt 圆点 | 图标外胶囊底 |
| 收缩 | 滚动时收缩为无标签胶囊 | 默认不收缩 |

### 12. 验收清单

- [ ] 高 58、距左右 16、距底部安全区 8，误差 ≤ 1pt
- [ ] 2–5 个项目，等分宽度
- [ ] 内容底部预留 ≥ 82 留白，最后一行不被遮挡
- [ ] 点击已选项回到顶部，且不重置导航栈
- [ ] 选中态同时有颜色、字重、圆点三个信号
- [ ] 标签 ≤ 4 字，且没有用图标代替标签
- [ ] 读屏读出"第 n 项，共 m 项"与选中状态

# 35 · Toolbar

**视觉参考**：高级画廊 35 ｜ **优先级** P1

### 1. 用途

与**当前上下文**相关的一组操作。和 TabBar 的区别是：TabBar 切换区域，Toolbar 操作当前内容。

- **用**：编辑器（撤销/重做/格式）、画布（缩放/对齐）、多选状态下的批量操作
- **不要用**：页面级导航（用 `WDNavigationBar`）；主区域切换（用 `WDTabBar`）；少于 2 个操作

### 2. 解剖

玻璃胶囊容器 + 若干图标按钮 + 可选分割线 + 可选文字。

### 3. 尺寸

| 项 | 值 |
| --- | --- |
| 容器高 | 48 |
| 图标按钮 | 36×36，图标 20 |
| 按钮间距 | `space.2`（4） |
| 容器内边距 | 6 |
| 圆角 | `radius.full` |
| 分割线 | 1pt × 24，色 `border.hairline` |

### 4. 变体

| 变体 | 位置 | 说明 |
| --- | --- | --- |
| 顶部 | 导航栏下方 | 与当前对象相关的操作 |
| 底部 | 内容上方 | 单手可达，用于高频操作 |
| 键盘上方 | 键盘附着 | 输入辅助（格式、插入） |

### 5. 状态

| 状态 | 视觉 |
| --- | --- |
| 默认 | `surface.glass-strong` + `border.hairline` + `elevation.1` |
| 按钮按下 | 按钮缩放 0.94 + `fill.pressed` |
| 按钮选中 | 按钮底 `gradient.mid` + 白色图标 |
| 按钮禁用 | 40%，不响应 |

### 6. 布局

- 内容宽度，水平居中；操作多时允许横向滚动
- 顶部变体与导航栏间距 `space.2`（4）
- 底部变体与内容间距 `space.4`（12），距安全区 `space.4`（12）
- 键盘上方时紧贴键盘，不叠加安全区

### 7. 内容

- 最多 7 个操作，超过时把低频操作收进"更多"
- 图标必须语义明确，含义模糊的图标要配短文字
- 破坏性操作不放进 Toolbar（容易误触）

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击按钮 | 执行操作 |
| 长按按钮 | 显示工具提示（文字标签） |
| 无可用操作 | 保持显示但按钮禁用，**不要隐藏整条工具栏**（隐藏会导致布局跳动） |

### 9. 动效

按钮按下 100ms；按钮选中态切换 160ms；工具栏本身不做进出动画。

### 10. 无障碍

- 每个图标按钮必须有标签，长按提示是补充不是替代
- 整条工具栏有分组标签（如"编辑工具"）
- 按钮的选中 / 禁用状态要能被读出
- 触控热区 ≥ 44×44（按钮视觉 36，热区向外扩 4）

### 11. 平台差异

iOS 用 `.toolbar { ToolbarItemGroup }` 或自定义浮层；
Android 用 `TopAppBar` 的 actions 或自定义 `Surface`。
键盘上方变体在 Android 上用 `Modifier.imePadding()` 附着。

### 12. 验收清单

- [ ] 容器高 48、按钮 36×36、圆角 `radius.full`，误差 ≤ 1pt
- [ ] 按钮触控热区 ≥ 44×44
- [ ] 超过 7 个操作时收进"更多"
- [ ] 无可用操作时按钮禁用而不是隐藏整条工具栏
- [ ] 每个图标按钮都有标签，长按显示提示
- [ ] 破坏性操作没有放进工具栏
- [ ] 键盘上方变体不叠加安全区

# 36 · FAB

**视觉参考**：高级画廊 36 ｜ **优先级** P1

### 1. 用途

页面的**主操作**，悬浮在内容之上，滚动时保持可达。

- **用**：新建任务、记一笔、添加成员——一屏一个的创建类动作
- **不要用**：每屏已经有一个 `filled` 按钮（重复了主操作）；破坏性操作；多个并列动作（用 Toolbar）

### 2. 解剖

容器 + 图标（+ 展开后的一组子操作）。

### 3. 尺寸

| 档 | 尺寸 | 圆角 | 图标 |
| --- | --- | --- | --- |
| 标准 | 56×56 | `radius.fab` 19 | 24 |
| 大 | 64×64 | 22 | 28 |
| 小 | 40×40 | 14 | 20 |

### 4. 变体

| 变体 | 说明 |
| --- | --- |
| 圆角方（默认） | 区别于圆形，和卡片体系更协调 |
| 圆形 | 与系统规范一致时使用 |
| 可展开 | 点击展开 2–4 个子操作，图标旋转 45° 变关闭 |

### 5. 状态

| 状态 | 视觉 | 动效 |
| --- | --- | --- |
| 默认 | `gradient.fill`（浅深两端各自取值）+ `elevation.brand` | — |
| 按下 | 缩放 0.95 | 100ms |
| 滚动 | 向下滚动时缩小到 40 并降低不透明度；向上滚动恢复 | `motion.spring.gentle` |
| 展开 | 图标旋转 45°，子操作逐个出现 | 240ms，错峰 40ms |
| 禁用 | 40% | 无 |

### 6. 布局

- 距右边缘 `space.5`（18 视觉，取 18）
- 距底部安全区 18；有 Tab 栏时改为 92（Tab 栏高 58 + 间距 8 + 留白）
- 是页面**最后一个**进入无障碍焦点序列的交互元素（视觉上压在最上层，但逻辑顺序在内容之后）
- 子操作向上展开，纵向排列，间距 `space.3`（8）

### 7. 内容

- 图标必须配无障碍标签；展开态的子操作用"图标 + 文字"而不是纯图标
- 一个页面最多一个 FAB
- 展开态最多 4 个子操作，超过说明该用整页

### 8. 交互

| 操作 | 结果 |
| --- | --- |
| 点击 | 执行主操作 / 展开子操作 |
| 展开后点击遮罩 | 收起 |
| 展开后点击子操作 | 执行并收起 |
| 下拉滚动 | 缩小但不隐藏（隐藏后用户找不到） |

### 9. 动效

| 过渡 | 令牌 |
| --- | --- |
| 按下 | `motion.duration.instant` 100ms |
| 展开 | 240ms，子操作错峰 40ms，`motion.spring.gentle` |
| 图标旋转 | 240ms `motion.spring.snappy` |
| 滚动缩放 | `motion.spring.gentle` |

### 10. 无障碍

- 标签写动作："新建任务"
- 展开态作为一个组朗读，子操作各自可聚焦
- 子操作展开时焦点移入第一个子操作
- 触控热区：标准 56 已满足；小号 40 需向外扩到 44
- 与 Tab 栏共存时，两者不重叠且都可点

### 11. 平台差异

| 项 | iOS | Android |
| --- | --- | --- |
| 形态 | 圆角方（与卡片体系一致） | Material 默认圆形，需显式改圆角 |
| 位置 | 距 Tab 栏上方 | 默认在 Tab 栏之上，注意 `Snackbar` 出现时上移 |
| 展开 | 自定义 | `FloatingActionButton` + 自定义子项 |

### 12. 验收清单

- [ ] 标准 56×56、圆角 19、图标 24，误差 ≤ 1pt
- [ ] 一个页面最多一个 FAB
- [ ] 距右 18、距底部安全区 18；有 Tab 栏时改为 92 且不重叠
- [ ] 展开态最多 4 个子操作，子项带文字
- [ ] 图标旋转 240ms，子操作错峰 40ms
- [ ] 向下滚动时缩小但不隐藏
- [ ] 小号 40 的热区补到 ≥ 44
- [ ] 展开时焦点进入第一个子操作，点击遮罩收起
