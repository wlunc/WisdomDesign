# 07 · 内容与文案规范

> 界面的"家庭感"多半不来自配色，来自文案。同一句提示，换个说法就从"系统在管你"变成"家里人在提醒你"。
> 本文是写文案的唯一依据，组件规格里的文案示例都从这里取值。

## 1. 三条原则

| 原则 | 含义 | 反例 → 正例 |
| --- | --- | --- |
| **温和** | 不指责、不催促、不惊讶 | "操作失败，请重试" → "没保存成功，看看网络" |
| **具体** | 说清发生了什么、下一步做什么 | "输入无效" → "名称里有特殊符号，换一个试试" |
| **不说教** | 不教育用户该怎么生活 | "坚持才有收获！" → "今天完成了 3 项" |

家庭工具的用户里有老人和孩子，**看不懂的文案等于没写**。写完读一遍：一个 70 岁的人第一次用，能不能看懂？

---

## 2. 句式规则

### 2.1 人称

| 场景 | 用法 | 例 |
| --- | --- | --- |
| 界面文案 | **省略主语**或"你"，不用"您" | "保存好了" 而不是 "您已保存成功" |
| 成员称呼 | 用家庭关系称谓 | "妈妈" 而不是 "张丽" |
| 成员看自己 | 一律用"我" | 头像显示"我"；"我来做" |
| 通知 | 用称谓，不用名字 | "妈妈完成了买菜" |

不用"您"是有意的：家庭场景里"您"会拉开距离，而省略主语在中文里读起来更自然、也不失礼。

### 2.2 标点

- **不用感叹号**。感叹号在工具类 App 里会显出催促感
- 用全角标点；短句可省略句末句号，两句话时用句号分隔
- 不用省略号制造悬念（"正在加载…" → "正在同步"）
- 中英混排时，中文与英文/数字之间加空格："还剩 3 天" 而不是 "还剩3天"

### 2.3 数字与单位

| 项 | 规则 |
| --- | --- |
| 阿拉伯数字 | 一律用阿拉伯数字，不用"三"（"3 项"） |
| 单位 | 用中文单位（天 / 项 / 人 / 分钟），不用 d / items |
| 百分比 | 数字与 `%` 之间不加空格："62%" |
| 时间 | 24 小时制，不补零："18:00"、"9:30" |
| 计数上限 | 超过 99 显示 `99+`；超过 999 显示 `999+` |
| 金额 | 货币符号在前："¥128" |

---

## 3. 时间与日期

**24 小时内用相对说法，超过用绝对日期。** 相对说法好懂，但超过一天后就失去了参照。

| 距离现在 | 显示 |
| --- | --- |
| 今天内 | `18:00` |
| 明天 | `明天 09:00` |
| 本周内 | `周六 18:00` |
| 今年内 | `10月3日` |
| 跨年 | `2026年10月3日` |
| 已过期 | `已逾期`（徽标里）/ `昨天 18:00`（详情里） |

不写"1 天后""2 小时前"这类相对量——用户得自己换算，而"明天 09:00"是直接可用的。

---

## 4. 长度上限

每个位置都有上限，**超出就是信息没提炼好**，不是空间不够。

| 位置 | 上限 | 超出怎么办 |
| --- | --- | --- |
| 按钮 | 2–6 个汉字 | 换更短的动词 |
| 导航栏标题 | 8 | 缩短页面名 |
| 表单字段标签 | 2–8 | 缩短名词 |
| 徽标 | 4 | 换更短的词 |
| 列表行标题 | 20（单行截断） | 截断加省略号 |
| 列表行副标题 | 24（单行截断） | 截断 |
| 对话框标题 | 12 | 换成陈述句 |
| 对话框正文 | 60（最多 3 行） | 拆成两步，或改用 BottomSheet |
| 错误提示 | 20（一行） | 只说最重要的那一条 |
| Toast | 20 | 换更短的说法 |
| Banner | 40（最多 2 行） | 改用整页说明 |
| 空状态标题 | 12 | — |
| 空状态说明 | 40（最多 2 行） | — |
| 输入框占位符 | 12 | 写示例而不是解释 |

---

## 5. 分场景写法

### 5.1 按钮

- 用**动词 + 对象**，不用"确定 / 好的 / 提交"
- 破坏性操作直接写"删除"，不写"确定"

| 场景 | 写 | 不写 |
| --- | --- | --- |
| 主操作 | 保存 / 创建任务 / 添加成员 | 确定 / 提交 |
| 次操作 | 稍后提醒 / 跳到下一步 | （"取消"是标准词，可以保留） |
| 破坏性 | 删除任务 / 退出家庭 | 确定 / 是 |

### 5.2 标题

- 用**页面名**，不用动作名：`家庭` 而不是 `查看家庭`
- 分组标题用时间或类别：`今天` / `本周` / `家庭共享`
- 不用问句

### 5.3 错误提示

必须包含**哪里错了 + 怎么改**，两句都要有。

| 情况 | 写 |
| --- | --- |
| 名称重复 | 名称已被占用，换一个试试 |
| 格式不对 | 日期格式像是 2026-10-03，检查一下 |
| 网络断了 | 网络不可用，改动已暂存本地 |
| 权限被拒 | 需要通知权限才能提醒你，去设置里打开 |
| 已达上限 | 免费版最多 5 个清单，删掉一个再加 |

**不写"操作失败""出错了""未知错误"**——这三句等于什么都没说。

### 5.4 成功提示

- 说结果，不说过程："任务已保存" 而不是 "正在保存任务"
- 不带情绪："已完成" 而不是 "太棒了！"
- 需要用户知道影响范围时补一句："已共享给全家 4 位成员"

### 5.5 空状态

三段结构：**陈述现状 → 说明原因或价值 → 给出下一步**。

| 变体 | 写 |
| --- | --- |
| 首次空 | 还没有任务 / 新建一个，从今天开始 / 新建第一个任务 |
| 搜索无结果 | 没找到"储物间" / 换个词试试，或清除筛选条件 / 清除筛选 |
| 权限受限 | 需要通知权限 / 开启后才能收到提醒 / 去设置 |
| 加载失败 | 没加载出来 / 检查网络后重试 / 重试 |

**不写"这里什么都没有"**——那是描述界面，不是描述用户的事。

### 5.6 危险操作确认

结构：**标题提问（做什么）→ 正文说明后果 → 按钮用动词**。

| 项 | 写 |
| --- | --- |
| 标题 | 删除这条任务？ |
| 正文 | 删除后无法恢复，其他成员也看不到了。 |
| 按钮 | 取消 ｜ 删除 |

**不用"你确定吗？"**——这不是信息，是刁难。

### 5.7 权限请求

先说**用途**，再说请求。

| 权限 | 写 |
| --- | --- |
| 通知 | 开启后才能在你设的时间提醒你 |
| 日历 | 授权后可以把家务日程同步到系统日历 |
| 相册 | 用来给家人设置头像 |
| 麦克风 | 语音添加任务，说完自动识别 |

不写"我们需要您的授权"——用户关心的是"对我有什么好处"。

### 5.8 通知

- 标题 ≤ 12 字，正文 ≤ 30 字
- 用称谓不用名字："妈妈完成了买菜"
- **不在通知里暴露敏感信息**：锁屏上可能被别人看到，"体检报告已更新"要改成"有一条新消息"
- 不用"快来看看""别错过"

## 6. 禁忌词表

| 不要写 | 改写为 | 原因 |
| --- | --- | --- |
| 操作失败 | 没保存成功，检查网络后重试 | 说了等于没说 |
| 无效输入 | 名称里有特殊符号，换一个试试 | 要指出具体问题 |
| 未知错误 | 没成功，稍后再试试 | 别暴露技术细节 |
| 您 | 你 / 省略主语 | 家庭场景里太生分 |
| 请稍候 | 正在同步 | 说清在做什么 |
| 亲 / 小伙伴 | （删除） | 与"温和"不是一回事，是油腻 |
| ！ | 。 | 催促感 |
| 你确定吗？ | 直接说后果 | 不是信息 |
| 数据不存在 | 这条任务已被删除 | 用人话 |
| 系统繁忙 | 服务暂时不可用，稍后再试 | 同上 |

---

## 7. 中文与英文、数字的混排

| 规则 | 例 |
| --- | --- |
| 中文与半角英文/数字之间加空格 | `还剩 3 天`、`打开 Wi-Fi` |
| 中文标点用全角 | `，。？：` |
| 英文与数字内部用半角 | `18:00`、`Wi-Fi` |
| 引号用中文形式 | `"储物间"` |
| 版本号、单位缩写保留半角 | `v1.0.0`、`5 GB` |

---

## 8. 文案与无障碍的关系

读屏标签与视觉文案**不是同一份文本**，两者都要写：

| 场景 | 视觉文案 | 读屏标签 |
| --- | --- | --- |
| 图标按钮 | 无 | 搜索 |
| 计数徽标 | 3 | 并入宿主：提醒，3 条未读 |
| 头像 | 妈 | 妈妈 |
| 进度 | 3/5 | 已完成 3 项，共 5 项 |
| 时间 | 18:00 | 今天 18:00 |

规律：**视觉文案可以短，读屏标签必须完整**。完整句式模板见 [`06-accessibility.md`](06-accessibility.md) §3.2。

## 9. 验收清单

- [ ] 全文没有感叹号
- [ ] 全文没有"您"
- [ ] 没有出现 §6 禁忌词表里的词
- [ ] 每条错误提示都包含"哪里错 + 怎么改"
- [ ] 每个危险操作都说明了后果，且没有用"你确定吗"
- [ ] 每个空状态都给出了下一步
- [ ] 所有文案长度在上限之内
- [ ] 中文与数字/英文之间有空格
- [ ] 时间显示符合 §3 的相对/绝对规则
- [ ] 通知文案不包含锁屏敏感信息
- [ ] 读屏标签覆盖了所有视觉上被简写的文案
- [ ] 把界面文案单独摘出来看，仍然读得通
