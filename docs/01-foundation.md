# 01 · 设计基础

## 1. 设计原则

| 原则 | 含义 | 落地做法 |
| --- | --- | --- |
| 清新 | 界面要"透气" | 内容页用充足留白，彩色面积不超过 30%，分隔线用极低对比 |
| 自然 | 色彩来自自然，不刺眼 | 色相取自叶、雾、天光；中性色带一点绿灰倾向，不用纯灰 |
| 温和 | 没有攻击性的形态 | 大圆角、无锐角、阴影柔和、动效带弹性但不夸张 |
| 家庭 | 多人共享的语境 | 成员头像、共享状态、任务归属类组件优先；文案友好不说教 |
| 工具 | 高效、可预期 | 状态机明确（默认/按下/选中/禁用/加载/错误），操作即时反馈 |

## 2. 风格基调：Liquid Glass

iOS 26 的 Liquid Glass 由六个特征构成，这是整个系统的视觉骨架：

1. **分层材质** — 界面分成"内容层"与"浮在内容之上的玻璃层"。导航栏、Tab 栏、工具条、浮层用半透明材质，内容在其下滚动并透出。
2. **边缘高光** — 玻璃边缘有一道 1px 高光描边（上亮下暗），暗示折射与光源。这是最容易识别的特征，也是"廉价毛玻璃"和"真玻璃"的分界线。
3. **同心圆角** — 嵌套容器的圆角保持同心：内圆角 = 外圆角 − 内边距。避免圆角套圆角产生视觉噪声。
4. **悬浮与收缩** — 导航栏与 Tab 栏在滚动时可收缩、吸附成胶囊，主动为内容让位。
5. **动态取色** — 玻璃会吸收下层内容的颜色倾向；同时重要操作按钮会点亮品牌色。
6. **克制阴影** — 层次由模糊与描边建立，阴影只做轻量落地感，不参与分层。

### 平台策略

| 层面 | 策略 |
| --- | --- |
| 令牌 | 完全共享（色彩、字阶、间距、圆角、曲线、动效时长） |
| 语义 | 完全共享（组件名、变体名、状态机、无障碍标签） |
| 外观 | 各自原生：iOS 用 SF Symbols + 大标题 + 边缘返回手势；Android 用 Material Symbols + Top App Bar + 预测式返回 |
| 目标 | 跨端保证**视觉重量一致**（层级、密度、强调度），不追求逐像素复刻 |

## 3. 色彩系统

定稿方案：**温和蓝**。以天蓝 `#1677B3` 与湖蓝 `#B0D5DF` 为主，浅色版为主交付，深色版同期出。
所有色值经对比度验证，具体数值见下表。

### 3.1 色卡

十二个色按层位分成两段：**浅段做背景，深段做组件**。分段依据是能不能承载白字。

**背景层 · 浅段**（只配深色文字）

| 名称 | 色值 | 白字对比 | 深字对比 | 用途 |
| --- | --- | --- | --- | --- |
| 湖水蓝 | `#B0D5DF` | 1.5:1 ❌ | 13.6:1 ✅ | 页面底、卡片染色、图标底座 |
| 天青 | `#7EC4CF` | 1.9:1 ❌ | 10.5:1 ✅ | 背景渐变副色、进度轨道 |
| 群青 | `#4C8DAE` | 3.7:1 ❌ | 5.8:1 ✅ | 描边、次级强调 |

**组件层 · 深段**（可配白字，越深越重）

| 名称 | 色值 | 白字对比 | 用途 |
| --- | --- | --- | --- |
| 石青 | `#1685A9` | 4.2:1 ⚠️ | 装饰亮色：图标、光晕。不做承载文字的填充 |
| 天蓝 | `#1677B3` | 4.9:1 ✅ | 文字、图标、链接；深色版按钮填充起点 |
| 景泰蓝 | `#2A5CAA` | 6.7:1 ✅ | 深色版按钮填充终点 |
| 靛蓝 | `#065279` | 8.4:1 ✅ | 按下态 |
| 海军蓝 | `#1E3B7A` | 10.7:1 ✅ | 深色模式表面 |
| 海青 | `#080F40` | 17.1:1 ✅ | 最深，深色模式备用 |

### 3.2 派生色

色卡里没有、但组件必须用的几个色，全部由上面的色值派生并验证过：

| 令牌 | 值 | 说明 |
| --- | --- | --- |
| `derived.fill-light-1/2` | `#8FCFDD → #63BAD2` | **浅色版按钮 / 芯片填充**，配 `#0E3A55` 深字，5.4–6.9:1 |
| `derived.fill-mid-1/2` | `#4FB0C8 → #1685A9` | 小面积标记：勾选、开关、圆点 |
| `derived.text-on-soft` | `#123F5C` | 背景层上的文字色，6–14:1 |
| `derived.text-on-fill` | `#0E3A55` | 浅色按钮上的文字色 |

### 3.3 语义色

红黄回归，但全部降饱和；同时保留绿色作为成功色。

| 语义 | 色值 | 白字对比 | 浅底色 | 说明 |
| --- | --- | --- | --- | --- |
| 成功 | `#2A7F5C` | 4.9:1 ✅ | `#E3F5EC` | 柔和鼠尾草绿 |
| 信息 | `#1677B3` | 4.9:1 ✅ | `#E1F0F8` | 复用主色 |
| 警示 | `#97651F` | 5.0:1 ✅ | `#FFF4DC` | 蜂蜜色，不用亮黄 |
| 危险 | `#B8564D` | 4.7:1 ✅ | `#FBE7E4` | 陶土红，不用正红 |

两条硬约束：

- 降饱和不能降过头——红黄一旦提亮到"好看"，白字对比就会掉到 4.5 以下。
  陶土红 `#B8564D`（4.7）和蜂蜜色 `#97651F`（5.0）是同时满足"柔和"和"可读"的边界。
- 颜色不单独承担信号：成功用对勾、警示用三角、错误用实心禁止图标，错误文案加粗。

### 3.5 使用规则

**规则一：浅段不能放白字。** 湖水蓝、天青配白字只有 1.5 / 1.9，等于没有文字。
浅段只做表面，文字一律用 `#123F5C`。

**规则二：石青不承载文字。** `#1685A9` 配白字 4.2:1，差一点。
它是系统里的"装饰亮色"——图标、进度条、光晕可用，按钮填充必须从天蓝起。

**规则三：所有组件统一用蓝。** 按钮、开关、勾选、进度、Tab 选中、FAB 一律走蓝，
红黄只出现在语义提示里，不参与控件配色。界面读起来就是"一套蓝 + 少量信号色"。

**规则四：组件比背景重一档，但别跳到最深。** 两个版本的分工：

| 版本 | 背景 | 组件填充 | 组件文字 | 对比度 |
| --- | --- | --- | --- | --- |
| 浅色版 | 湖蓝 / 天青色晕 + 近白卡片 | `#8FCFDD → #63BAD2` | `#0E3A55` | 5.4–6.9:1 |
| 深色版 | 深蓝底 + 深蓝表面 | `#1677B3 → #2A5CAA` | 白色 | 4.9–6.7:1 |

浅色版最容易犯的错是"为了对比把按钮压深"：`#1677B3` 铺满按钮，整屏立刻变重，
而且它和卡片、图标底座的浅蓝不在一个系统里，看起来像两套东西。
按钮只要比背景重一档就够——浅底深字的对比度其实比深底白字更高。

**规则五：玻璃只用在浮层。** 卡片、列表行、提示条、输入框用近实底（92–96% 白）+
单条 hairline + 一层柔和投影；导航栏、Tab 栏、浮层、材质演示才用完整玻璃配方。
在同一个圆角上叠"半透明 + 描边 + 内高光 + 背景模糊"，浏览器在圆角处采样背景会产生重影。

**规则六：阴影带品牌色。** 用 `rgba(10,60,100,…)` 而不是纯黑，避免把明亮界面压灰。

### 3.6 渐变

渐变分两类，不能互换：

| 类别 | 令牌 | 值 | 约束 |
| --- | --- | --- | --- |
| 背景渐变 | `gradient.surface` | `#B0D5DF → #7EC4CF` | 只配 `#123F5C` 深字 |
| 组件渐变（浅） | `gradient.fill-light` | `#8FCFDD → #63BAD2` | 配 `#0E3A55` 深字 5.4–6.9:1 |
| 组件渐变（深） | `gradient.fill-dark` | `#1677B3 → #2A5CAA` | 白字 4.9–6.7:1 |
| 小面积标记 | `gradient.mid` | `#4FB0C8 → #1685A9` | 勾选、开关、圆点 |
| 重组件 | `gradient.deep` | `#065279 → #1E3B7A` | 按下态，白字 8.4–10.7:1 |

**页面色晕**：不用纯色铺底。用 2–3 个大半径径向渐变叠在 canvas 上，
色相取湖水蓝 / 天青 / 群青，透明度 18–66%。这套写法在浅色和深色下都成立：

```css
--wash:
  radial-gradient(90% 62% at 12% -6%, rgba(176,213,223,.66), transparent 62%),
  radial-gradient(82% 58% at 92%  2%, rgba(126,196,207,.46), transparent 64%),
  radial-gradient(120% 74% at 58% 104%, rgba(76,141,174,.18), transparent 68%);
```

**深色模式的坑**：背景层渐变的两个色必须换成深色（`#123449` / `#0F4055`），
否则深色下会出现"浅底 + 浅字"完全看不清。CSS 里把两个色标分别包一层 `light-dark()`：

```css
--grad-surface: linear-gradient(135deg,
  light-dark(#B0D5DF, #123449) 0%,
  light-dark(#7EC4CF, #0F4055) 100%);
```


## 4. 字体系统

### 4.1 字族

| 用途 | iOS | Android |
| --- | --- | --- |
| 正文/界面 | SF Pro Text / Display | Roboto Flex（系统默认） |

### 4.3 规则

- 一行正文最多 2 行，列表主文案 1 行截断，说明文字 2 行截断。
- 数值（金额、计数、时长）使用**等宽数字**（iOS `.monospacedDigit()` / Compose `FontFeatureSetting("tnum")`）。
- 全端尊重系统字号缩放：iOS Dynamic Type 至少支持到 AX3 不截断；Android 支持 `fontScale` 到 1.3。
- 使用 `caption2` 以下字号时，必须保证文字本身不是唯一信息载体。

## 5. 间距与布局

基准栅格 **4pt**。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `space.1` | 2 | 图标与角标 |
| `space.2` | 4 | 紧密内距 |
| `space.3` | 8 | 组件内距、行内元素间距 |
| `space.4` | 12 | 卡片内边距（小）、列表行内距 |
| `space.5` | 16 | **页面左右边距**、卡片内边距、区块内堆叠 |
| `space.6` | 20 | 大屏边距 |
| `space.7` | 24 | 区块之间的间距 |
| `space.8` | 32 | 分组之间 |
| `space.9` | 40 | 页面上下留白 |
| `space.10` | 48 | 空状态留白 |

规则：

- 页面左右边距手机 16，宽屏（≥ 428pt）20。
- 卡片之间 12，分组之间 24，分组标题与内容 8。
- 相关联的元素间距 ≤ 8，不相关的元素间距 ≥ 24 —— 用间距表达关系，而不是用分割线。

## 6. 形状与圆角

### 6.1 圆角阶梯

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `radius.xs` | 8 | 角标、小标签 |
| `radius.sm` | 10 | 芯片、小图标底座 |
| `radius.md` | 14 | 按钮、输入框、列表图标底座 |
| `radius.lg` | 18 | 小卡片、内嵌块 |
| `radius.xl` | 24 | 卡片、弹层 |
| `radius.2xl` | 32 | 底部弹层、大容器 |
| `radius.full` | 999 | 胶囊按钮、Tab 栏、分段控件 |

### 6.2 同心圆角

嵌套容器必须同心，否则视觉会出现"圆角打架"：

```
内圆角 = 外圆角 − 内边距
```

例：卡片 `radius.xl` (24) + 内边距 16 → 内部图片圆角 = 8（取 `radius.xs`）。

连续曲率（squircle）在 iOS 上直接使用 `RoundedRectangle(cornerRadius:style: .continuous)`；
Compose 没有等价 API，用 `RoundedCornerShape` 并把数值 **+2** 补偿视觉差异。

## 7. 高度与材质

### 7.1 阴影

阴影只做"落地感"，用双层（环境光 + 主光）薄阴影，禁止单层重阴影。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `elevation.0` | 无 | 平铺卡片 |
| `elevation.1` | `0 1 2 rgba(10,60,100,.04)` + `0 6 16 rgba(10,60,100,.06)` | 卡片、列表行 |
| `elevation.2` | `0 2 6 rgba(10,60,100,.06)` + `0 14 32 rgba(10,60,100,.09)` | 悬浮按钮、玻璃卡片 |
| `elevation.3` | `0 8 20 rgba(10,60,100,.09)` + `0 28 56 rgba(10,60,100,.13)` | 弹层、设备外框 |
| `elevation.brand` | `0 6 16 rgba(22,119,179,.18)` | 品牌填充元素专用（按钮、图标底座） |

**阴影带品牌色**，不要用纯黑阴影——纯黑会把明亮界面压灰。深色模式下退化为黑阴影。

### 7.2 玻璃材质

四种厚度，按"浮层与内容的距离"选择，距离越远越厚。

| 令牌 | 模糊 | 填充 | 用途 |
| --- | --- | --- | --- |
| `material.ultraThin` | 14 | `rgba(255,255,255,.38)` | 表头、输入浮层 |
| `material.thin` | 22 | `rgba(255,255,255,.54)` | 导航栏、Tab 栏、工具条 |
| `material.regular` | 30 | `rgba(255,255,255,.70)` | 浮层、Sheet 头 |
| `material.thick` | 44 | `rgba(255,255,255,.86)` | 模态、键盘上方工具条 |
| `material.tinted` | 30 + 品牌染色 | 品牌色 24–30% 叠加 | Hero 卡、选中态容器 |
| `material.sheen` | — | 白色高光扫过，3800ms | 强调卡片的动态高光 |

透明度的用法：**玻璃只用在浮层**。导航栏 62%、Tab 栏 62%、浮层 82%；
卡片、列表行、提示条、输入框用近实底（92–96% 白）+ 单条 hairline，
不要在同一层同时叠半透明、描边、内高光和背景模糊。

一个合格的玻璃层包含四件事，缺一件就会显得廉价：

1. 模糊背景（backdrop blur）
2. 半透明填充
3. 1px 顶部高光描边（`semantic.border.glass-top`）
4. 外圈 hairline（`semantic.border.hairline`）

性能与降级：低于 iOS 26 / Android 12 的系统降级为 `material.regular` 的纯色 + 描边版本，不做模糊。

## 8. 图标

- iOS 用 **SF Symbols**，优先 `.rounded` 变体；Android 用 **Material Symbols Rounded**。
- 尺寸阶梯：16 / 20 / 24 / 28。同一层级不混用。
- 描边粗细与文字对齐：24pt 图标线宽约 1.8–2。
- **图标底座**：需要强调时给图标加 34×34（`radius.sm`）或 40×40（`radius.lg`）的底座，
  填充 `gradient.surface`（浅蓝渐变）配 `derived.text-on-soft` 图标；
  需要更重时用 `gradient.mid` 配白色图标（如"收拾浴室"这类需要区分的行）。
- 图标不可单独承载信息，必须配文案或无障碍标签。

## 9. 动效

### 9.1 时长

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `motion.duration.instant` | 100 | 按压、勾选 |
| `motion.duration.fast` | 160 | 小元素出入 |
| `motion.duration.base` | 240 | 默认过渡 |
| `motion.duration.slow` | 340 | 页面转场、Sheet |
| `motion.duration.slower` | 500 | 大容器形变 |

规则：**进场慢、出场快**。位移距离越长，时长越长；透明度变化保持 160 以内。

### 9.2 弹簧

| 令牌 | iOS 参数 | Compose 近似 | 用途 |
| --- | --- | --- | --- |
| `motion.spring.gentle` | response .40 / damping .85 | dampingRatio .85 / stiffness 380 | 默认过渡 |
| `motion.spring.snappy` | response .28 / damping .82 | dampingRatio .82 / stiffness 900 | 开关、分段选中 |
| `motion.spring.bouncy` | response .42 / damping .68 | dampingRatio .68 / stiffness 300 | 强调反馈、完成任务 |

### 9.3 交互反馈

| 交互 | 反馈 |
| --- | --- |
| 任何可点区域按下 | 缩放至 0.97 + 亮度 96%，100ms |
| 勾选 / 取消 | 勾的描边 260ms 弹出（`cubic-bezier(.2,1.6,.5,1)`）+ 光晕 400ms 扩散 + 轻触觉 |
| 开关切换 | 滑块 300ms 弹簧，轨道 260ms 变色，轻触觉 |
| 进度增长 | 3200ms `easeOutCubic`，数字同步递增，不用线性 |
| 提示浮入 | 320ms 上移淡入；浮出 160ms |
| 危险操作确认 | 警告触觉 |
| 下拉刷新越界 | 阻力递增，触觉在阈值处触发一次 |
| 列表插入/删除 | 340ms `gentle` + 位移 10pt，多项时错峰 20ms |
| 骨架屏 | 2200ms 微光扫过，只在加载态播放 |

开启"减弱动态效果"时：所有位移与缩放退化为 150ms 交叉淡入淡出，弹簧改为线性。
骨架微光与玻璃高光扫过直接停止，显示静态占位。

## 10. 无障碍

- **触控目标**：任何可点区域最小 44×44，视觉尺寸可以更小。
- **动态字体**：全部组件用相对字号，AX3 下不截断、不重叠；禁止用固定高度裁切文字。
- **色彩不是唯一信息**：状态同时用图标或文字表达。
- **焦点顺序**：按视觉阅读顺序；弹层出现时焦点进入弹层，关闭后归还。
- **屏幕阅读器**：图标按钮必须有标签；列表行读作"标题，副标题，状态"；家庭场景中的成员头像读作"成员名 + 角色"。
- **降低透明度**：系统开启后，玻璃降级为不透明表面。
